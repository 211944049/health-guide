## 适用人群

- 嘴唇干、起皮、裂口的人。
- 习惯舔嘴唇、撕死皮的人。
- 冬天或干燥环境里嘴唇明显不适的人。
- 给孩子挑唇膏的家长。

<strong>需要看医生</strong>：<strong>反复发作的唇部红肿脱屑、口角开裂、嘴唇出现白斑/色素改变/硬结/久不愈合的溃疡</strong>。

## 具体做法

### 1. 为什么会干：嘴唇结构特殊

- <strong>嘴唇没有皮脂腺和汗腺</strong>，不能自己分泌油脂形成保护膜。
- <strong>角质层很薄</strong>，屏障能力弱。
- <strong>一直暴露在外</strong>，受风吹、干燥、紫外线、唾液影响。

<strong>所以嘴唇需要"外来的油脂"来锁水</strong>，这就是唇膏的作用。<strong>它不"补水"，它是封闭保湿。</strong>

### 2. 选唇膏：看成分，不看包装

<strong>有效的成分（选含这些的）：</strong>

| 成分 | 作用 |
| --- | --- |
| <strong>凡士林（矿脂）</strong> | <strong>最有效的封闭剂</strong>，锁水能力最强，几乎不刺激 |
| <strong>矿物油、石蜡、微晶蜡</strong> | 封闭 |
| <strong>角鲨烷、霍霍巴油、乳木果油</strong> | 封闭 + 柔润 |
| <strong>神经酰胺、胆固醇</strong> | 修复屏障 |
| <strong>甘油、透明质酸</strong> | 湿润（吸水），<strong>需配合封闭剂</strong> |
| <strong>防晒成分（氧化锌、二氧化钛等）</strong> | 嘴唇也会被晒伤和光老化 |

<strong>应该避开的成分（会刺激或加重干裂）：</strong>

- <strong>薄荷醇、樟脑、薄荷油</strong>——清凉感来自刺激，<strong>会让干裂更明显</strong>，还容易形成"越用越依赖"的循环。
- <strong>苯酚、水杨酸</strong>——去角质作用，用在唇上会<strong>加重脱屑和裂口</strong>（部分老式"唇炎膏"含这些）。
- <strong>香精、色素</strong>——常见过敏原。
- <strong>丙二醇</strong>——部分人会刺激。
- <strong>"丰唇""辣感"成分</strong>——是刺激，不是效果。

<strong>一条实用原则</strong>：<strong>成分表越短越好，最好以凡士林或蜡为第一位。</strong>

### 3. 怎么用

- <strong>一天多次，感觉干就涂</strong>，不要等到裂开。
- <strong>睡前厚涂一层</strong>（夜间是修复窗口），这是最有效的单次操作。
- <strong>涂之前不要舔、不要撕死皮</strong>。
- <strong>出门前涂含防晒的唇膏</strong>（嘴唇是皮肤癌和光老化的部位之一）。
- <strong>喝水后用清水轻拍、再涂</strong>（去掉刺激性残留，比如食物酸、酱汁）。
- <strong>不要共用唇膏</strong>（尤其有唇疱疹时）。

### 4. 舔嘴唇：这条比选唇膏更重要

<strong>舔嘴唇是嘴唇干裂的主要原因之一，而且是"越舔越干"的循环：</strong>

- 唾液蒸发时<strong>带走唇部更多水分</strong>。
- 唾液里的<strong>消化酶</strong>会刺激已经薄弱的角质层。
- 反复舔 → 干 → 更想舔 → <strong>形成"舌舔性唇炎"</strong>。

<strong>怎么戒：</strong>
- <strong>感觉想舔就改成涂唇膏</strong>（用动作替换动作）。
- <strong>手边随时有一支</strong>，减少"凑合舔一下"的机会。
- <strong>已经有舌舔性唇炎</strong>（口周一圈红斑、脱屑）：需要<strong>严格停止舔唇</strong> + 保湿，<strong>通常需要数周</strong>；严重的要看皮肤科（可能需要短期用药）。

### 5. 其他常见原因与处理

| 情况 | 处理 |
| --- | --- |
| <strong>口角开裂（口角炎）</strong> | 常见与干燥、舔唇、营养（B 族、铁）或真菌/细菌感染有关。<strong>保持干燥 + 保湿</strong>；反复不愈要看医生（可能需要抗真菌或抗菌药膏） |
| <strong>冬天/空调房干裂</strong> | 加湿 + 频繁涂封闭性唇膏 |
| <strong>晒伤后嘴唇痛</strong> | 冷敷 + 凡士林，避免再暴晒（见 [晒伤和晒后怎么处理](/entry/after-sun/)） |
| <strong>对唇膏或口红过敏</strong> | 换成分最简单的产品；反复发作需做斑贴试验 |
| <strong>嘴唇脱皮严重</strong> | <strong>不要撕</strong>。厚涂凡士林软化后自然脱落 |

## 健康原理

- <strong>为什么嘴唇比脸更容易干</strong>：面部皮肤有<strong>皮脂腺</strong>分泌皮脂形成皮脂膜，而<strong>唇部没有皮脂腺和汗腺</strong>，角质层也更薄（约 3–5 层细胞，面部其他部位更多）。<strong>没有内源性的油脂屏障，水分蒸发就更快</strong>——这是结构决定的。
- <strong>为什么"封闭"比"补水"重要</strong>：唇部缺的是<strong>锁水的能力</strong>。凡士林这类封闭剂能在表面形成疏水膜，<strong>把蒸发量降到最低</strong>（凡士林可减少经皮水分流失约 98%，是最强的封闭剂之一）。而单纯"补水"成分如果不同时封闭，蒸发时反而带走更多水分。
- <strong>为什么薄荷醇、樟脑会加重干裂</strong>：它们通过<strong>激活冷觉受体（TRPM8）</strong>产生清凉感，<strong>这是刺激而不是治疗</strong>。刺激会引起局部炎症和血管反应，<strong>破坏本就脆弱的屏障</strong>；同时清凉感消失后，人会想再涂——形成依赖循环。
- <strong>为什么苯酚、水杨酸不该用在唇上</strong>：它们的作用是<strong>去角质/剥脱</strong>。唇部角质层本来就薄，剥脱后屏障更差，<strong>短期看起来"去了死皮"，实则加重裂口</strong>。这类成分在部分老式唇炎产品里还存在，<strong>买之前要看成分表</strong>。
- <strong>为什么舔唇会形成恶性循环</strong>：唾液<strong>蒸发带走水分</strong>（渗透和蒸发双重作用），其中<strong>淀粉酶、溶菌酶等会刺激角质层</strong>。反复刺激导致角质层增厚、脱屑、皲裂，形成<strong>舌舔性唇炎</strong>——典型表现是<strong>唇缘一圈清晰的红斑和脱屑</strong>，正好是舌头能舔到的范围。
- <strong>为什么嘴唇也需要防晒</strong>：唇部皮肤薄、黑色素少，<strong>对紫外线更敏感</strong>。下唇是<strong>日光性唇炎和鳞状细胞癌</strong>的常见部位，长期户外工作者尤其要注意。<strong>这是唇膏要含防晒的真实理由</strong>（不是营销）。
- <strong>为什么标 C</strong>：唇部结构与唇膏成分的作用机制<strong>清楚且有共识</strong>（凡士林的效果接近 A）；但"某种唇膏对唇炎的改善"缺少高质量对照研究，多数唇炎还与舔唇、感染、营养、过敏等多因素相关。<strong>方向可靠，具体效果因人而异</strong>，因此 C。

## 常见误区

- <strong>"唇膏会越用越干、产生依赖"</strong>：<strong>没有这种机制</strong>。干是因为唇部本身不能保湿、又持续受刺激（舔、风吹、干燥）。<strong>不涂才更干。</strong> 但含薄荷醇/苯酚的产品确实会形成"越用越想用"的循环——<strong>那是成分的问题，不是唇膏本身。</strong>
- <strong>"舔嘴唇能润一下"</strong>：<strong>这是最常见的错误</strong>，且是干裂的主要原因。
- <strong>"多喝水就不干"</strong>：全身补水有帮助，但<strong>唇部缺的是表面油脂</strong>，喝水不能替代封闭保湿。
- <strong>"撕掉死皮就好了"</strong>：撕会<strong>撕破下面的活组织</strong>，造成裂口和出血，可能继发感染。
- <strong>"唇膏越贵越好"</strong>：<strong>凡士林是最便宜的、也是证据最强的</strong>。价格主要买的是香味、质地和包装。
- <strong>"嘴唇干是缺维生素"</strong>：只有<strong>明确的 B 族维生素或铁缺乏</strong>才相关（少见）。<strong>大多数干裂是外部因素。</strong>
- <strong>"唇炎要涂激素药膏"</strong>：<strong>不要自己用</strong>。需要先明确类型（接触性、舌舔性、感染性、光化性等），用药完全不同。
- <strong>"口红可以替代唇膏"</strong>：口红主要给颜色，保湿能力有限；<strong>长期用不保湿的口红会加重干裂</strong>。
- <strong>"唇部去角质能改善脱皮"</strong>：<strong>不要</strong>。唇部不能像脸一样去角质。

## 风险与禁忌

- <strong>不要舔嘴唇、不要撕死皮、不要用磨砂去唇部角质</strong>。
- <strong>不要使用含薄荷醇、樟脑、苯酚、水杨酸的唇部产品</strong>（尤其已有干裂时）。
- <strong>不要在唇部破损时使用含香精、色素、防晒剂的产品</strong>（可能刺激），先用纯凡士林。
- <strong>有唇疱疹（单纯疱疹）时不要共用唇膏、不要用手碰后接触眼睛</strong>。
- <strong>不要自行使用含激素的药膏涂唇</strong>（长期使用会导致皮肤萎缩等问题）。
- <strong>孕期</strong>：避免含维 A 酸类成分的唇部产品（罕见但应留意成分表）。
- <strong>儿童</strong>：用成分简单的凡士林类产品；<strong>避免含薄荷、香精的产品</strong>（孩子更容易舔）。
- <strong>出现以下情况尽快就医</strong>：嘴唇溃疡超过 2 周不愈、出现白斑或色素改变、有硬结、下唇长期糜烂、口角反复开裂不愈。
- <strong>户外工作者/长期日晒者</strong>：含防晒的唇膏 + 帽子，下唇要重点保护。

## 何时求助专业人士

- <strong>唇部干裂、脱屑反复超过 2–4 周</strong>，用基础保湿无效 → 皮肤科。
- <strong>口角反复开裂</strong>（口角炎）→ 皮肤科或口腔科（可能需要排查感染或营养因素）。
- <strong>嘴唇或口腔出现白斑、红斑、硬结、溃疡超过 2 周不愈</strong> → <strong>尽快就诊</strong>（需排除癌前病变或恶性病变）。
- <strong>怀疑接触性过敏</strong>（换用某口红/唇膏后出现红肿脱屑）→ 皮肤科做斑贴试验。
- <strong>嘴唇明显肿胀、伴呼吸困难</strong> → <strong>立即急诊</strong>（可能是血管性水肿或过敏反应）。
- <strong>孩子嘴唇反复干裂、口角裂</strong> → 儿科或皮肤科（需排查舔唇习惯与营养因素）。
