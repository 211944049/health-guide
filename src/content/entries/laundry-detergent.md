## 适用人群

- 皮肤敏感、换洗衣液后起疹或瘙痒的人。
- 家里有婴幼儿或湿疹患者，想知道怎么洗的人。
- 纠结要不要买「除螨」「杀菌」洗衣液的人。
- 想减少家里化学品用量的人。

<strong>需要就医而非换洗涤剂的情况</strong>：反复皮疹、瘙痒、渗出——衣物洗涤剂可能加重，但不能替代皮肤科治疗。

## 具体做法

### 1. 普通洗衣液就够用

| 产品类型 | 实际必要性 |
| --- | --- |
| 普通洗衣液 | <strong>日常够用</strong>，去污主要靠表面活性剂 |
| 洗衣凝珠 | 方便、剂量固定；注意<strong>儿童误食风险很高</strong> |
| 「杀菌」洗衣液 | 日常家庭意义有限；<strong>真正需要消毒时应用专门的消毒剂</strong>（如含氯或酚类，按说明） |
| 「除螨」洗衣液 | 效果有限（见下） |
| 柔顺剂 | <strong>非必需</strong>，敏感肌建议不用 |
| 洗衣粉 | 去污强、碱性高，对手洗和敏感肌不太友好 |

<strong>核心结论：把「洗干净」做好，比选哪种「功能」更重要。</strong>

### 2. 敏感肌与婴幼儿的四个动作

1. <strong>选无香、无色素、成分简单的洗衣液</strong>（婴幼儿专用款通常符合这一点）。
2. <strong>用量减半</strong>：多数人倒得远超需要，残留随之增加。<strong>按瓶身建议的上限往下调。</strong>
3. <strong>多漂洗一次</strong>：这是最有效的一步。
4. <strong>不用柔顺剂，不用香氛珠</strong>，避免「留香持久」类产品。

另外：<strong>新衣服先洗再穿</strong>，能去除整理剂和染料残留。

### 3. 关于「除螨」

尘螨是常见的过敏原，但<strong>洗衣液杀螨的效果有限</strong>。真正有效的是：

- <strong>热水洗</strong>：55–60 ℃ 以上能有效杀死尘螨（多数洗衣机有高温洗或「除菌洗」程序）。
- <strong>烘干或暴晒</strong>：高温干燥环境能让尘螨失活。
- <strong>控制湿度</strong>：室内相对湿度低于 50% 能显著抑制尘螨繁殖（见[湿度多少合适](/entry/humidity/)）。
- <strong>防螨床品</strong>：物理隔离螨虫及其过敏原，对过敏人群有实际意义。

对尘螨过敏的人，<strong>重点在床品和环境湿度</strong>，而不是洗衣液的功能宣称。

### 4. 关于消毒

- <strong>日常洗衣不需要消毒剂</strong>：洗涤剂 + 机械揉搓 + 干燥已能去除绝大部分微生物。
- <strong>需要消毒的情况</strong>：家中有传染病患者（如诺如病毒、流感）、衣物被体液污染、或免疫低下者的衣物。
- <strong>不要混用消毒剂</strong>：<strong>含氯消毒剂（84 等）与酸性清洁剂混合会产生氯气</strong>，这是真实的急性中毒风险。
- <strong>消毒剂按说明稀释和接触时间使用</strong>，不是「多放更有效」。

### 5. 安全存放（尤其有孩子和宠物）

- <strong>洗衣凝珠必须放在儿童拿不到的地方</strong>：外观像糖果，误食可造成严重化学损伤，<strong>这是真实的儿童中毒来源</strong>。
- <strong>原包装保存，不要换到饮料瓶里</strong>。
- <strong>不要放在食物附近</strong>。
- <strong>柔顺剂、消毒剂分开存放，不要混装</strong>。

### 6. 洗涤剂用量的实际建议

- <strong>滚筒洗衣机用水少，用量应少于波轮</strong>。
- <strong>硬水地区可略增，但不能靠加量解决</strong>（见[净水器怎么选](/entry/water-purifier-choice/)）。
- <strong>泡沫多不等于洗干净了</strong>。
- <strong>过量的洗涤剂会残留在纤维里</strong>，让衣服发硬、发黏、吸水变差，也可能刺激皮肤。

## 健康原理

- <strong>洗衣液怎么去污</strong>：表面活性剂一端亲水、一端亲油，把油污从纤维上「拉」下来并分散在水里；助洗剂软化水、防止污垢再沉积。这是成熟的化学过程，<strong>不需要额外的「功能」</strong>。
- <strong>残留为什么会刺激皮肤</strong>：洗涤剂和柔顺剂中的香精、防腐剂（如甲基异噻唑啉酮）、某些表面活性剂是接触性皮炎的常见致敏原。衣物贴身穿着、加上汗液和摩擦，会促进这些成分的渗透。
- <strong>柔顺剂的机制与代价</strong>：阳离子表面活性剂在纤维表面形成润滑膜，带来柔软手感，但<strong>这层膜会降低织物吸水性和透气性</strong>——所以运动服明确不建议用柔顺剂（见[运动服怎么选](/entry/sportswear/)）。
- <strong>尘螨的生态</strong>：尘螨以人体脱落的皮屑为食，在<strong>温暖（约 20–25 ℃）且潮湿（相对湿度 70–80%）</strong>的环境中繁殖最快。因此控制湿度和温度是根本手段，杀螨剂和「除螨洗衣液」只是辅助。
- <strong>为什么标 C</strong>：洗涤剂的基本去污能力是确定的；但「某类洗衣液能改善皮肤健康或降低过敏」的直接对照研究很少，且个体敏感性差异极大。方向（减少残留、控制湿度、热水洗）有机制和间接证据支持，具体产品推荐证据薄弱。综合给出 C。<sup class="ref-mark">[1][2][3][4]</sup>

## 常见误区

- <strong>泡沫越多洗得越干净</strong>：泡沫量与去污力无关，低泡配方反而更易漂洗。
- <strong>洗衣液放得越多越干净</strong>：过量会残留、伤衣物、刺激皮肤，还可能洗不干净。
- <strong>柔顺剂让衣服更健康</strong>：它改善手感，但降低吸水性、增加化学残留，<strong>贴身衣物和运动服都不建议用</strong>。
- <strong>「除螨洗衣液」能解决尘螨过敏</strong>：效果有限。<strong>热水洗、烘干、控制湿度、防螨床品</strong>才是有效手段。
- <strong>一定要用消毒剂才卫生</strong>：日常洗衣不需要；消毒剂滥用还会促进耐药和刺激皮肤。
- <strong>热水洗对所有衣物都好</strong>：高温会缩水、褪色、损伤弹性纤维，需按标签选择。
- <strong>婴儿衣物必须用专用洗衣液</strong>：温和的无香产品就够，「专用」更多是营销；关键是<strong>成分简单 + 充分漂洗</strong>。
- <strong>衣物晒干就一定有阳光味</strong>：那种气味的来源是阳光下的光化学产物和臭氧，与「杀菌效果」不同，不要把它当作卫生指标。
- <strong>混用清洁剂效果更强</strong>：<strong>含氯消毒剂与酸性产品混合会产生有毒氯气</strong>，这是危险行为。

## 风险与禁忌

- <strong>含氯消毒剂（84 消毒液等）</strong>：
  - <strong>绝对不能与洁厕灵、醋等酸性物质混合</strong>，会产生氯气，可致严重呼吸道损伤甚至死亡。
  - 不要与含氨产品混用。
  - 需按说明稀释，使用时保持通风，戴手套。
- <strong>洗衣凝珠</strong>：<strong>儿童误食风险高</strong>，可致口腔、气道和消化道化学烧伤。必须锁存。误食后<strong>不要催吐</strong>，立即就医或拨打急救电话。
- <strong>皮肤病患者（湿疹、银屑病、接触性皮炎）</strong>：用无香、无柔顺剂方案，若仍加重需就医明确致敏原。
- <strong>婴幼儿</strong>：皮肤屏障未发育完全，<strong>优先无香、充分漂洗</strong>；尿布区衣物更要注意残留。
- <strong>哮喘、过敏性鼻炎患者</strong>：尘螨是常见诱因，控制湿度、热水洗床品比选洗衣液更重要。
- <strong>免疫功能低下者</strong>：衣物消毒可按医嘱进行，但不要自行滥用消毒剂。
- <strong>不要用洗衣液洗餐具或食物容器</strong>：成分与食品用洗涤剂不同，残留有风险。
- <strong>绝对不要把洗涤剂分装到饮料瓶里</strong>，这是家庭误服中毒的经典原因。

## 何时求助专业人士

- <strong>换洗衣液后出现皮疹、瘙痒、红肿</strong>：停用可疑产品并看皮肤科，必要时做斑贴试验确定致敏原。
- <strong>婴幼儿衣物接触部位反复发红、渗出</strong>：建议儿科或皮肤科就诊。
- <strong>误食洗涤剂、消毒剂或洗衣凝珠</strong>：<strong>立即就医或拨打急救电话</strong>，不要自行催吐。
- <strong>吸入混用消毒剂产生的气体后出现咳嗽、胸闷、呼吸困难</strong>：<strong>立即离开现场并急诊</strong>。
- <strong>尘螨过敏症状（晨起喷嚏、鼻塞、夜间咳嗽）长期不缓解</strong>：建议变态反应科评估，可能需要环境干预 + 药物治疗。
- <strong>衣物洗后仍发硬、发黏、有异味</strong>：通常是洗涤剂残留或洗衣机需要清洗，可先减少用量并清洁洗衣机。
