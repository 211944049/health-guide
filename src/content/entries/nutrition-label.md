## 适用人群

- 在超市、便利店、电商买包装食品的人。
- 想减糖、减钠、控制反式脂肪，但不想背营养学的人。
- 看广告词（0 糖、无蔗糖、0 反式脂肪、非油炸）时想知道到底什么意思的人。

需要严格计算碳水、蛋白质、钾磷摄入的人（糖尿病、慢性肾病等），标签只是数据来源之一，算法要按医生或营养师给的方案来。

## 具体做法

### 1. 先看配料表的前三位

配料按<strong>加入量递减</strong>排列。前三位基本决定了这个产品是什么。

举例：一款「全麦饼干」的配料是「小麦粉、白砂糖、植物油、全麦粉……」，说明全麦粉排在三名之外，用量很可能很少——它仍然是糖和油占主导的饼干，不是粗粮。

判断口诀：<strong>前三位里有糖或油，就不能指望它是健康食品。</strong>

### 2. 扫一遍配料表里有没有这些词

| 看到的词 | 意味着什么 |
| --- | --- |
| 白砂糖、绵白糖、果葡糖浆、葡萄糖浆、麦芽糖浆 | 添加糖。看它排第几位，越靠前越多 |
| 麦芽糊精 | 淀粉水解物，升血糖速度不亚于糖，常被用来"凑量" |
| 氢化植物油、部分氢化植物油、人造奶油、起酥油、植脂末 | 可能含反式脂肪，注意看它在配料表的位置 |
| 果胶、卡拉胶、黄原胶 | 增稠剂，安全性没问题，不用避 |
| 山梨酸钾、苯甲酸钠 | 防腐剂，合规用量下不必担心 |
| 三氯蔗糖、阿斯巴甜、安赛蜜、赤藓糖醇 | 代糖。热量低，但"无糖"不等于"没热量" |

<strong>不必一见添加剂就恐慌</strong>：合规使用的添加剂有安全评估，真正值得盯的是糖、钠、饱和脂肪和反式脂肪。

### 3. 营养成分表：一律换算成每 100 g 比较

这是最关键的一条。很多产品用「每份 30 g」把数字做得很小，看起来什么都低。

<strong>同类产品横向比较时，统一按每 100 g（或每 100 mL）看</strong>，数字才有可比性。

### 4. 盯三个数

| 指标 | 怎么判断 |
| --- | --- |
| 钠 | 看 NRV%。一份的钠 NRV% 就超过 30%，属于高钠食品，值得考虑换一个 |
| 饱和脂肪 + 反式脂肪 | 配料表里有氢化植物油、植脂末、起酥油的，重点看这两项 |
| 碳水化合物里的糖 | 注意「碳水化合物」不等于「糖」，糖的信息可能在配料表里更清楚 |

### 5. 看懂几个标注的法定含义

| 标签上写的 | 法规含义 | 容易误解的地方 |
| --- | --- | --- |
| 0 糖 / 无糖 | 每 100 g（或 100 mL）糖 ≤ 0.5 g | 不等于没有碳水、没有热量 |
| 无蔗糖 | 只说明没加蔗糖 | 可能加了果葡糖浆、麦芽糖浆 |
| 0 反式脂肪 | 每 100 g 反式脂肪 ≤ 0.3 g | 配料表有氢化植物油，仍可能含少量 |
| 非油炸 | 没有法定含义 | 很多非油炸是烤的，但依然刷了大量油 |
| 高钙 / 富含膳食纤维 | 有法定阈值 | 达到阈值不代表含量很高，要对比具体数值 |

### 6. 别忘了高钠的重灾区

大家看标签时容易只盯零食，其实这些才是隐形钠来源：<strong>挂面、面包、沙拉酱、火锅底料、酱腌菜、速冻食品、卤味</strong>。

### 7. 最后看保质期和储存条件

需要冷藏却常温摆放的，直接放回去。

## 健康原理

- 标签是<strong>唯一能在货架前拿到的客观信息</strong>，广告词不是。
- 钠摄入与血压的关系证据充分，而包装食品是容易被忽略的钠来源——很多人以为自己"吃得不咸"，其实钠主要来自加工食品。
- 反式脂肪对心血管的危害证据充分，因此法规要求标注；但允许「0」的阈值（≤0.3 g/100 g），所以<strong>配料表比营养成分表更早暴露问题</strong>。
- 游离糖建议控制在总能量的 10% 以内、最好 5% 以内（WHO）。糖浆类配料是主要的隐形来源。
- 为什么标 <strong>B</strong>：「标签应该怎么标」是法规事实（证据强），但「看标签能改善健康结局」主要靠间接推论，缺少直接研究，所以整体标 B。<sup class="ref-mark">[1][2][3][4]</sup>

## 常见误区

- <strong>只看正面的大字</strong>（0 糖、高钙、非油炸），不看背面。
- <strong>用「每份」的数字横向比较不同产品</strong>：份量定义不一样，比不了。
- <strong>把「无蔗糖」当成无糖</strong>：果葡糖浆、麦芽糖浆同样要算。
- <strong>认为「非油炸」就是低脂</strong>：很多非油炸零食是烤的，但依然刷了大量油。
- <strong>认为「0 反式脂肪」等于完全没有</strong>：法规允许阈值内标 0。
- <strong>只买零食时看标签</strong>：挂面、面包、沙拉酱、火锅底料这些高钠品类更值得看。
- <strong>把「天然」「植物」当成安全保证</strong>：这些词没有法定含义。
- <strong>认为配料表越短越健康</strong>：长短不是标准，糖、油、钠的实际含量才是。

## 风险与禁忌

- 标签信息<strong>不能替代医嘱</strong>：需要限钠、限钾、限磷或计算碳水的人，请用医生或营养师给的方案，不要自己按 NRV% 折算。
- 对<strong>坚果、乳、蛋、麸质、大豆</strong>过敏的人，除了配料表还要看「可能含有微量……」的致敏提示，并且注意同一条生产线带来的交叉污染。
- 代糖对多数人是安全的，但<strong>糖醇类（木糖醇、赤藓糖醇、山梨糖醇）一次吃多可能腹泻</strong>，肠胃敏感的人留意。
- 苯丙酮尿症患者必须避开阿斯巴甜（配料表会标注）。
- 别把「低糖」「无糖」的加工食品当成可以随便吃的通行证：脂肪和热量可能仍然很高。

## 何时求助专业人士

- 有高血压、糖尿病、慢性肾病、高脂血症等诊断，需要把标签换算成个体化的摄入量。
- 拿到体检报告发现血脂、血糖、尿酸异常，不知道从哪一类食物改起。
- 严格按标签控制饮食后出现乏力、体重明显下降、月经紊乱等情况。
- 需要为孕妇、婴幼儿、老年人选择特殊食品时。
- 有进食障碍倾向（对食物极度焦虑、反复计算到影响生活）——这种情况应该减少对数字的执着，并寻求专业帮助。
