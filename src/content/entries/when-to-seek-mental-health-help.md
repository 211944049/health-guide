## 适用人群

- 不确定自己的情绪问题是「正常波动」还是「需要看病」的人。
- 长期情绪低落、焦虑但觉得「不至于去医院」的人。
- 家人出现情绪和行为变化、想帮忙但不知道怎么帮的人。
- 已经在服药或接受治疗、想知道什么时候该复诊或调整的人。

<strong>以下情况属于急症，请立即求助</strong>：有自伤或自杀念头、计划或行为；出现幻觉、妄想；意识模糊、极度兴奋或木僵；因情绪问题无法进食饮水。

## 具体做法

### 1. 三条判断标准（任一成立就值得求助）

<strong>（1）持续时间</strong>

- <strong>情绪低落、兴趣丧失持续 2 周以上</strong>：这是抑郁症诊断的时间门槛。
- <strong>过度担心、紧张、坐立不安持续数月</strong>：可能是广泛性焦虑。
- <strong>反复出现突发的强烈恐惧伴心悸、窒息感</strong>：可能是惊恐发作。

<strong>（2）功能影响</strong>

问自己：<strong>这件事有没有影响我的工作、学习、家庭或人际关系？</strong>

- 无法完成原本能完成的工作或学业。
- 回避社交、不愿出门。
- 和家人关系明显紧张。
- 无法照顾自己或孩子。

<strong>功能受影响是比「感觉多难受」更客观的指标。</strong>

<strong>（3）躯体症状</strong>

情绪问题常以身体症状出现，且反复检查查不出器质性问题：

- 持续失眠或嗜睡（见[失眠怎么办](/entry/insomnia/)）。
- 食欲和体重明显变化（一个月内变化超过 5%）。
- 持续疲劳、乏力。
- 心慌、胸闷、气短、手抖。
- 头痛、胃肠不适、慢性疼痛。

### 2. 需要立即求助的「红旗」信号

| 信号 | 处理 |
| --- | --- |
| <strong>自伤或自杀念头、计划、行为</strong> | <strong>立即</strong>：联系信任的人陪同、前往精神心理科急诊或综合医院急诊，或拨打当地心理援助热线／急救电话 |
| 出现幻觉、妄想、言语紊乱 | <strong>立即就医</strong>，可能是精神病性障碍急性期 |
| 极度兴奋、话多、几天不睡但精力旺盛 | <strong>尽快就医</strong>，可能是躁狂发作 |
| 木僵、不语不动、拒食 | <strong>急症，立即就医</strong> |
| 产后出现伤害自己或婴儿的念头 | <strong>立即求助</strong>，产后精神障碍是需要紧急处理的 |
| 大量饮酒或用药后情绪失控 | 立即就医，戒断有生命危险 |

<strong>如果你不确定对方是否有自杀风险，直接问。</strong> 大量研究显示，<strong>询问自杀念头不会「诱导」自杀</strong>，反而能打开话题、降低风险。这是家属最需要知道的一条。

### 3. 去哪里求助：按情况选渠道

| 渠道 | 适合 |
| --- | --- |
| <strong>综合医院精神心理科／精神专科医院</strong> | 需要诊断、药物治疗、或病情较重 — <strong>首选</strong> |
| 心理治疗／心理咨询 | 明确的心理困扰，需要谈话治疗 |
| 睡眠门诊 | 以失眠为主诉（见[失眠怎么办](/entry/insomnia/)） |
| 学校心理中心 | 学生，免费且便利 |
| 单位 EAP（员工帮助计划） | 职场压力、短期咨询 |
| 心理援助热线 | 急性情绪危机、需要立即有人倾听 |
| 急诊 | 自杀风险、精神病性症状、木僵拒食 |

<strong>建议优先去综合医院精神心理科</strong>，因为需要先排除躯体疾病（甲状腺功能异常、贫血、药物影响等都可以表现为情绪问题），必要时还要用药。

### 4. 第一次就诊怎么准备

- <strong>记录症状时间线</strong>：什么时候开始、什么情况下加重。
- <strong>睡眠和食欲变化</strong>：具体到「几点睡、醒几次、体重变化几斤」。
- <strong>列出正在服用的所有药物和补剂</strong>（包括酒和保健品的用量）。
- <strong>家族史</strong>：家人有没有类似情况或精神疾病史。
- <strong>想清楚你最想解决的一个问题</strong>：先说这个，能提高就诊效率。
- <strong>可以带一个信任的人同去</strong>，帮助补充信息、也能减少紧张。

### 5. 关于治疗的两点认知

- <strong>心理治疗和药物都是有效治疗</strong>，不是「一个是正规、一个是敷衍」。中度以上抑郁通常建议药物 + 心理治疗联合。
- <strong>起效需要时间</strong>：抗抑郁药通常 <strong>2–4 周</strong>才开始见效，且可能需要调整剂量或换药。<strong>不要吃两周觉得没用就自行停药</strong>。
- <strong>不要自行停药</strong>：突然停用可能出现撤药反应和复发，减药应在医生指导下进行。
- <strong>治疗周期通常较长</strong>：症状缓解后往往还需要维持治疗一段时间，以降低复发风险。这是治疗的一部分，不是「依赖药物」。

## 健康原理

- <strong>为什么早期干预重要</strong>：精神障碍有「kindling（点燃）」现象——发作次数越多、间隔越短、越容易复发，治疗难度也越大。<strong>早期、足量、足疗程治疗能显著改善长期预后</strong>，这与很多慢性病同理。
- <strong>为什么功能影响比主观痛苦更可靠</strong>：主观感受个体差异大、容易受性格和表达习惯影响；而<strong>功能受损是可观察、可比较的客观指标</strong>，也是临床评估的核心维度之一。
- <strong>为什么会以躯体症状表现</strong>：抑郁和焦虑通过自主神经和 HPA 轴影响心率、胃肠蠕动、肌张力和睡眠，因此常表现为心慌、胸闷、胃肠不适和疼痛。这也是很多患者先去心内科、消化科的原因——<strong>反复检查无异常时，应考虑情绪因素</strong>。
- <strong>自杀风险为什么要直接询问</strong>：自杀念头常伴随强烈的羞耻和孤独感，主动询问能传递「这件事可以说」的信号。研究一致显示询问不会增加风险，反而有助于识别高危个体。
- <strong>为什么标 B</strong>：抑郁症、焦虑症的诊断标准和治疗有效性有大量证据支持（这部分接近 A）；但「求助的最佳时机」这类操作性建议缺少对照研究，且不同文化背景下就诊门槛差异很大。综合给出 B。<sup class="ref-mark">[1][2][3][4]</sup>

## 常见误区

- <strong>心理问题不是病，靠意志力就能好</strong>：抑郁和焦虑是有明确神经生物学基础的疾病，<strong>意志力不能替代治疗</strong>。
- <strong>去精神科会被贴标签、影响前途</strong>：精神心理科的诊疗信息受隐私保护；<strong>不治疗对工作和生活的影响远大于就诊</strong>。
- <strong>看心理医生就是聊天、没用</strong>：规范化心理治疗（如 CBT、IPT）有大量随机对照试验支持，不是普通聊天。
- <strong>吃药会成瘾、会变傻</strong>：抗抑郁药不属于成瘾性药物；「变傻」的观感多来自疾病本身的认知症状，治疗后会改善。
- <strong>症状好了就可以立刻停药</strong>：自行停药复发风险明显升高，需在医生指导下逐步减量。
- <strong>问别人有没有自杀念头会「提醒」他</strong>：研究明确否定这一点，<strong>直接询问是安全的、也是推荐的</strong>。
- <strong>孩子情绪问题是「叛逆」「矫情」</strong>：青少年抑郁常表现为易激惹、成绩下降、拒绝上学，容易被误读，<strong>需要专业评估</strong>。
- <strong>老年人情绪低落是「正常老化」</strong>：老年抑郁常被忽略或表现为躯体不适和认知下降，是可治疗的。
- <strong>产后情绪不好是「矫情」</strong>：产后抑郁常见且有有效治疗；产后精神障碍（伴幻觉妄想）是需要紧急处理的情况。
- <strong>熬过去就好了</strong>：部分轻症可以自行缓解，但<strong>中重度不会「熬过去」</strong>，拖延只会加重并可能慢性化。

## 风险与禁忌

- <strong>有自伤或自杀念头、计划或行为</strong>：<strong>立即求助</strong>，不要独处、不要保留自伤工具（药物、利器），请家人陪同就医。
- <strong>不要自行停用精神科药物</strong>：可能出现撤药反应、反跳和复发；调整需医生指导。
- <strong>不要用酒精或镇静药物自我「治疗」</strong>：会加重抑郁、影响睡眠，并有依赖和过量风险（见[酒精能不能碰](/entry/alcohol/)）。
- <strong>不要只做心理测评量表就自我诊断</strong>：量表是筛查工具，不能替代临床诊断。
- <strong>就诊前要排除躯体疾病</strong>：甲状腺功能异常、贫血、维生素 B12 缺乏、某些药物（如激素、部分降压药）都可引起情绪症状，需要检查。
- <strong>孕期与哺乳期用药</strong>：需要产科与精神科共同评估，<strong>不要自行停药</strong>（停药复发的风险可能更大）。
- <strong>青少年</strong>：涉及自伤、拒学、进食障碍时应尽快就诊；家长不要用惩罚或说教应对。
- <strong>老年人</strong>：注意药物相互作用和跌倒风险，用药调整需谨慎。
- <strong>危机期间的安全措施</strong>：移除家中危险物品、建立紧急联系人清单、把心理援助热线存进手机。
- <strong>不要用「你就是想太多」回应求助者</strong>：这会增加羞耻感并降低求助意愿。

## 何时求助专业人士

<strong>以下情况请尽快就诊（精神心理科优先）：</strong>

- 情绪低落、兴趣丧失<strong>持续 2 周以上</strong>。
- 过度担心、紧张、坐立不安<strong>持续数月</strong>，或反复惊恐发作。
- 已经<strong>影响工作、学习、家庭或人际功能</strong>。
- 持续失眠、食欲体重明显变化、查不出原因的躯体症状。
- 产后情绪问题、伤害自己或婴儿的念头。
- 青少年情绪行为明显改变、成绩下降、拒绝上学。
- 老年人出现情绪低落、兴趣减退、认知下降或躯体不适反复就诊无果。
- 有精神疾病家族史且出现类似症状。

<strong>以下情况请立即求助（急诊或拨打急救电话／心理援助热线）：</strong>

- 有自伤或自杀念头、计划或行为。
- 出现幻觉、妄想、言语紊乱。
- 躁狂表现：极度兴奋、话多、几乎不睡但精力旺盛。
- 木僵、不语不动、拒食。
- 意识模糊、严重酗酒或药物中毒表现。
