## 适用人群

- <strong>慢性疼痛</strong>：腰痛、颈痛、膝骨关节炎、肩痛持续 <strong>3 个月以上</strong>的人
- <strong>头痛</strong>：偏头痛（用于预防，减少发作次数）或紧张型头痛
- <strong>药物效果不理想</strong>，或不想长期服用止痛药的人
- 已经明确诊断、做过必要检查的人（<strong>针灸不负责找病因</strong>）

<strong>不适合把针灸当首选的情况</strong>：突发剧烈疼痛、伴随发热或体重下降、夜间痛醒、下肢无力或大小便异常——这些要先看医生查原因。

## 具体做法

| 项目 | 建议 |
| --- | --- |
| 疗程 | 通常 <strong>每周 1–2 次</strong>，连续 <strong>4–8 周</strong>再看效果；不是扎一次就完 |
| 判断有效 | 疼痛评分下降、止痛药用量减少、活动能力改善——<strong>至少看 4 周</strong> |
| 判断无效 | 连续 <strong>6–8 次</strong>没有可察觉改善，就没必要继续 |
| 针具 | 必须是<strong>一次性无菌针</strong>，拆包装在你面前 |
| 操作者 | 有执业资质的医疗机构；不要在美容院、按摩店做"针灸" |
| 如实告知 | 正在吃的所有药（尤其是抗凝药）、是否怀孕、有无心脏起搏器 |

<strong>电针</strong>（接电流的那种）和普通针刺效果相近，但对<strong>装心脏起搏器的人禁用</strong>。

## 健康原理

针灸的止痛效果在<strong>慢性疼痛</strong>上有比较一致的证据，机制上可能同时包含几层：

1. <strong>局部与中枢的疼痛调制</strong>——针刺刺激可以激活下行抑制通路，这在动物和人体实验里都观察到过。
2. <strong>预期与注意力效应</strong>——这一点必须承认：<strong>扎在非穴位的"假针灸"也有相当一部分效果</strong>，两者的差距通常小于"针灸 vs 不治疗"的差距。所以止痛效果里有一部分不是针刺特有的。
3. <strong>就诊过程本身</strong>——一次 30–60 分钟的一对一关注、躺下休息，对慢性疼痛患者本身就有帮助。

<strong>为什么仍算 B 级而不是 C</strong>：因为方向一致、可重复，且多国指南把它列为可选方案。<strong>为什么不是 A</strong>：因为效应量中等偏小、假针灸对照下优势有限、且研究质量参差。

> 一个常被忽略的事实：<strong>承认"部分效果来自安慰剂"不等于说它没用</strong>。慢性疼痛的安慰剂效应是真实且可测量的，患者感受到的缓解也是真实的。问题只在于<strong>不要把它当成能改变病程的治疗</strong>。

## 常见误区

- <strong>"针灸能治百病"</strong> —— 证据主要集中在<strong>疼痛</strong>和<strong>化疗后恶心呕吐</strong>等少数领域。对感染、肿瘤、代谢病没有治疗作用。
- <strong>"扎得越深、越疼越有效"</strong> —— 没有这回事。得气感与疗效的关系并未被证实，而深刺和强刺激恰恰是气胸等并发症的风险来源。
- <strong>"针灸可以替代检查"</strong> —— 最危险的一条。有人腰痛先扎针，几个月后才发现是别的问题。
- <strong>"中药和针灸一起上效果翻倍"</strong> —— 没有证据支持"叠加更强"，但<strong>中药带来的相互作用风险会叠加</strong>（见「中药和西药能不能一起吃」）。
- <strong>"没有副作用"</strong> —— 见下一节。

## 风险与禁忌

<strong>严重不良事件罕见，但不是零</strong>：

| 风险 | 说明 |
| --- | --- |
| <strong>气胸</strong> | 胸背部、肩部深刺可能刺破肺。这是最需要警惕的严重并发症，规范操作可避免 |
| <strong>感染</strong> | 复用针、消毒不严可传播乙肝、丙肝等；<strong>必须一次性无菌针</strong> |
| <strong>出血与血肿</strong> | 服用<strong>抗凝药或抗血小板药</strong>（华法林、阿司匹林、氯吡格雷等）的人风险明显升高 |
| <strong>晕针</strong> | 空腹、疲劳、紧张时容易发生；应躺着做，不要空腹 |
| <strong>断针、滞针</strong> | 与针具质量和操作有关 |
| <strong>电针</strong> | <strong>心脏起搏器或植入式除颤器者禁用</strong> |

<strong>需要先问医生再决定的情况</strong>：

- 正在用抗凝药或抗血小板药
- 怀孕（部分穴位被认为应避免，但证据有限——<strong>如实告知，由操作者判断</strong>）
- 有出血性疾病、血小板减少
- 有心脏起搏器（电针禁用）
- 扎针部位有感染、溃疡、瘢痕
- 免疫功能严重低下

## 何时求助专业人士

<strong>针灸不能替代这些情况下的就医</strong>：

- 疼痛<strong>突然加重</strong>、夜间痛醒、休息不缓解
- 伴随<strong>发热、体重下降、盗汗</strong>
- <strong>下肢麻木无力、大小便失禁或困难</strong>（可能是马尾综合征，<strong>急诊</strong>）
- 胸痛、呼吸困难、腹痛剧烈
- 针刺后出现<strong>持续加重的胸痛或呼吸困难</strong>——立即急诊（警惕气胸）

<strong>先确诊、再考虑针灸</strong>。针灸处理的是"痛"，不是"为什么痛"。
