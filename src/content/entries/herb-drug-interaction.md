## 适用人群

- 正在<strong>同时服用中药（汤剂、中成药、颗粒剂）和西药</strong>的人
- 长期服用<strong>华法林、阿司匹林、氯吡格雷</strong>等抗凝/抗血小板药的人
- 长期服用<strong>降压药、降糖药、抗癫痫药、免疫抑制剂</strong>的人
- 帮<strong>老人</strong>同时买中成药和西药的人
- 认为"中药是天然的所以没相互作用"的人

## 具体做法

<strong>只有一件事必须做：把你在用的所有东西告诉医生和药师。</strong>

| 做什么 | 怎么做 |
| --- | --- |
| 列清单 | 把<strong>所有</strong>在用的东西写下来：西药、中药、中成药、保健品、代茶饮 |
| 带上实物 | 就诊时<strong>带着药盒或说明书</strong>——比口头描述准确得多 |
| 主动说 | 不要等医生问。<strong>很多人不把中药算作"在吃药"</strong>，这是最容易漏的 |
| 问药师 | 药店的执业药师可以做相互作用初筛，<strong>免费且比网上查可靠</strong> |
| 记录反应 | 新加一种药后出现异常（出血、头晕、乏力、黄疸、尿色变深），<strong>立刻停药并就医</strong> |
| 复查指标 | 长期用中药的人，<strong>定期查肝肾功能</strong> |

<strong>不要做的事</strong>：

- <strong>不要</strong>为了"保险"自行把中西药隔开半小时就以为没事了（理由见下）
- <strong>不要</strong>同时吃多种成分不明、来源不明的"偏方""保健粉"
- <strong>不要</strong>因为"吃了很久都没事"就认为安全——很多相互作用是累积性的

## 健康原理

药物相互作用发生在四个环节，而<strong>中药在每一个环节都可能插一脚</strong>：

| 环节 | 中药怎么影响 | 例子 |
| --- | --- | --- |
| <strong>吸收</strong> | 改变胃肠动力或形成络合物 | 含金属离子的中药影响某些抗生素吸收 |
| <strong>代谢（最主要）</strong> | 影响肝药酶 CYP450 的活性 | <strong>贯叶连翘</strong>诱导 CYP3A4，使多种药物浓度大幅下降 |
| <strong>转运</strong> | 影响 P-糖蛋白等外排泵 | 改变药物在肠道的吸收量 |
| <strong>效应</strong> | 药理作用叠加或对抗 | 甘草的升压作用对抗降压药 |

<strong>为什么"隔开半小时"挡不住</strong>：代谢环节的相互作用发生在药物<strong>已经进入血液、到达肝脏之后</strong>，跟两种药在胃里见不见面没关系。隔开服用能减少的是<strong>吸收阶段的物理化学结合</strong>——那只是四类相互作用里的一小类，而且主要影响的是含钙、铁、铝的制剂。

<strong>为什么中药也会伤肝</strong>：肝脏要代谢中药里的各种成分。某些成分（如吡咯里西啶类生物碱、部分蒽醌类）有明确的肝毒性。<strong>"天然"与"安全"是两个不同的概念</strong>——毒蘑菇也是天然的。

> <strong>一个必须知道的历史教训</strong>：含<strong>马兜铃酸</strong>的药材（如关木通、广防己）曾导致大量<strong>不可逆的肾衰竭</strong>（"中草药肾病"），并已被证实与泌尿系统肿瘤相关。中国已于 <strong>2003 年起取消关木通的药用标准</strong>。这说明问题不在"中药"这个大类，而在<strong>具体成分必须逐个查清、并且监管必须跟上</strong>。

## 常见误区

- <strong>"中西药隔开半小时就没事"</strong> —— <strong>没有可靠证据支持</strong>，而且它挡不住最要紧的代谢类相互作用。<strong>真正有用的做法是如实告知医生，而不是调整服药时间。</strong>
- <strong>"中药是天然的，所以没有副作用"</strong> —— 天然物同样有药理活性，有活性就有副作用。而且中药材的种植、炮制、储存环节都可能引入重金属、农药残留、霉菌毒素。
- <strong>"中成药是药厂生产的，更安全"</strong> —— 中成药的风险主要来自<strong>成分与西药的相互作用</strong>和<strong>说明书里"尚不明确"的禁忌项</strong>，与是否工业化生产关系不大。
- <strong>"吃了很久都没事，所以没关系"</strong> —— 有些相互作用（如抗凝药叠加出血风险）平时没感觉，<strong>一旦出血就是急症</strong>。
- <strong>"补药不算是药"</strong> —— 人参、甘草、当归、银杏都有明确的相互作用记录。<strong>补药是最容易被漏报的一类。</strong>

## 风险与禁忌

<strong>以下组合需要特别警惕</strong>（不是绝对禁用，而是<strong>必须在医生监测下使用</strong>）：

| 中药 / 成分 | 与什么相互作用 | 后果 |
| --- | --- | --- |
| <strong>丹参、当归、川芎、银杏</strong> | 华法林、阿司匹林、氯吡格雷 | <strong>出血风险明显升高</strong>（INR 升高） |
| <strong>贯叶连翘（圣约翰草）</strong> | 避孕药、抗排异药、抗癫痫药、抗抑郁药、部分抗肿瘤药 | <strong>药效大幅下降</strong>，可致避孕失败、排异反应、癫痫失控 |
| <strong>甘草（大量或长期）</strong> | 降压药、利尿剂、地高辛 | 血压升高、<strong>低血钾</strong>、心律失常 |
| <strong>麻黄</strong> | 降压药、单胺氧化酶抑制剂 | 血压骤升、心率加快 |
| <strong>人参</strong> | 华法林、降糖药 | 抗凝效果减弱、血糖波动 |
| <strong>大黄、番泻叶（长期）</strong> | 利尿剂、地高辛 | 低血钾、电解质紊乱 |

<strong>需要特别小心的人群</strong>：

- <strong>孕妇与哺乳期</strong>：多数中药缺乏安全性数据。<strong>不要自行服用任何中药。</strong>
- <strong>肝肾功能不全者</strong>：代谢和排泄能力下降，风险成倍上升
- <strong>儿童与老人</strong>：剂量与耐受性与成年人不同
- <strong>术前</strong>：多数中药应在<strong>手术前 1–2 周停用</strong>，必须主动告诉麻醉医生
- <strong>正在服用抗凝药的人</strong>：这是风险最高的一组，任何中药都要先问医生

## 何时求助专业人士

<strong>出现以下情况立即就医</strong>：

- <strong>异常出血</strong>：牙龈出血、鼻血不止、皮肤大片瘀斑、黑便、血尿
- <strong>黄疸</strong>：皮肤或眼白发黄、尿色像浓茶、右上腹不适、极度乏力（<strong>药物性肝损伤的典型表现</strong>）
- <strong>尿量明显减少、下肢水肿</strong>
- <strong>血压骤升伴剧烈头痛、心悸</strong>
- 新加中药后出现<strong>皮疹、发热、呼吸困难</strong>

<strong>就诊前做一件事</strong>：把<strong>所有在用的东西</strong>（西药、中药、中成药、保健品）连包装一起带去。<strong>很多人不把中药算作"在吃药"，这是最容易造成漏诊的一环。</strong>
