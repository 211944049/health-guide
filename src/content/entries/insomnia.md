## 适用人群

- 躺下超过 30 分钟还睡不着、每周发生 3 次以上、持续 3 个月以上的人。
- 夜里频繁醒、醒了很难再睡的人。
- 长期靠安眠药或酒精助眠的人。
- 睡眠环境本身有问题的人，可先看[睡眠环境怎么调](/entry/sleep-environment/)。

<strong>先排除这些</strong>：睡眠呼吸暂停（打鼾伴呼吸暂停、白天极度嗜睡）、不宁腿综合征、甲状腺功能异常、抑郁症、慢性疼痛——这些是「继发性失眠」，治失眠之前要先治原发病。

## 具体做法

### 1. 三条核心行为（CBT-I 的刺激控制）

这三条是 CBT-I 里效果最确定的部分，<strong>做对了比吃什么都有用</strong>：

1. <strong>固定起床时间</strong>：每天同一时间起，包括周末。起床时间锚定了生物钟，比纠结几点睡有用得多。
2. <strong>躺下约 20 分钟睡不着就起来</strong>：离开卧室，做点单调安静的事（读纸质书、听舒缓音频），有困意再回床。<strong>不要在床上躺着焦虑</strong>——躺着睡不着会让大脑把「床」和「清醒焦虑」绑在一起。
3. <strong>床只用于睡觉</strong>：不刷手机、不看剧、不办公、不吃饭。让「上床」这个动作重新只意味着睡觉。

### 2. 睡眠限制：听着反直觉，但有效

记录一周睡眠日记，算出你实际睡着的平均时长（比如 5.5 小时），然后<strong>先把卧床时间压缩到这个时长加 30 分钟</strong>，并保持固定起床时间。等这一段时间里能睡满 85% 以上，再每周提前 15–20 分钟上床。

原理是制造轻度的睡眠压力，让「上床就能睡着」重新成立。<strong>白天不要补觉</strong>，否则这条会失效。

### 3. 记录睡眠日记

每天记：上床时间、估计入睡耗时、夜间醒来次数和时长、起床时间、白天精神状态、当天咖啡因/酒精/运动情况。记两周就能看出规律，也是就医时医生最需要的信息。

### 4. 把加重因素一个个拆掉

| 因素 | 改法 |
| --- | --- |
| 下午的咖啡因 | 下午 2 点后不喝咖啡、浓茶（见[咖啡怎么喝不伤胃](/entry/coffee/)） |
| 睡前饮酒 | 酒精让人<strong>更快入睡但后半夜易醒、睡眠变浅</strong>，必须停 |
| 午睡过长 | 控制在 20–30 分钟且不晚于下午 3 点 |
| 睡前刷手机 | 不是「蓝光」的问题，而是内容让大脑兴奋、以及挤占睡眠时间 |
| 睡前大量进食、剧烈运动 | 至少间隔 2–3 小时 |
| 白天活动量不足 | 规律的有氧运动能改善睡眠质量，但别在睡前 3 小时内做 |

### 5. 关于安眠药

- <strong>短期、按医嘱使用</strong>是合理的，尤其在急性应激期。
- <strong>不要自行长期服用</strong>：多数安眠药有耐受和依赖风险，突然停药会反跳性失眠。
- <strong>CBT-I 的长期效果优于药物</strong>，这是指南把它放在一线的原因。现在有多种线上 CBT-I 程序可用，也可找睡眠门诊。

## 健康原理

- <strong>失眠为什么会「维持」下去</strong>：急性失眠往往由应激触发，但之后是<strong>行为和学习</strong>让它变成慢性的——因为害怕睡不着而提前上床、躺床上焦虑、白天补觉、靠酒助眠，这些都在削弱「床 = 睡眠」的联结，并打乱生物钟。CBT-I 针对的正是这个维持机制。
- <strong>为什么固定起床时间比固定入睡时间重要</strong>：入睡时刻受很多因素影响、无法直接控制；而起床时间决定了当晚的睡眠压力和生物钟相位，是<strong>你能直接控制的杠杆</strong>。
- <strong>刺激控制的机制</strong>：条件反射。反复在「清醒 + 焦虑」状态下待在床上，会让床变成焦虑的触发线索；通过限制卧床并只在困时上床，重新建立「床 = 睡眠」的联结。
- <strong>睡眠限制的机制</strong>：通过轻度睡眠剥夺增加腺苷积累（睡眠压力），让入睡变快、睡眠变深，再用逐步延长的方式把总睡眠时间补回来。
- <strong>为什么标 A</strong>：CBT-I 有大量随机对照试验支持，且被 ACP、ESRS、中国指南等主要指南一致推荐为<strong>一线治疗</strong>，长期效果优于药物。这是本站里证据最扎实的条目之一。<sup class="ref-mark">[1][2][3][4]</sup>

## 常见误区

- <strong>失眠就该吃安眠药</strong>：指南一线是 CBT-I。药物适合短期过渡，不适合作为长期唯一方案。
- <strong>睡前喝点酒好睡</strong>：酒精缩短入睡时间，但会<strong>增加后半夜觉醒、减少深睡和快速眼动睡眠</strong>，长期加重失眠。
- <strong>躺床上闭眼休息也是休息</strong>：躺着清醒且焦虑，会强化失眠的维持机制。真正有效的做法是起来，困了再回床。
- <strong>早点上床就能多睡</strong>：提前上床通常只是延长了「躺着睡不着」的时间，反而削弱睡眠压力。<strong>睡眠限制恰恰要求你更晚上床。</strong>
- <strong>周末补觉能还债</strong>：周末大幅晚起会打乱生物钟，让周一更难睡，形成「社会时差」。
- <strong>一定要睡满 8 小时</strong>：成人需要量因人而异，常见范围 7–9 小时。<strong>判断标准是白天是否功能正常</strong>，不是数字。
- <strong>打鼾是睡得香</strong>：响亮打鼾伴呼吸暂停、白天嗜睡，可能是睡眠呼吸暂停，需要就医，不是「睡得沉」。
- <strong>褪黑素能治失眠</strong>：褪黑素对<strong>时差和昼夜节律紊乱</strong>更有效，对典型慢性失眠的效果有限，它不是安眠药。
- <strong>数羊有用</strong>：没有可靠证据；占用工作记忆的放松方法（如渐进式肌肉放松、意象训练）证据更好。

## 风险与禁忌

- <strong>不要自行突然停用长期安眠药</strong>：可能出现反跳性失眠和戒断反应，需在医生指导下逐步减量。
- <strong>酒精 + 安眠药（或镇静类药物）同用有呼吸抑制风险</strong>，这是真实的危险组合。
- <strong>睡眠限制期间的日间嗜睡</strong>：如果开车、操作机械，需格外小心；有癫痫、双相障碍、严重抑郁的人做睡眠限制前必须咨询医生。
- <strong>老年人</strong>：跌倒风险随夜间起夜和镇静药物升高，用药需格外谨慎。
- <strong>孕期与哺乳期</strong>：任何助眠药物都要先问产科医生。
- <strong>不要用「白天补觉」弥补夜间失眠</strong>，这会破坏 CBT-I 的效果。

## 何时求助专业人士

- <strong>失眠持续 3 个月以上、每周 3 次以上，且已影响白天工作或情绪</strong>：建议去睡眠门诊或精神心理科，接受规范的 CBT-I。
- <strong>打鼾伴呼吸暂停、白天难以抑制地嗜睡、晨起头痛</strong>：需做睡眠监测，排除睡眠呼吸暂停。
- <strong>情绪持续低落、兴趣丧失、明显焦虑</strong>：失眠与抑郁、焦虑常互相加重，需要同时评估，见精神心理科。
- <strong>腿部不适、夜间必须活动腿才能缓解</strong>：可能是<strong>不宁腿综合征</strong>，需专科评估。
- <strong>需要靠药物才能入睡、且剂量在增加</strong>：请医生重评方案，不要自行加量。
- <strong>出现自伤或自杀念头</strong>：请立即寻求专业帮助或拨打当地心理援助热线。
