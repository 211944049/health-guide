## 适用人群

- 谁适合照做：同时服用 2 种以上药物的人；在多个科室开药的人；给老人管理用药的家属；正在吃保健品或中成药的人；准备自行加用非处方药的人。
- 谁不适用：这条是<strong>用药安全常识</strong>，不能替代药师核方。<strong>已经出现疑似药物不良反应</strong>时，按「风险与禁忌」一节处理，不要留在家里研究。

## 具体做法

### 1. 先做一件事：列一张「我在吃什么」的清单

这一步是所有判断的基础，而且<strong>只有你能做到</strong>——不同医院、不同科室的信息系统往往不互通。

清单要包括：

- <strong>处方药</strong>：药名 + 剂量 + 一天几次（照着药盒抄，不要凭记忆）
- <strong>非处方药</strong>：包括偶尔吃的止痛药、感冒药、胃药
- <strong>中成药和中药饮片</strong>：这类常被漏掉，但成分复杂，相互作用风险真实存在
- <strong>保健品</strong>：维生素、钙片、鱼油、蛋白粉都算
- <strong>外用药</strong>：贴剂、含激素的药膏（也会吸收入血）

<strong>做法</strong>：把所有药装在一个袋子里，或者<strong>拍下每盒药的正面和说明书</strong>。下次看病、买药都带着。

### 2. 判断能不能一起吃，不要按「中药/西药」分类

常见的错误分类是「中药温和、西药猛」或者「都是医生开的所以不冲突」。<strong>这两种都不成立。</strong>

真正的判断依据是<strong>成分与代谢途径</strong>。你不需要自己懂药理学，但需要知道<strong>去哪里核</strong>：

| 情况 | 找谁核 |
| --- | --- |
| 新开了药，或想知道两种药能不能一起吃 | <strong>药房药师</strong>（免费、立等可取，比网上查可靠） |
| 有慢性病、在吃多种药 | 开药医生，或请医院药学门诊做一次<strong>用药梳理</strong> |
| 想加保健品 / 中成药 | 同样问药师，<strong>带上实物或照片</strong> |
| 不确定的网上信息 | 只作为提问线索，不要当作结论 |

### 3. 三种特别危险且常见的组合

这些是真实的、发生频率较高的相互作用，<strong>重点记住</strong>：

<strong>① 抗凝药 / 抗血小板药 + 止痛药</strong>

- 华法林、阿司匹林、氯吡格雷等 + 布洛芬等非甾体抗炎药 → <strong>出血风险明显上升</strong>（胃肠道出血尤其）
- 需要止痛时，<strong>首选对乙酰氨基酚</strong>（但仍要问医生），并告知你在服用抗凝药
- 参考[止痛药怎么吃才安全](/entry/painkiller-safety/)

<strong>② 多种影响血压 / 心率的药叠加</strong>

- 降压药 + 部分抗抑郁药 + 部分前列腺药 + 硝酸酯类 → 可能<strong>血压过低、头晕、跌倒</strong>
- 老年人尤其要注意，参考[家里老人怎么防跌倒](/entry/fall-prevention/)

<strong>③ 葡萄柚（西柚）汁</strong>

- 它会影响肠道和肝脏的一种代谢酶（CYP3A4），<strong>使多种药物血药浓度升高</strong>
- 涉及：部分他汀类降脂药、部分降压药、抗心律失常药、免疫抑制剂、部分镇静催眠药
- <strong>服药期间不要喝西柚汁</strong>，不确定就直接问药师
- 参考[水果怎么吃、吃多少](/entry/fruit-intake/)，那里也提到了这一条

### 4. 吃药的时间间隔能解决一部分问题

有些相互作用只能靠<strong>换药或调整剂量</strong>，但另一些可以靠<strong>错开时间</strong>减少影响：

- <strong>钙片、铁剂、含镁铝的胃药</strong>会影响部分抗生素（如喹诺酮类、四环素类）和甲状腺药的吸收 → 通常需要<strong>间隔 2–4 小时</strong>
- <strong>甲状腺药（左甲状腺素）</strong>通常要求<strong>空腹服用，服后至少 30–60 分钟再进食</strong>，且与钙铁分开
- 具体间隔<strong>看说明书或问药师</strong>，不同药的要求不一样

### 5. 养成三个习惯

- <strong>固定一家药房</strong>。药师的系统里会有你的用药记录，能主动发现冲突（在不同药房零散买药就做不到这一点）。
- <strong>每次新开药时主动说一句</strong>：「我还在吃××，能不能一起用？」——<strong>不要等医生问</strong>。
- <strong>出现新症状先想一下是不是药</strong>。皮疹、头晕、乏力、黑便、食欲改变都可能是药物反应。

## 健康原理

<strong>药物相互作用分两类，机制不同，后果也不同。</strong><sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>一类是「药效学」相互作用</strong>：两种药作用于同一生理环节，效果叠加或抵消。比如两种都降血压的药一起吃 → 血压降得过低；抗凝药 + 抗血小板药 → 凝血功能被从两个方向削弱，出血风险不是简单相加。这类相互作用<strong>与代谢无关，所以错开服用时间通常没用</strong>。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>另一类是「药动学」相互作用</strong>：一种药改变了另一种药的吸收、分布、代谢或排泄。最典型的是<strong>代谢酶抑制</strong>——肝脏的 CYP450 酶系负责代谢大量药物，某些成分（如西柚汁中的呋喃香豆素）会抑制 CYP3A4，导致原本该被代谢掉的药在体内蓄积、浓度升高。这类相互作用<strong>可能通过错开时间部分缓解</strong>（比如钙片影响抗生素吸收），但酶抑制的影响是持续的，错开时间往往没用。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>为什么不能按「中药/西药」判断。</strong> 因为决定相互作用的是<strong>具体成分和代谢途径</strong>，不是药物的来源分类。中成药里可能含有影响凝血或肝酶的成分（如某些含丹参、银杏的制剂与抗凝药同用会增加出血风险），而西药之间也可能完全互不影响。用「中药温和」这种印象做判断，会同时漏掉真实风险和制造不必要的担心。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>为什么「多个科室开药」特别危险。</strong> 医院之间、科室之间的信息系统通常不互通，每位医生看到的是自己开的那部分。<strong>患者是唯一同时掌握全部用药信息的人</strong>——这就是为什么本篇把「列清单」放在第一条。世界卫生组织把「用药核对」（medication reconciliation）列为患者安全的重点，正是针对这个结构性缺口。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>为什么药师是成本最低的核对资源。</strong> 药师受过药物相互作用的专门训练，且药房的系统会记录你的购药历史。<strong>药事咨询通常是免费且不需要挂号的</strong>——在「该问谁」这件事上，这是投入产出比最高的选择。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>证据等级为什么是 B。</strong> 主要相互作用（抗凝药 + NSAIDs 的出血风险、CYP3A4 抑制、钙铁影响吸收）都有充分的药理学研究和监管机构文件支持，各国药监部门的警示一致——这部分证据很强。但<strong>具体到某个患者用某个剂量是否会出现临床后果，个体差异很大</strong>，且大量中成药/保健品的相互作用研究仍不充分（很多只有个案报告），所以整体定在 B 级，并把重点放在「怎么去核对」而不是「背清单」。<sup class="ref-mark">[1][2][3][4][5]</sup>

## 常见误区

- <strong>误区：都是医生开的，所以一起吃没问题。</strong> 不同科室的医生可能互相不知道对方开了什么。<strong>患者要主动说。</strong>
- <strong>误区：中药温和，和西药一起吃没事。</strong> 判断依据是成分和代谢途径，不是来源。部分中成药与抗凝药同用会增加出血风险。
- <strong>误区：保健品不是药，不会有相互作用。</strong> 鱼油、银杏、维生素 K、圣约翰草等都有明确的相互作用记录。
- <strong>误区：错开半小时吃就都安全了。</strong> 错开时间只能解决<strong>吸收环节</strong>的干扰；药效叠加和酶抑制这两类，错开时间往往没用。
- <strong>误区：说明书上没写相互作用就是没有。</strong> 说明书更新滞后于研究，而且新药与老药的组合常常缺乏数据。<strong>不确定时问药师。</strong>
- <strong>误区：症状变化一定是病情，不会是药。</strong> 药物反应常表现为乏力、头晕、皮疹、食欲改变，很容易被当成"年纪大了"或"病情加重"。
- <strong>误区：葡萄柚只是水果，和药没关系。</strong> 它是<strong>影响药代动力学最典型</strong>的食物之一，涉及多类常用药。
- <strong>误区：一次漏服就补两倍。</strong> 漏服应看说明书或问医生，<strong>加倍补服可能造成过量</strong>。

## 风险与禁忌

- <strong>不要自行停用或调整长期药物</strong>（降压药、降糖药、抗凝药、激素、抗癫痫药）。突然停用可能造成危险，调整必须由医生决定。
- <strong>不要用「先吃着看看」的方式试新药组合</strong>，尤其涉及抗凝药、降糖药、抗心律失常药、免疫抑制剂时。
- <strong>服药期间不要大量饮酒</strong>：酒精与镇静催眠药、镇痛药、降糖药、部分抗生素有明确相互作用。
- <strong>不要喝西柚汁，也不要吃大量西柚</strong>（如果正在服用相关药物）；不确定时问药师。
- <strong>不要同时吃两种含相同成分的复方感冒药</strong>（常见的是对乙酰氨基酚叠加，参考[止痛药怎么吃才安全](/entry/painkiller-safety/)）。
- <strong>含圣约翰草（贯叶连翘）的制剂</strong>会诱导肝酶、降低多种药物（包括部分避孕药、抗抑郁药、抗凝药）的效果，<strong>服用前必须问医生</strong>。
- <strong>老年人多重用药（5 种以上）应定期做用药梳理</strong>，很多药物可以减量或停用，收益大于风险。
- <strong>出现以下情况立即就医</strong>：<strong>黑便或呕血、不明原因的大片淤青、严重头晕或晕厥、呼吸困难、面部或喉部肿胀、意识改变</strong>。
- 就医时<strong>带上所有正在用的药</strong>（实物或照片），并告知医生你在用一种以上的药。

## 何时求助专业人士

出现以下情况先看医生，不要只靠本文：

- <strong>服用新药后出现皮疹、呼吸困难、面部或喉部肿胀</strong> —— 可能是严重过敏反应，<strong>立即就医</strong>。
- <strong>出现黑便、呕血、异常淤青或出血不止</strong> —— 立即就医（尤其正在服用抗凝药或止痛药）。
- <strong>严重头晕、站立时眼前发黑、晕厥</strong> —— 可能与降压药叠加或低血压有关，尽快就医。
- <strong>新出现的持续乏力、食欲下降、黄疸、尿色变深</strong> —— 可能是药物性肝损伤，尽快就诊并带上用药清单。
- <strong>同时在吃 5 种以上药物</strong> —— 建议主动要求一次用药梳理（医院药学门诊或药师咨询）。
- <strong>正在服用抗凝药、抗癫痫药、免疫抑制剂、甲状腺药、强心苷类</strong> —— 任何新增药物（含非处方药和保健品）都应先问医生或药师。
- <strong>孕期、哺乳期、肝肾功能不全的人</strong> —— 用药相互作用风险更高，所有新增用药都需专业评估。
- <strong>不确定某两种药能不能一起吃</strong> —— <strong>去药房问药师</strong>，这是免费的，而且比网上查可靠得多。
