## 适用人群

- 谁适合照做：怕冷的人；冬季户外通勤者（尤其骑车、等车）；老年人；需要长时间在户外工作的人；有心脑血管基础病的人。
- 谁不适用：这条没有不适用的人。<strong>有雷诺现象、末梢循环障碍或糖尿病周围神经病变的人</strong>更需要严格保暖，但要注意<strong>不能用热水袋、暖宝宝直接长时间接触皮肤</strong>（见「风险与禁忌」）。

## 具体做法

### 1. 先护住三个部位：颈、头、手

人体在寒冷中散热最多的部位是<strong>头颈部</strong>（面积相对大、血流丰富、且常常暴露），这也是为什么围巾和帽子的体感收益最明显。

- <strong>围巾</strong>：护住颈部，同时能挡住领口进风。<strong>材质首选羊毛、羊绒或抓绒</strong>，它们靠固定静止空气层保暖；化纤针织次之。
- <strong>帽子</strong>：要<strong>盖住耳朵</strong>（或另配耳罩），因为耳朵是最容易冻伤的部位之一。针织帽贴合度比宽松款式好。
- <strong>手套</strong>：分指手套灵活、连指（并指）手套更暖。<strong>骑行或长时间户外选连指或加绒款</strong>。

### 2. 围巾的几个实用细节

- <strong>不要过长、不要垂到车轮或机器附近</strong>——骑车、开电动车、操作机械时有被卷入的危险。<strong>这是最需要注意的安全问题。</strong>
- <strong>不要只图宽松好看</strong>：领口松会灌风。可以选能塞进外套领口内的长度。
- <strong>围巾不要蒙住口鼻长时间呼吸</strong>：呼出的水汽会让围巾潮湿，反而降低保暖性；对呼吸系统疾病患者也可能造成不适。雾霾天如需防护应用口罩而不是围巾。
- <strong>清洗</strong>：围巾直接接触颈部和面部，皮脂和汗水会积累，建议 1–2 周清洗一次，参考[衣服多久洗一次](/entry/laundry-frequency/)。

### 3. 帽子与手套的材质选择

| 需求 | 推荐 |
| --- | --- |
| 日常通勤 | 羊毛/羊绒针织帽、抓绒手套 |
| 骑车、风大 | <strong>防风外壳 + 抓绒内里</strong>（单独针织挡不住风） |
| 极寒或长时间户外 | 加厚连指手套、带护耳的帽子 |
| 手部易出汗 | 内层薄手套 + 外层防风手套，可分层调整 |
| 触屏需求 | 选带触屏指尖的款式，或准备薄内衬手套 |

<strong>「防风」比「厚」更重要一点。</strong> 风会持续带走体表的暖空气层，所以骑行和风大时，<strong>防风外层</strong>的作用往往大于单纯加厚。

### 4. 老人和特殊人群

- <strong>老年人</strong>：体温调节能力下降，对寒冷的感觉可能不敏感，<strong>容易在没觉得冷的时候就已经受凉</strong>。建议出门前就穿戴好，而不是"觉得冷了再加"。
- <strong>心脑血管病人</strong>：<strong>寒冷会使血管收缩、血压升高</strong>，是冬季心脑血管事件高发的机制之一。出门注意保暖，尤其避免从温暖的室内突然进入寒冷环境。
- <strong>骑行者</strong>：除了围巾安全，还要注意<strong>手指和脚趾最先失去知觉</strong>——手部保暖不足会影响刹车操作，这是安全风险。
- <strong>儿童</strong>：活动量大、易出汗，建议<strong>分层穿</strong>，方便加减；注意帽子手套容易丢，可备一套替换。

### 5. 分层比加厚更有效

冷天的最优结构是三层：

1. <strong>内层（贴身）</strong>：排汗（化纤或美利奴羊毛），保持皮肤干爽。
2. <strong>中层</strong>：保温（抓绒、羊毛、羽绒）。
3. <strong>外层</strong>：防风防水。

<strong>参考[保暖怎么穿](/entry/warmth/)的完整做法。</strong> 围巾帽子手套是这套结构在"末端"的补充。

## 健康原理

<strong>保暖的本质是「留住身体产生的热量」。</strong> 人体不断产热，也通过传导、对流、辐射和蒸发散热。衣物的作用不是"发热"，而是<strong>固定一层静止空气</strong>——空气是热的不良导体，这层空气就是保温层。所以保暖效果取决于：<strong>纤维能固定多少空气（蓬松度）、以及这层空气会不会被风带走（防风性）</strong>。这解释了为什么"防风"和"蓬松"比单纯"厚"更重要。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>为什么头颈部值得优先保护。</strong> 头颈部皮肤薄、血流丰富、表面积占比不小，而且在日常生活中常常是唯一暴露的部位。寒冷环境中，如果身体其他部分被包裹而头颈暴露，散热损失会很明显。所以围巾和帽子是<strong>收益成本比最高</strong>的两件装备。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>为什么手和脚容易先变冷。</strong> 寒冷时身体会通过<strong>血管收缩</strong>减少末梢血流，把血液集中到核心以保护重要器官。这是正常的体温调节反应，但代价是手指脚趾温度下降快、也更容易冻伤。所以末梢的保暖需要<strong>主动加强</strong>（手套、厚袜），而不是靠"身体自己会暖过来"。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>为什么寒冷会升高心血管风险。</strong> 冷刺激引起外周血管收缩，<strong>血压升高、心率加快、心脏负荷增加</strong>；同时血液黏稠度可能上升。这些机制共同解释了冬季心脑血管事件（心肌梗死、脑卒中）发病率上升的现象。<strong>所以对已有心血管病的人，保暖不只是舒适问题，而是风险管理。</strong> 从温暖室内到寒冷室外的<strong>温差骤变</strong>尤其需要缓冲。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>为什么老年人风险更高。</strong> 随年龄增长，体温调节反应（如寒战产热、血管收缩）效率下降，对寒冷的感知也可能减弱，导致<strong>在主观不觉得冷的情况下核心体温已在下降</strong>。这是老年人冬季低体温症发生率较高的原因，也是"提前穿戴、不要靠感觉"这一建议的依据。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>证据等级为什么是 C。</strong> 衣物保温的物理机制（静止空气层、防风）是明确的；寒冷与心血管事件、低体温风险升高的关联也有较一致的流行病学证据。但<strong>"围巾帽子手套的具体材质和款式对健康结局的影响"几乎没有直接的临床研究</strong>——本篇的建议主要由保温和生理机制推导而来，属于<strong>机制合理但缺乏专门研究</strong>，所以定在 C 级。<sup class="ref-mark">[1][2][3][4][5]</sup>

## 常见误区

- <strong>误区：穿得越厚越暖。</strong> 厚度只是手段之一；<strong>防风</strong>和<strong>分层</strong>往往更有效。穿得过厚还会出汗，湿了以后更冷。
- <strong>误区：只有老人才需要戴帽子。</strong> 任何人在寒冷户外都会通过头颈散热，帽子对所有人都有用。
- <strong>误区：围巾越长越好、越飘逸越好看。</strong> 骑车或操作机械时，<strong>长围巾有卷入危险</strong>。安全优先。
- <strong>误区：用围巾蒙住口鼻可以防雾霾。</strong> 围巾对细颗粒物几乎没有过滤作用，还可能因潮湿带来不适。需要防护应用口罩。
- <strong>误区：喝酒能暖身。</strong> 酒精使皮肤血管扩张，<strong>会让人感觉暖但同时加快散热</strong>，在寒冷环境中反而增加低体温风险。
- <strong>误区：手冷就搓一搓、哈口气就好。</strong> 这些只能暂时缓解。持续暴露会加重末梢缺血，应回到温暖环境或加手套。
- <strong>误区：暖宝宝贴着皮肤用更有效。</strong> 直接长时间接触皮肤可造成<strong>低温烫伤</strong>，必须隔一层衣物。
- <strong>误区：冻伤后马上用热水泡。</strong> 快速复温的方式不当会加重损伤，应使用温水（约 37–40 ℃）并尽快就医。<!-- fact:bath-water-temp -->

## 风险与禁忌

- <strong>骑车、开电动车或操作机械时，不要让围巾过长、不要让其垂落</strong>——卷入风险是真实且严重的事故原因。
- <strong>不要用热水袋、暖宝宝、电热毯直接长时间接触皮肤</strong>，尤其老人、糖尿病周围神经病变、感觉减退的人，容易发生<strong>低温烫伤</strong>且不易察觉。
- <strong>不要用酒精"御寒"</strong>，它会加快散热并影响判断力。
- <strong>冻伤部位不要摩擦、不要用雪搓、不要用热水或火烤</strong>——应移到温暖处，用温水缓慢复温并尽快就医。
- <strong>有心脑血管疾病的人</strong>应避免突然的冷热交替（如从暖气房直接冲到室外运动），出门前先在门厅适应一下。
- <strong>有雷诺现象、糖尿病、末梢循环障碍的人</strong>要格外注意手指脚趾的颜色和感觉变化，出现持续发白、发紫、麻木应尽快处理。
- <strong>婴幼儿</strong>不宜用长围巾（缠绕窒息风险），可选护颈套或高领衣物；睡眠时不要用围巾或帽子（有过热和窒息风险）。
- <strong>感冒或发热时</strong>不要用"捂汗"的方式加厚衣物，可能导致体温过高，尤其儿童。
- <strong>感觉不到冷不等于不需要保暖</strong>（老年人、糖尿病神经病变患者尤其如此），应按气温而非感觉安排穿戴。

## 何时求助专业人士

出现以下情况先看医生，不要只靠本文：

- <strong>手指、脚趾、耳朵持续发白、发紫、变硬、失去感觉</strong>——可能是冻伤，需尽快就医，不要自行用热水处理。
- <strong>皮肤出现苍白、蜡样、水疱或变黑</strong>——严重冻伤表现，<strong>立即就医</strong>。
- <strong>长时间暴露于寒冷后出现意识模糊、嗜睡、言语不清、寒战停止</strong>——可能是<strong>低体温症</strong>，<strong>立即呼叫急救</strong>并缓慢复温（这两点很重要：不要快速加热，也不要让患者继续暴露）。
- <strong>寒冷环境中出现胸痛、胸闷、心悸、气短</strong>——可能是心血管事件，立即就医，参考[什么时候该看医生](/entry/when-to-see-a-doctor/)。
- <strong>手指遇冷后反复出现发白→发紫→发红的变色过程</strong>（雷诺现象）——需要评估是否存在结缔组织病等问题。
- <strong>有糖尿病、周围血管病、心脑血管病</strong>并需要长时间户外活动——建议提前与医生讨论防护和用药安排。
- <strong>老年人冬季出现食欲下降、活动减少、明显乏力</strong>——可能是慢性受凉或低体温的表现，需要评估，不要简单归因于"年纪大了"。
