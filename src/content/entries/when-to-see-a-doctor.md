## 适用人群

- 不确定某个症状要不要去医院的人。
- 家里有老人、需要判断是否送医的照顾者。
- 习惯「忍一忍就过去」、容易延误就诊的人。
- 想了解急救常识的普通人。

<strong>这一条的目的不是让你自我诊断</strong>，而是帮你判断<strong>是否需要专业评估，以及有多紧急</strong>。任何拿不准的情况，<strong>联系医生或去医院都比在网上查更安全</strong>。

## 具体做法

### 1. 立刻拨打急救电话（120）的情况

<strong>出现以下任一情况，不要自己开车、不要等天亮、不要先观察：</strong>

| 情况 | 具体表现 |
| --- | --- |
| <strong>疑似心梗</strong> | 胸骨后压榨性疼痛或胸闷，<strong>持续超过 15 分钟不缓解</strong>，伴大汗、恶心、呼吸困难、放射到左臂/下颌/背部 |
| <strong>疑似卒中</strong>（FAST） | <strong>F</strong>ace 面部歪斜；<strong>A</strong>rm 一侧肢体无力；<strong>S</strong>peech 说话不清或听不懂；<strong>T</strong>ime 立即拨打 120 |
| <strong>严重呼吸困难</strong> | 说不出完整句子、口唇发紫、喘不上气 |
| <strong>意识不清</strong> | 昏迷、叫不醒、抽搐、突然不能言语 |
| <strong>大出血</strong> | 呕血、咯血、大量便血、外伤后出血不止 |
| <strong>严重过敏</strong> | 全身皮疹伴呼吸困难、面部/咽喉肿胀、头晕 |
| <strong>严重外伤</strong> | 车祸、高处坠落、头部外伤后呕吐或意识改变、骨折畸形 |
| <strong>中毒</strong> | 药物过量、农药、一氧化碳（煤气）中毒 |
| <strong>剧烈腹痛</strong> | 突然发生的剧烈腹痛、腹部板硬 |
| <strong>产科急症</strong> | 孕妇阴道大量出血、剧烈腹痛、胎动明显减少 |
| <strong>自杀风险</strong> | 有自伤或自杀念头、计划或行为（见[什么时候该求助心理专业人士](/entry/when-to-seek-mental-health-help/)） |

<strong>拨打 120 时要说清</strong>：具体地址（门牌、楼号、显著标志物）、病人主要症状、发病时间、联系电话，并<strong>保持电话畅通、按调度员指导操作</strong>。

<strong>等待救护车时</strong>：
- <strong>不要给意识不清的人喂水喂食</strong>（窒息风险）。
- <strong>疑似卒中不要自行喂阿司匹林或降压药</strong>。
- <strong>让病人保持安静、平卧或侧卧</strong>（呕吐时侧卧防误吸）。
- <strong>心梗病人不要自行走动</strong>，解开衣领，保持通风。
- <strong>准备好病历、用药清单、医保卡</strong>。

### 2. 一两周内务必就诊的信号

这类情况不紧急，但<strong>拖下去风险会上升</strong>，属于「尽早评估」：

| 信号 | 可能提示 |
| --- | --- |
| <strong>不明原因体重下降</strong>（半年内下降超过 5%） | 代谢、消化、肿瘤、情绪等问题 |
| <strong>持续发热超过 2–3 周</strong> | 感染、免疫、血液系统疾病 |
| <strong>大便带血或黑便</strong> | 消化道出血、痔疮、肿瘤 |
| <strong>无痛性肿块</strong>（乳房、颈部、腋下、腹股沟） | 需排除肿瘤，<strong>无痛反而更要查</strong> |
| <strong>溃疡超过 2 周不愈合</strong>（口腔、皮肤） | 需排除恶变 |
| <strong>持续咳嗽超过 3 周</strong>、或咯血 | 呼吸道疾病、结核、肿瘤 |
| <strong>吞咽困难或进行性加重</strong> | 食管疾病，<strong>是重要警示症状</strong> |
| <strong>痣的形状、颜色、大小变化</strong> | 需排除黑色素瘤 |
| <strong>持续疲劳、乏力超过数周</strong> | 贫血、甲状腺、糖尿病、抑郁等 |
| <strong>夜间痛、静息痛</strong>（骨、关节） | 需排除炎症、感染或肿瘤 |
| <strong>排尿异常</strong>：血尿、尿痛、尿频伴发热 | 泌尿系感染或结石 |
| <strong>月经异常</strong>：绝经后出血、经量剧变 | 妇科评估 |
| <strong>新发或变化的头痛</strong>，尤其清晨加重、伴呕吐 | 需排查颅内问题 |
| <strong>情绪低落、兴趣丧失超过 2 周</strong> | 抑郁，可治疗 |
| <strong>伤口红肿化脓、伴发热</strong> | 感染，可能需要抗生素处理 |

### 3. 可以先观察的情况

这些通常是<strong>自限性</strong>问题，观察和家庭护理即可，但要知道什么时候该升级：

| 情况 | 可观察的条件 | 何时就诊 |
| --- | --- | --- |
| 普通感冒 | 无高热、能正常进食饮水 | <strong>超过 10 天不缓解</strong>、高热超过 3 天、呼吸困难 |
| 轻度腹泻 | 无脱水、无血便、能喝水 | 有血便、高热、<strong>明显脱水</strong>、超过 3 天 |
| 轻度扭伤 | 能负重、无明显畸形 | 不能负重、明显肿胀畸形、麻木 |
| 轻度头痛 | 与既往相似、能缓解 | <strong>突发的剧烈头痛（雷击样）</strong>、伴发热颈硬、神经症状 |
| 轻度皮疹 | 无全身症状 | 伴发热、呼吸困难、大面积水疱、黏膜受累 |
| 轻度咽痛 | 能进食饮水 | 吞咽困难、流涎、张口受限、单侧剧痛 |
| 腰背痛 | 与劳损相关、休息缓解 | 伴腿麻无力、大小便异常、夜间痛、外伤后 |

<strong>判断「该升级」的核心是</strong>：症状<strong>加重</strong>、<strong>持续超预期</strong>、或<strong>出现新症状</strong>（尤其发热、呼吸困难、意识改变）。

### 4. 特别容易被延误的四个情况

1. <strong>卒中</strong>：很多人等「看看能不能好」，但<strong>溶栓时间窗只有几小时</strong>，「时间就是大脑」。<strong>FAST 任一表现出现，立即打 120。</strong>
2. <strong>心梗</strong>：尤其<strong>女性、老年人和糖尿病患者症状可能不典型</strong>（表现为乏力、恶心、上腹不适、气短而非典型胸痛），容易被当成胃病。<strong>有心血管风险因素的人出现不明原因的上腹不适伴大汗，要想到心脏。</strong>
3. <strong>便血</strong>：很多人当痔疮自行处理，但<strong>便血需要由医生判断原因</strong>，不能默认是痔疮。
4. <strong>情绪问题</strong>：抑郁和焦虑常以躯体症状（心慌、胃肠不适、疼痛）表现，反复在各科检查无异常时，<strong>应考虑情绪因素</strong>。

### 5. 看病前的准备（提高效率）

- <strong>记录症状时间线</strong>：什么时候开始、什么情况下加重或缓解。
- <strong>列出正在服用的所有药物和补剂</strong>（包括中药、保健品、酒）。
- <strong>带上既往检查报告和病历</strong>，避免重复检查。
- <strong>写下最想问的一个问题</strong>，先说这个。
- <strong>有过敏史、慢病史、手术史要主动说</strong>。
- <strong>可以带家人同去</strong>，帮助补充信息、记医嘱。

## 健康原理

- <strong>为什么「时间窗」是急症的核心</strong>：心梗时心肌缺血超过一定时间即发生不可逆坏死（「时间就是心肌」）；卒中时脑组织每分钟损失大量神经元（「时间就是大脑」）。<strong>溶栓、取栓都有严格时间窗</strong>，所以「等一等看」在这些情况下代价最高。
- <strong>为什么危险信号常常不典型</strong>：老年人、女性、糖尿病患者的痛觉和自主神经反应可能受损，心梗和急腹症常表现不典型。这也是<strong>不能只按「教科书症状」自我判断</strong>的原因。
- <strong>为什么要重视无痛性肿块和持续溃疡</strong>：恶性肿瘤早期往往无痛，疼痛反而多与炎症相关。所以「不疼」不能作为放心的理由，「持续存在」和「进行性变化」才是更重要的判断维度。
- <strong>为什么自限性疾病可以观察</strong>：普通感冒、病毒性胃肠炎有自限过程，抗生素和过度用药反而有害。观察的前提是<strong>能识别「恶化信号」</strong>，而不是无限期拖延。
- <strong>为什么标 C</strong>：警示症状的清单和急救原则来自临床指南和公共卫生建议，方向明确；但「具体某个症状该多快去就医」缺少随机对照研究，且个体差异（年龄、基础病）很大。这是一条<strong>操作性建议</strong>，标 C 是为了不把间接推论说得比实际更确定。<sup class="ref-mark">[1][2][3][4]</sup>

## 常见误区

- <strong>能忍就别去医院，医院容易交叉感染</strong>：对急症而言，<strong>延误的代价远大于感染风险</strong>。
- <strong>自己开车送急症病人更快</strong>：<strong>心梗和卒中病人应叫救护车</strong>——救护车能在途中监护、吸氧，并直接送到有救治能力的医院（卒中中心/胸痛中心）。自己开车还可能因病情变化导致事故。
- <strong>胸痛缓一缓再说</strong>：持续 15 分钟不缓解的胸痛<strong>按心梗处理，立即打 120</strong>。
- <strong>中风等一等，有时候会自己好</strong>：短暂好转（TIA）也是<strong>急症预警</strong>，需立即就医。
- <strong>发烧一定要马上吃退烧药、打针</strong>：发热本身是免疫反应，<strong>关键是看精神状态和其他症状</strong>；持续高热或伴危险信号才需紧急处理。
- <strong>便血就是痔疮</strong>：需要医生判断，<strong>不能自行默认</strong>。
- <strong>不疼就没事</strong>：多数早期肿瘤和牙周病都不疼。
- <strong>先在网上查清楚再去</strong>：网络信息不能替代面诊，<strong>出现危险信号应直接就医</strong>，不要用搜索替代就诊。
- <strong>年轻人不会得重病</strong>：年轻人心梗、卒中和肿瘤都可能发生，判断依据是<strong>症状</strong>而不是年龄。
- <strong>挂不上号就等着</strong>：出现急症信号应<strong>走急诊</strong>，不必等专家号。
- <strong>体检正常就代表没病</strong>：常规体检有局限，<strong>新出现并持续的症状仍需就诊</strong>。

## 风险与禁忌

- <strong>急症情况不要自行处理</strong>：疑似心梗不要自行走动、不要自行服用他人药物；疑似卒中不要喂水喂药；意识不清不要喂食。
- <strong>不要自行停用或加量慢性病药物</strong>（降压药、降糖药、抗凝药、精神科药物），调整需医生指导。
- <strong>不要用止痛药掩盖警示症状</strong>：可能掩盖急腹症、心梗等，延误诊断。
- <strong>不要用抗生素自行治疗</strong>：多数上呼吸道感染是病毒性的，滥用抗生素无效且有害。
- <strong>老年人</strong>：症状常不典型、进展快，<strong>宁可及早就医</strong>。
- <strong>婴幼儿</strong>：精神状态差、拒食、呼吸急促、抽搐、囟门膨隆要立即就医；<strong>不要给婴幼儿自行用药</strong>。
- <strong>孕妇</strong>：腹痛、阴道出血、胎动减少、头痛视力模糊（可能子痫前期）需<strong>立即就医</strong>。
- <strong>免疫低下者</strong>：感染进展可能极快，发热应尽早就医。
- <strong>有心血管疾病、糖尿病、慢性肾病、慢阻肺者</strong>：出现新症状的门槛要更低。
- <strong>不要依赖网络自诊或 AI 给自己下诊断</strong>，包括本站内容——<strong>本站不构成医疗建议，不能替代面诊</strong>。

## 何时求助专业人士

<strong>立即拨打 120（或前往急诊）：</strong>

- 胸痛/胸闷持续超过 15 分钟不缓解，伴大汗、恶心、气短。
- 突发面歪、单侧肢体无力、说话不清（卒中）。
- 严重呼吸困难、口唇发紫。
- 意识不清、抽搐、突然不能言语。
- 大出血（呕血、咯血、大量便血）。
- 严重过敏反应（呼吸困难、咽喉肿胀）。
- 严重外伤、头部外伤后意识改变。
- 中毒（药物、农药、一氧化碳）。
- 突然剧烈腹痛、腹部板硬。
- 孕妇大量阴道出血、剧烈腹痛、胎动明显减少。

<strong>尽快（数天内）就诊：</strong>

- 不明原因体重下降、持续发热 2–3 周。
- 便血、黑便、血尿、咯血。
- 无痛性肿块；溃疡或口腔溃疡超过 2 周不愈。
- 吞咽困难、持续咳嗽超过 3 周。
- 痣的形态变化。
- 情绪低落、兴趣丧失超过 2 周。
- 任何<strong>持续存在且进行性加重</strong>的症状。

<strong>可以先观察，但要知道升级信号：</strong>

- 普通感冒、轻度腹泻、轻度扭伤、轻度皮疹——<strong>加重或超期就就诊</strong>。
