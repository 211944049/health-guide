## 适用人群

- 平时买瓶装水、想知道该买哪种的人。
- 觉得"自来水不干净"想找替代方案的人。
- 运动、户外、高温作业需要补水的人。
- 给孩子买水的家长。

<strong>先澄清</strong>：如果你所在地区自来水符合国标（大多数城市都是），<strong>烧开喝就够了</strong>，不必为健康去买贵的水。瓶装水的价值主要在<strong>方便</strong>和<strong>特定场景</strong>（户外、旅行、水质不确定时）。

## 具体做法

### 1. 先分清四类"水"

| 类型 | 标准 | 是什么 | 说明 |
| --- | --- | --- | --- |
| <strong>饮用纯净水</strong> | GB 19298 | 经反渗透/蒸馏等处理，<strong>几乎只有水</strong> | 不含矿物质。安全，但也没有"额外好处" |
| <strong>饮用天然水</strong> | GB 19298 | 来自水源地，<strong>仅做有限处理</strong> | 保留部分天然矿物质 |
| <strong>饮用天然矿泉水</strong> | <strong>GB 8537</strong> | 从地下深处取得，<strong>矿物质含量须达到标准界限</strong> | 这是唯一有"界限指标"要求的一类 |
| <strong>苏打水/气泡水</strong> | 视产品而定 | 充入二氧化碳 | <strong>加糖的是饮料，不是水</strong> |

<strong>看标签就能分清</strong>：
- 写"饮用纯净水"→ 第一类。
- 写"饮用天然矿泉水"→ 有 GB 8537 和<strong>水源地、界限指标</strong>标注。
- <strong>只写"矿物质水"</strong>→ 通常是纯净水里<strong>人工添加</strong>了矿物质，与天然矿泉水不同。
- <strong>配料表里有白砂糖、果葡糖浆</strong>→ 是<strong>含糖饮料</strong>。

### 2. 什么时候该选哪一类

| 场景 | 建议 |
| --- | --- |
| 日常在家喝水 | <strong>烧开的自来水</strong>即可（成本最低） |
| 外出、通勤、办公室 | 纯净水或天然水都行，<strong>看方便</strong> |
| 长时间运动/大量出汗 | <strong>含钠的饮品</strong>（见第 4 条） |
| 户外、旅行、水质不确定 | 瓶装水（注意密封和保质期） |
| 婴幼儿冲奶粉 | <strong>按说明用</strong>：多数建议把水<strong>烧开晾温</strong>；不要用矿泉水冲（矿物质负荷） |
| 想补充矿物质 | <strong>不要靠水</strong>，靠食物 |

### 3. 哪些宣称不值得多花钱

| 宣称 | 判断 |
| --- | --- |
| <strong>"弱碱性水更健康"</strong> | <strong>没有可靠证据</strong>。人体血液 pH 由自身严格调控（7.35–7.45），<strong>喝水改变不了它</strong> |
| <strong>"小分子团水""活化水""富氧水"</strong> | <strong>没有可靠证据</strong>，也没有公认的检测标准 |
| <strong>"矿物质水更有营养"</strong> | 水里的矿物质<strong>含量很低</strong>，对日常摄入的贡献可以忽略。一杯牛奶的钙远超几瓶矿泉水 |
| <strong>"深层水源、冰川水"</strong> | 水源是营销点，<strong>安全性看是否符合国标</strong>，与"深层"无必然关系 |
| <strong>"纯净水会冲走体内矿物质"</strong> | <strong>不成立</strong>。人体矿物质主要来自食物，肾脏会精细调节 |
| <strong>"长期喝纯净水不好"</strong> | <strong>没有证据</strong>。WHO 曾讨论过"低矿物质水"的极端情况，但<strong>正常饮食下不构成问题</strong> |

<strong>结论：选水看"是否安全 + 是否方便 + 价格"，不必为健康宣称付溢价。</strong>

### 4. 运动补水：这一条最容易被做错

- <strong>出汗会同时流失水和钠</strong>。长时间大量出汗后<strong>只喝大量白水</strong>，可能稀释血钠，导致<strong>低钠血症</strong>（头痛、恶心、乏力，严重时意识模糊、抽搐）——这在马拉松等耐力运动中有真实病例。
- <strong>怎么做</strong>：
  - <strong>1 小时以内的普通运动</strong>：白水足够。
  - <strong>超过 1 小时、大量出汗、高温环境</strong>：选<strong>含钠的饮品</strong>（运动饮料、或白水 + 少量盐分的食物）。
  - <strong>不要喝含糖量很高的饮料</strong>（吸收慢、可能加重胃肠不适）。
  - <strong>按口渴喝 + 少量多次</strong>，不要一次性猛灌。
- 具体见 [怎么判断自己喝水够不够](/entry/hydration-signs/)。

### 5. 用瓶装水的注意事项

- <strong>开封后尽快喝完</strong>：放置越久，微生物越多（尤其直接对嘴喝过）。
- <strong>不要反复使用 PET 瓶</strong>（1 号塑料是一次性设计）。
- <strong>不要把瓶装水放在高温车里</strong>：高温会加速塑料中成分的迁移，也影响口感（见 [水杯材质怎么选](/entry/drinkware-material/)）。
- <strong>不要用瓶装水反复装热水</strong>。
- <strong>看保质期和储存条件</strong>；瓶身鼓胀、有异味、水有异常颜色不要喝。
- <strong>运动水壶要每天清洗</strong>（密封圈和吸管是霉菌重灾区）。

### 6. 自来水到底行不行？

- <strong>我国自来水出厂执行 GB 5749</strong>，绝大多数城市供水达标。
- <strong>"有氯味"不等于不安全</strong>：余氯是<strong>为了在管网里持续消毒</strong>，烧开或静置会挥发。
- <strong>真正需要装净水器的情况</strong>：管道老化、二次供水水箱不洁、对口感敏感等。见 [净水器怎么选](/entry/water-purifier-choice/) 与 [老房子的水管和水质要注意什么](/entry/old-building-water/)。
- <strong>烧开水的作用</strong>：<strong>杀灭微生物</strong>（这是最核心的）。它<strong>不能去除重金属和部分化学污染物</strong>——如果怀疑这类问题，需要检测或换水源，而不是"多烧一会儿"。

## 健康原理

- <strong>水的核心健康作用是"补水"，不是"补充营养"</strong>：人体对水的需求是<strong>维持体液平衡和代谢</strong>。矿物质的主要来源是<strong>食物</strong>——一瓶矿泉水里的钙（通常几十 mg/L）与一杯牛奶（约 300 mg）相比可以忽略。
- <strong>为什么"弱碱性水"改变不了体质</strong>：血液 pH 由<strong>呼吸和肾脏</strong>在 7.35–7.45 之间严格调控（碳酸氢盐缓冲系统）。<strong>胃酸（pH 1.5–3.5）会先把任何进入的水酸化</strong>，之后在肠道被中和。所以"喝碱性水调节体质"在生理学上不成立。
- <strong>为什么补钠对长时间运动重要</strong>：汗液是<strong>低渗</strong>的（含钠约 20–50 mmol/L），大量出汗时<strong>水流失多于钠</strong>。如果只补白水，细胞外液钠浓度会被稀释，水分进入细胞（包括脑细胞），引起<strong>低钠血症</strong>的症状。这就是运动饮料含钠的真正理由，不是为了"补能量"。
- <strong>为什么矿泉水有"界限指标"</strong>：GB 8537 对<strong>锂、锶、锌、偏硅酸、硒、游离二氧化碳、溶解性总固体</strong>等设了界限值，<strong>达不到就不能叫"天然矿泉水"</strong>。这是分类依据，<strong>不是健康功效的依据</strong>。
- <strong>为什么纯净水安全</strong>：经反渗透或蒸馏处理，<strong>微生物和大部分溶解物被去除</strong>。它不会"冲走矿物质"——人体对钠、钾、钙的调节由<strong>肾脏和激素</strong>完成，不会因为喝低矿物质水就失衡。<strong>WHO 的相关讨论针对的是"完全以低矿物质水为唯一水源且饮食极差"的极端情况。</strong>
- <strong>为什么开封后的水菌量会上升</strong>：瓶口接触口腔和手，<strong>细菌随唾液进入水中</strong>；室温下细菌会繁殖。<strong>这是"尽快喝完"的理由</strong>（不是因为水本身有问题）。
- <strong>为什么 PET 瓶不能装热水</strong>：PET（1 号）<strong>耐热性差</strong>（约 70 ℃ 就会变形），高温会加速<strong>小分子迁移</strong>。所以 PET 瓶是<strong>一次性冷饮设计</strong>（见 [水杯材质怎么选](/entry/drinkware-material/)）。
- <strong>为什么标 B</strong>："水的安全标准、补水机制、运动补钠"有<strong>明确的标准和生理学依据</strong>（这部分接近 A）；但<strong>"某种水更健康"的宣称大多缺少证据</strong>，而"长期饮用某种水的健康影响"也缺少高质量研究。综合 B。

## 常见误区

- <strong>"弱碱性水/小分子团水更健康"</strong>：没有可靠证据。血液 pH 由身体自己调控。
- <strong>"纯净水会带走体内矿物质"</strong>：不成立。矿物质主要来自食物。
- <strong>"矿泉水能补钙"</strong>：含量太低，<strong>补钙靠乳制品、豆制品、绿叶菜</strong>。
- <strong>"自来水有氯所以不能喝"</strong>：余氯是为管网消毒而保留的，<strong>烧开或静置即可</strong>。安全标准有上限要求。
- <strong>"多喝水能排毒"</strong>：没有"排毒"这回事（肝肾负责代谢废物）。<strong>喝水过多反而危险</strong>（低钠血症）。
- <strong>"运动后要多喝白水"</strong>：短时间可以；<strong>长时间大量出汗要补钠</strong>。
- <strong>"瓶装水开封后能放几天"</strong>：直接对嘴喝过的，<strong>建议当天喝完</strong>。
- <strong>"苏打水更健康"</strong>：<strong>看是否含糖</strong>。含糖苏打水是饮料。无糖气泡水对健康人没问题，但<strong>胃食管反流、胃胀气的人可能不适</strong>。
- <strong>"瓶装水放车里晒一天还能喝"</strong>：<strong>不建议</strong>。高温加速迁移，也影响口感。
- <strong>"贵的水一定更安全"</strong>：安全性看<strong>是否符合国标</strong>，与价格无关。
- <strong>"喝碱性水能防癌"</strong>：<strong>没有任何可靠证据</strong>。

## 风险与禁忌

- <strong>不要在长时间大量出汗后只喝大量白水</strong>（低钠血症风险，严重可危及生命）。
- <strong>有心力衰竭、肾功能不全、肝硬化腹水的人</strong>：<strong>饮水量需要医生限定</strong>，不要按"多喝水"的通用建议执行。
- <strong>不要用矿泉水冲婴儿配方奶</strong>（矿物质负荷），按说明用烧开晾温的水。
- <strong>不要反复使用 PET 瓶</strong>，不要装热水，不要暴晒。
- <strong>不要把瓶装水长期放在高温环境</strong>（车内、阳台）。
- <strong>怀疑自来水有污染</strong>（异味、异色、浑浊）：<strong>停止饮用并联系供水部门</strong>，不要靠"多烧一会儿"解决。
- <strong>不要相信"富氧水""活化水""量子水"这类产品</strong>。
- <strong>低钠血症的警示症状</strong>（大量出汗后）：<strong>头痛、恶心、乏力、意识模糊、抽搐</strong> → <strong>立即就医</strong>。
- <strong>出现腹泻、呕吐时</strong>：不要只补白水，需要<strong>口服补液盐</strong>（含电解质）而非纯水。

## 何时求助专业人士

- <strong>家中有持续的水质问题</strong>（异味、异色、沉淀）→ 联系供水部门或做水质检测，必要时咨询专业净水方案。
- <strong>有心衰、肾病、肝病</strong>的人 → 向医生确认每日允许的饮水量。
- <strong>运动中出现头晕、恶心、意识模糊</strong> → 立即停止运动并就医（可能是低钠血症或中暑）。
- <strong>婴幼儿喂养用水的疑问</strong> → 咨询儿科医生（尤其冲调配方奶）。
- <strong>长期只喝某一种水且有健康疑虑</strong> → 咨询营养科，不要自行购买"功能性水"。
