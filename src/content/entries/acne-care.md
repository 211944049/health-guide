## 适用人群

- 反复长痘、想搞清楚该怎么处理的人。
- 试过很多护肤品但没改善的人（<strong>很可能需要的是药物，不是护肤品</strong>）。
- 青春期的孩子和家长（这一类要早介入，避免留坑）。
- 有痘印、痘坑困扰的人。

<strong>必须直接看医生、不要自己处理的情况</strong>：<strong>结节、囊肿（摸起来硬、大的皮下包块）、大面积红肿、留坑、伴发热</strong>，以及<strong>突然出现的严重痤疮</strong>。

## 具体做法

### 1. 第一步：判断你的类型

| 类型 | 表现 | 谁来处理 |
| --- | --- | --- |
| <strong>轻度（非炎症型）</strong> | 黑头、白头、闭口，少量小丘疹 | 可以自己用非处方成分 |
| <strong>中度（炎症型）</strong> | 较多红肿丘疹、脓疱 | <strong>建议看皮肤科</strong> |
| <strong>重度</strong> | 结节、囊肿、融合成片、留坑 | <strong>必须看皮肤科</strong>（可能需要口服药） |

<strong>判断标准很简单</strong>：<strong>只要有明显的红肿、脓疱、或者摸到皮下的硬块，就属于需要医生介入的范围。</strong> 自己处理只适用于以粉刺为主的情况。

### 2. 非处方有效成分（粉刺型和轻度炎症型）

| 成分 | 作用 | 怎么用 |
| --- | --- | --- |
| <strong>过氧化苯甲酰</strong> | 杀菌 + 抗炎 + 溶解角质，<strong>痤疮一线外用药</strong> | 从 2.5% 起，点涂或薄涂，<strong>初期可能脱皮刺痛，从隔天一次开始</strong> |
| <strong>外用维 A 酸类</strong>（阿达帕林、维 A 酸） | 调节毛囊角化、溶解粉刺，<strong>预防新痘的关键</strong> | <strong>晚上用、薄涂全脸（不止涂痘上）</strong>；初期会"爆痘期"，通常 4–8 周后改善；<strong>必须防晒</strong> |
| <strong>水杨酸</strong> | 溶解角质、疏通毛孔 | 2% 左右；适合黑头白头；<strong>可能与维 A 酸叠加刺激</strong> |
| <strong>壬二酸</strong> | 抗炎 + 抑菌 + 帮助痘印 | 10%–20%；刺痛感明显，需建立耐受 |
| <strong>烟酰胺</strong> | 抗炎、减少油脂、帮助痘印 | 与维 A 酸搭配相对温和 |

<strong>关键用法要点：</strong>

- <strong>不要只点涂痘痘</strong>：阿达帕林这类<strong>要涂在容易长痘的整片区域</strong>，作用是预防新痘，不是"消灭已有的"。
- <strong>要有耐心</strong>：<strong>至少 8–12 周</strong>才看得出效果。<strong>前 2–4 周可能变差（爆痘期）</strong>，这是正常的角化调整过程，不是"不适合"。
- <strong>一次只用一种活性成分开始</strong>，耐受后再考虑搭配（常见有效搭配：<strong>早上过氧化苯甲酰 + 晚上阿达帕林</strong>，但都要从低频开始）。
- <strong>保湿和防晒必须跟上</strong>：这些成分都会让皮肤更干、更怕光。

### 3. 护肤步骤：简化，再简化

<strong>长痘的人最该做的是"减法"</strong>：

- <strong>温和清洁，每天 1–2 次</strong>，用氨基酸类或温和洁面。<strong>不要用磨砂、不要用洗脸刷、不要一天洗三次脸。</strong>
- <strong>保湿要有</strong>（屏障坏了更容易长痘）。选标注"不易致粉刺"的清爽型。
- <strong>防晒</strong>：紫外线会加重炎症和痘印。选清爽、不闷的（见 [防晒霜怎么选](/entry/sunscreen-choice/)）。
- <strong>停掉</strong>：多层精华叠加、频繁敷面膜、去角质、精油、酒精含量高的产品。

<strong>不要做的事</strong>（每一条都会让痘痘更糟）：

- <strong>挤、挑、抠</strong>：这是留疤留坑的<strong>首要原因</strong>。挤压会把炎症推入更深层，造成结节和永久性凹陷。
- <strong>频繁换产品</strong>：每换一次都要重新经历爆痘期，永远看不到效果。
- <strong>过度清洁</strong>：破坏屏障 → 更多炎症 → 更多痘。<strong>痘痘不是"没洗干净"。</strong>
- <strong>用牙膏、酒精、碘伏点痘</strong>：刺激性大且无效。
- <strong>相信"排毒爆痘"是好事</strong>：爆痘期是维 A 酸类的已知反应，但<strong>如果持续加重超过 6 周，应该找医生</strong>，不是继续忍。

### 4. 痘印和痘坑：要分清

| 类型 | 外观 | 处理 |
| --- | --- | --- |
| <strong>红色痘印</strong> | 平的、红/粉色 | 血管扩张未消退。<strong>抗炎 + 防晒 + 时间</strong>，会自己退（数周到数月） |
| <strong>褐色痘印</strong> | 平的、褐色 | 炎症后色素沉着。<strong>防晒 + 美白成分（烟酰胺、维 C、壬二酸）</strong> |
| <strong>痘坑</strong> | 凹陷的 | <strong>护肤品无效</strong>，需要医美（激光、微针等），且越早治疗越好 |
| <strong>增生性疤痕</strong> | 凸起的 | 需要皮肤科处理 |

<strong>所以"痘印能靠精华消掉"只对褐色痘印部分成立</strong>；红色痘印主要靠时间和防晒；<strong>痘坑只能靠医美</strong>。这也是为什么"早点看医生"很重要——<strong>避免留坑比消除坑容易得多</strong>。

### 5. 影响痘痘的几个生活习惯（证据强弱不一）

| 因素 | 证据强度 | 建议 |
| --- | --- | --- |
| <strong>高升糖指数饮食（甜食、含糖饮料）</strong> | 中等，多项研究方向一致 | 值得减少 |
| <strong>牛奶（尤其脱脂奶）</strong> | 中等，观察性研究为主 | 痘痘明显的人可以试停 4–8 周看变化 |
| <strong>压力与睡眠不足</strong> | 明确（通过激素影响） | 优先改善 |
| <strong>频繁摩擦（头盔、口罩、手托脸）</strong> | 明确（机械性痤疮） | 减少摩擦、勤换口罩 |
| <strong>某些化妆品/发油</strong> | 明确（致粉刺性） | 选"不易致粉刺"标注 |
| <strong>巧克力、油炸食品</strong> | <strong>证据弱</strong> | 不是主要原因，但高糖高油的饮食模式可以一起改 |
| <strong>"清洁不彻底"</strong> | <strong>不成立</strong> | 过度清洁反而加重 |

<strong>注意</strong>：饮食调整对痘痘的作用<strong>温和且因人而异</strong>，不能替代药物治疗。<strong>不要为了治痘搞极端饮食</strong>。

## 健康原理

- <strong>痤疮的四个环节</strong>：① 毛囊口<strong>角化异常</strong>导致堵塞 → ② <strong>皮脂分泌增多</strong>（受雄激素影响）→ ③ <strong>痤疮丙酸杆菌</strong>繁殖 → ④ <strong>炎症反应</strong>。四个环节互相促进。<strong>这就是为什么要"多靶点"处理，而单一成分往往不够。</strong>
- <strong>为什么维 A 酸类是"预防新痘"的关键</strong>：它作用于<strong>第一环节（角化异常）</strong>，让毛囊口不再堵塞。<strong>粉刺是痘痘的前身</strong>，消除粉刺等于从源头减少新痘。这就是为什么它要<strong>涂整片区域而不是点涂</strong>。
- <strong>为什么过氧化苯甲酰有效</strong>：它同时有<strong>杀菌、抗炎、溶解角质</strong>三个作用，而且<strong>细菌不会对它产生耐药</strong>（这是它作为一线药的重要原因）。
- <strong>为什么会有"爆痘期"</strong>：维 A 酸类加速角化脱落，<strong>原本已经在毛囊深处形成的粉刺被"推"到表面</strong>，看起来像变严重了。这个过程通常 2–4 周，之后改善。<strong>理解这一点很重要，否则大多数人会在见效前就放弃。</strong>
- <strong>为什么挤压会造成痘坑</strong>：挤压把<strong>炎症内容物推入真皮深层</strong>，引发更强的炎症反应，破坏胶原结构。真皮一旦塌陷，就形成<strong>永久性凹陷（痘坑）</strong>。同时挤压可能把细菌推向周围组织，形成更大的结节。<strong>所以"挤痘"是把自己从"能恢复的炎症"推向"结构损伤"。</strong>
- <strong>为什么"过度清洁"会加重</strong>：皮肤屏障（角质层 + 皮脂膜）被破坏后，<strong>炎症因子增加、经皮水分流失上升</strong>，皮肤的炎症反应更容易被触发。所以"洗得越干净越好"在痤疮上是错的。
- <strong>为什么牛奶可能有关</strong>：牛奶（尤其脱脂奶）含有<strong>胰岛素样生长因子-1（IGF-1）</strong>和多种激素前体，可能促进皮脂分泌和角化。观察性研究方向一致，但<strong>干预研究有限</strong>，所以是"值得试"而不是"必须戒"。
- <strong>为什么标 B</strong>：<strong>外用维 A 酸类、过氧化苯甲酰、口服异维 A 酸等治疗的证据非常充分</strong>（这部分接近 A）；但<strong>非药物措施（饮食、护肤）的证据强弱不一</strong>，且<strong>具体方案需要按类型和耐受度由医生判断</strong>。综合 B。

## 常见误区

- <strong>"痘痘是脸没洗干净"</strong>：不成立。痤疮的起因是毛囊角化 + 皮脂 + 细菌 + 炎症，<strong>不是表面脏</strong>。过度清洁反而加重。
- <strong>"挤出来就好了"</strong>：挤压是<strong>留痘坑的首要原因</strong>，还可能造成感染扩散。
- <strong>"痘痘过了青春期自然会好"</strong>：部分人会，但<strong>拖延期间留下的痘坑是永久的</strong>。中重度痤疮应尽早治疗。
- <strong>"涂了药马上就好"</strong>：需要 <strong>8–12 周</strong>。<strong>期待速效是治疗失败的最常见原因。</strong>
- <strong>"爆痘说明排毒"</strong>：没有"排毒"。爆痘期是维 A 酸类的已知反应，<strong>但持续加重超过 6 周要看医生</strong>。
- <strong>"防晒会闷痘所以不涂"</strong>：紫外线加重炎症和痘印；<strong>选清爽配方</strong>，而不是不防晒。
- <strong>"吃辣长痘"</strong>：<strong>证据很弱</strong>。真正有关的是<strong>高糖饮食</strong>和（可能的）<strong>牛奶</strong>。
- <strong>"痘痘不能保湿"</strong>：错。屏障受损会加重炎症，<strong>保湿是治疗的一部分</strong>（选清爽非致粉刺型）。
- <strong>"痘印靠美白精华就能全消"</strong>：只有褐色痘印部分适用；<strong>红色痘印靠时间，痘坑只能靠医美</strong>。
- <strong>"护肤品能治好中重度痤疮"</strong>：不能。<strong>中重度需要处方药</strong>。
- <strong>"异维 A 酸很可怕不能用"</strong>：它是<strong>重度痤疮最有效的治疗</strong>，确实有不良反应（需监测血脂、肝功能，<strong>有致畸性，育龄女性必须严格避孕</strong>），但<strong>在医生监测下是可控且获益明确的</strong>。

## 风险与禁忌

- <strong>孕期、哺乳期</strong>：<strong>维 A 酸类（外用和口服）禁用</strong>；水杨酸大面积使用需谨慎；<strong>口服异维 A 酸有明确致畸性</strong>，育龄女性使用前、中、后都需严格避孕并遵医嘱。
- <strong>口服异维 A 酸期间</strong>必须在医生监测下查血脂和肝功能；<strong>不要自行购买服用</strong>。
- <strong>不要挤压、挑破、抠痘痘</strong>，尤其是<strong>面部危险三角区</strong>（鼻周到上唇），感染可向颅内扩散。
- <strong>不要同时叠加多种酸类</strong>和维 A 酸；不要在皮肤破损、晒伤时使用活性成分。
- <strong>不要用牙膏、酒精、碘伏、精油点痘</strong>。
- <strong>使用外用维 A 酸类期间严格防晒</strong>；初期避免与其他刺激性产品叠加。
- <strong>出现以下情况立即就医</strong>：大面积红肿热痛、发热、结节迅速增大、面部明显肿胀（可能合并感染）。
- <strong>疤痕体质</strong>的人：任何挤压、挑痘都可能形成增生性疤痕或瘢痕疙瘩，<strong>更要避免自行处理</strong>。
- <strong>不要相信"排毒""深层清洁"类项目</strong>（如过度清洁、强力去角质、不明成分的面部护理）。

## 何时求助专业人士

- <strong>出现结节、囊肿、或任何摸得到的皮下硬块</strong> → 皮肤科（可能需要口服药）。
- <strong>治疗 8–12 周无改善</strong> → 复诊调整方案，不要自己加量。
- <strong>已经留坑</strong> → 皮肤科或正规医美评估（痘坑越早处理效果越好）。
- <strong>青春期孩子出现中重度痤疮</strong> → 尽早看皮肤科，<strong>避免留下永久性痘坑</strong>（这是最值得早介入的一类）。
- <strong>女性伴月经不规律、多毛、体重增加</strong> → 需排查多囊卵巢综合征等内分泌原因，看妇科或内分泌科。
- <strong>突然出现的严重痤疮</strong>（尤其伴发热）→ 尽快就医。
- <strong>出现明显的情绪困扰、社交回避</strong> → 痤疮对心理的影响是真实的，可以同时寻求心理支持。
