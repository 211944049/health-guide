## 适用人群

- 谁适合照做：所有家庭；长痘、皮肤敏感或湿疹的人；过敏性鼻炎、哮喘、尘螨过敏的人；租房族（洗衣机共用、通风差）；有婴幼儿的家庭；养宠物的家庭。
- 谁不适用：这条是<strong>日常纺织品的清洁与更换</strong>。<strong>皮肤或呼吸道症状持续加重</strong>应就医，清洁只是环境干预的一部分，参考[什么时候该看医生](/entry/when-to-see-a-doctor/)。

## 具体做法

### 1. 毛巾：干燥比「用了几次」更重要

<strong>参考频率：</strong>

| 用途 | 建议频率 |
| --- | --- |
| <strong>洗脸/洗澡毛巾</strong> | <strong>用 3–4 次就洗</strong>，或<strong>每周至少洗 1–2 次</strong> |
| <strong>擦手毛巾</strong> | 每 1–2 天换洗（使用人数多时更勤） |
| <strong>厨房抹布/擦手巾</strong> | <strong>每天换洗或消毒</strong>（与食品安全直接相关，参考[食物中毒怎么预防和处理](/entry/food-poisoning/)） |
| <strong>浴巾</strong> | 每周 1–2 次 |
| <strong>婴儿毛巾</strong> | <strong>用后即洗</strong>，与成人分开 |

<strong>关键做法：</strong>
- <strong>用完立刻展开挂起来</strong>，不要团成一团扔在浴室或洗衣篮里。<strong>潮湿 + 温暖 + 有皮屑 = 微生物繁殖最快的组合。</strong>
- <strong>浴室的通风很重要</strong>：没有窗或排风的卫生间毛巾很难干。可以把毛巾拿到阳台或有阳光/通风的地方晾。
- <strong>每人的毛巾分开</strong>（用不同颜色区分），<strong>不要共用</strong>。
- <strong>不要用毛巾擦脸后挂回原处反复用几周</strong>——脸部有油脂和皮屑，长痘和皮肤敏感的人尤其要勤换。
- <strong>手部有伤口、有脚气、有皮肤感染时</strong>，毛巾要专用并单独洗。

### 2. 床品：参考频率与做法

| 项目 | 建议频率 |
| --- | --- |
| <strong>床单</strong> | <strong>每 1–2 周</strong> |
| <strong>被套</strong> | <strong>每 1–2 周</strong> |
| <strong>枕套</strong> | <strong>每 3–7 天</strong>（脸部直接接触，长痘者更勤） |
| <strong>枕芯/被芯</strong> | <strong>每 3–6 个月清洗或晾晒</strong>（看材质和洗标） |
| <strong>床垫保护套</strong> | 每月 1 次 |
| <strong>床垫</strong> | 定期吸尘、保持干燥；不能洗的用吸尘器 |
| <strong>睡衣</strong> | 每 2–3 次穿着后洗（出汗多者每天），参考[衣服多久洗一次](/entry/laundry-frequency/) |

<strong>洗涤要点：</strong>
- <strong>水温尽量用 60 ℃ 以上</strong>（能更有效杀灭尘螨和多数微生物）；材质不允许高温时，按洗标来。
- <strong>充分晒干或烘干</strong>：阳光和高温烘干都有帮助；<strong>潮湿的床品不要直接铺上</strong>。
- <strong>不要塞太满洗衣机</strong>（影响清洗和漂洗效果）。
- <strong>不要过量使用柔顺剂</strong>（会在纤维表面成膜，降低吸水性；对毛巾尤其明显），参考[洗衣液和柔顺剂怎么选](/entry/laundry-detergent/)。
- <strong>新买的床品先洗再用</strong>（生产中的染料和整理剂残留），参考[怎么看衣服面料成分](/entry/fabric-labels/)。

### 3. 尘螨过敏的人：重点在枕芯和被芯

<strong>这是最容易被做错的一点。</strong>

- <strong>尘螨主要聚集在枕芯、被芯、床垫里</strong>——不是被套表面。<strong>只洗被套/枕套，对减少尘螨暴露作用有限。</strong>
- <strong>有效做法</strong>：
  - <strong>用防螨（防过敏原）罩</strong>把枕芯、被芯、床垫整个包起来——这是证据相对最好的措施。
  - <strong>枕芯、被芯定期清洗</strong>（可水洗的按洗标用 60 ℃ 以上；不能洗的定期晒、拍打、或用烘干机高温处理）。
  - <strong>降低室内湿度到 40%–60%</strong>（尘螨在低湿度下难以存活和繁殖），参考[湿度多少合适](/entry/humidity/)。
  - <strong>减少软装表面积</strong>：地毯、布艺沙发、大量毛绒玩具（儿童可保留 1–2 个并定期洗）。
  - <strong>定期吸尘</strong>（有高效过滤的吸尘器更好），参考[空气净化器怎么选](/entry/air-purifier-choice/)。
- <strong>参考</strong>[租房怎么防霉](/entry/mold-prevention/)：<strong>潮湿和霉菌问题常与尘螨问题同时存在</strong>，应一并处理。

### 4. 洗衣机本身也要清洁

- <strong>洗衣机内筒和密封圈是微生物的聚集处</strong>，会污染衣物和毛巾。
- <strong>做法</strong>：<strong>每 1–3 个月</strong>用洗衣机清洁剂（或高温空转）清洁一次；<strong>每次洗完打开机门通风</strong>；<strong>密封圈用布擦干</strong>。
- <strong>不要把湿衣服留在洗衣机里</strong>（几小时内就可能产生异味和微生物繁殖）。
- <strong>内衣、毛巾可以单独洗或用高温</strong>；<strong>有脚气或皮肤感染者的衣物应单独洗</strong>。
- <strong>合租/公共洗衣机</strong>：用洗衣袋、必要时用消毒型洗衣液；贴身衣物建议手洗或单独洗。

### 5. 几个实际场景

- <strong>长痘或皮肤敏感</strong>：<strong>枕套每 3 天换</strong>是最简单有效的措施之一；避免毛巾摩擦脸部（可以用一次性棉柔巾）。
- <strong>婴幼儿</strong>：床品、毛巾用<strong>无香精、温和洗涤剂</strong>；<strong>充分漂洗</strong>；避免使用柔顺剂（刺激皮肤）。
- <strong>养宠物</strong>：宠物不应上床（尤其过敏者）；床品洗得更勤，配合吸尘。
- <strong>租房族</strong>：入住前<strong>先洗所有床品</strong>（前一位住户的残留）；如果洗衣机是共用的，先空转清洁一次。
- <strong>感冒或皮肤感染后</strong>：毛巾、枕套及时更换清洗。

## 健康原理

<strong>毛巾和床品之所以需要定期清洗，是因为它们同时具备「有机物 + 水分 + 温度」这三个微生物繁殖条件——理解这一点就知道为什么「干燥」比「洗得多」更关键。</strong><sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>① 毛巾为什么是微生物的高风险载体。</strong> 毛巾用后含有<strong>水分、皮屑、油脂和汗液</strong>，而浴室通常<strong>温暖潮湿</strong>。这三个条件叠加，微生物数量会随时间快速上升（这也是"毛巾用久了有味道"的来源）。关键推论：<strong>潮湿状态下的时间比使用次数更决定微生物量</strong>——一条用后立刻晾干的毛巾，比一条用两次但一直团着湿的毛巾更干净。所以<strong>「挂开晾干」是第一条做法</strong>，而不是"少用几次"。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>② 为什么 60 ℃ 是重要阈值。</strong> <strong>尘螨在约 55–60 ℃ 以上会被杀死</strong>（蛋白质变性和失水），且多数细菌在这个温度下也难以存活。所以水洗的<strong>温度</strong>是决定杀螨效果的关键变量，而冷水洗只能去除部分过敏原（能洗掉水溶性的过敏原蛋白，但杀不死螨）。这就是指南普遍建议 <strong>60 ℃ 以上</strong> 的原因。当然，<strong>材质决定了能承受的温度</strong>（羊毛、丝绸、部分化纤不耐高温），所以实际操作是<strong>在洗标允许范围内尽量高温</strong>。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>③ 为什么尘螨的重点是枕芯和被芯。</strong> 尘螨以<strong>人类脱落的皮屑</strong>为食，并以<strong>纺织品纤维间的灰尘</strong>为栖息地。<strong>枕芯、被芯、床垫的纤维层提供了稳定、避光、相对湿润的微环境</strong>，且<strong>不易清洁</strong>——所以尘螨在这些"核心层"里的密度远高于可洗的套件表面。这是「防螨罩 + 处理芯体 + 控湿」这套组合的依据，也解释了为什么<strong>只洗被套对过敏症状改善有限</strong>。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>④ 为什么湿度控制这么重要。</strong> 尘螨<strong>通过体表从空气中吸收水分</strong>（它们不喝水），所以<strong>相对湿度是它们存活的限制因素</strong>：<strong>相对湿度低于约 50% 时繁殖和存活显著受抑</strong>，高于 70%–80% 时最活跃。这解释了为什么<strong>除湿和通风</strong>是尘螨控制的根本手段之一（比杀螨剂更可靠），也与[湿度多少合适](/entry/humidity/)里的机制一致。同时说明：<strong>潮湿环境会同时促进尘螨和霉菌</strong>，两者的控制手段高度重叠。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>⑤ 为什么柔顺剂对毛巾是负面的。</strong> 柔顺剂的成分（阳离子表面活性剂）会<strong>吸附在纤维表面形成一层膜</strong>，使纤维变得顺滑——代价是<strong>降低吸水性</strong>和<strong>影响纤维的透气/吸湿性能</strong>。对毛巾（核心功能是吸水）和功能性面料（速干衣）都是负面的，对敏感皮肤也可能增加刺激（残留）。这解释了为什么很多毛巾产品标注"不可使用柔顺剂"。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>⑥ 为什么洗衣机本身是污染源。</strong> 洗衣机的<strong>内筒夹层和门封圈</strong>长期处于潮湿状态，容易积累生物膜（细菌和真菌），在后续洗涤中<strong>污染衣物</strong>。这在文献里被称为洗衣机相关的微生物污染，可能造成洗后衣物仍有异味（"洗了还臭"）。应对方式是<strong>定期清洁内筒 + 每次用后开门通风</strong>，这比换更贵的洗衣液更有效。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>⑦ 为什么要给"频率"而不是只给"标准"。</strong> 微生物量在实际生活中是连续的，没有绝对的"干净"/"不干净"分界。给频率的价值在于<strong>把维护变成一个可执行的习惯</strong>；而同时说明"干燥更重要"，是为了让人理解<strong>如果做不到高频清洗，至少要做到彻底晾干</strong>——这是<strong>收益/成本比最高的那一步</strong>。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>证据等级为什么是 C。</strong> 分几块：<strong>「60 ℃ 以上可杀死尘螨」「相对湿度低于 50% 抑制尘螨」「防螨罩能减少过敏原暴露」</strong> 有实验和临床研究支持（物理杀螨的 Cochrane 评价显示，<strong>单一措施效果有限，但物理方法综合使用有效</strong>）；<strong>「洗衣机内筒存在微生物污染」</strong> 有微生物学研究支持。但<strong>「毛巾 3–4 次」「床单 1–2 周」这类具体频率没有对照研究</strong>——它们是根据微生物生长速度、皮屑/油脂积累速度和实际可执行性推导出的实践建议；<strong>「清洗频率对皮肤或过敏症状的实际改善程度」</strong> 也缺乏直接研究（多为环境过敏原浓度等替代指标）。所以整体定 C 级，并把证据较强的部分（温度、湿度、防螨罩）明确标出。<sup class="ref-mark">[1][2][3][4][5]</sup>

## 常见误区

- <strong>误区：毛巾只要看着干净就能继续用。</strong> 微生物<strong>看不见</strong>。关键是<strong>用完是否晾干</strong>和<strong>多久洗一次</strong>。
- <strong>误区：毛巾用完团起来放洗衣篮，攒够一起洗。</strong> 团着湿放是<strong>微生物繁殖最快</strong>的状态。应<strong>展开晾干</strong>再收。
- <strong>误区：热水洗会伤衣物，冷水洗也一样干净。</strong> 冷水能洗掉部分过敏原，但<strong>杀不死尘螨</strong>。应在洗标允许下<strong>尽量用 60 ℃ 以上</strong>。
- <strong>误区：只洗被套枕套就够，不用管枕芯被芯。</strong> <strong>尘螨主要在芯体里</strong>。过敏者应处理枕芯、被芯和床垫。
- <strong>误区：用柔顺剂让毛巾更柔软更好。</strong> 会<strong>降低吸水性</strong>并可能刺激敏感皮肤。毛巾和功能性面料应避免柔顺剂。
- <strong>误区：床品只要没脏就不用洗。</strong> 汗液、皮屑和油脂是<strong>看不见</strong>的，但它们正是尘螨和微生物的食物。
- <strong>误区：晒太阳能杀死所有尘螨。</strong> 阳光有帮助但<strong>受强度、时长和湿度影响</strong>；高温洗涤和烘干更可靠。
- <strong>误区：洗衣机不用清洁。</strong> <strong>内筒和密封圈会积累生物膜</strong>，导致衣物洗完仍有异味。应定期清洁并保持通风。
- <strong>误区：新买的床品可以直接用。</strong> 生产中的染料和整理剂残留是真实的。<strong>应先洗再用。</strong>
- <strong>误区：皮肤过敏只要换更贵的毛巾。</strong> 关键在<strong>材质（纯棉、无染料）、勤洗、充分晾干</strong>，与价格无关。
- <strong>误区：脚气患者的毛巾可以和家人一起洗。</strong> 应<strong>单独洗或高温洗</strong>，避免交叉感染。
- <strong>误区：潮湿的床品铺上晾干也行。</strong> 会让床垫和床品长时间处于高湿状态，<strong>促进尘螨和霉菌</strong>。应晾/烘干后再铺。

## 风险与禁忌

- <strong>有脚气、皮肤感染或伤口的人</strong>：毛巾、床品<strong>单独洗或高温洗</strong>，避免与家人混洗交叉感染。
- <strong>尘螨过敏、哮喘、过敏性鼻炎患者</strong>：应把重点放在<strong>防螨罩 + 控湿（40%–60%）+ 高温洗</strong>，参考[湿度多少合适](/entry/humidity/)与[租房怎么防霉](/entry/mold-prevention/)。
- <strong>婴幼儿</strong>：床品和毛巾用<strong>温和、无香精洗涤剂</strong>并<strong>充分漂洗</strong>；<strong>不要用柔顺剂</strong>；新用品先洗。
- <strong>皮肤敏感或湿疹患者</strong>：避免含香精的洗涤剂和柔顺剂；选择纯棉、浅色、无复杂整理的材质，参考[怎么看衣服面料成分](/entry/fabric-labels/)。
- <strong>不要把湿衣物或湿毛巾长时间留在洗衣机/洗衣篮里</strong>（几小时内即可产生异味和微生物繁殖）。
- <strong>不要在密闭潮湿的卫生间长期存放湿毛巾</strong>；应通风或移到干燥处。
- <strong>不要在床品潮湿时铺上床</strong>；会让床垫长期受潮。
- <strong>共用洗衣机（合租、公共洗衣房）</strong>：贴身衣物建议单独洗或手洗，必要时使用消毒型洗衣液；使用前可空转清洁一次。
- <strong>有伤口、术后或免疫低下者</strong>：床品、毛巾应更勤更换清洗，必要时按医生要求。
- <strong>不要用高温洗不耐热的材质</strong>（羊毛、丝绸、部分化纤会缩水变形）；应看洗标，必要时送洗。
- <strong>不要过量使用洗涤剂</strong>（残留会刺激皮肤，也可能影响漂洗效果）。
- <strong>出现以下情况应就医而不是只做清洁</strong>：皮肤症状持续加重、哮喘或鼻炎控制不佳、夜间咳嗽明显、皮疹渗液或感染。
- <strong>不要用消毒剂直接喷洒在床品上代替清洗</strong>（刺激呼吸道，且不能去除过敏原）；如果使用，应充分通风并按说明稀释。

## 何时求助专业人士

出现以下情况先看医生，不要只靠本文：

- <strong>过敏性鼻炎、哮喘症状持续或加重</strong>，尤其<strong>夜间或晨起明显</strong> —— 建议做过敏原评估（尘螨是常见室内过敏原），并制定环境控制方案，参考[空气净化器怎么选](/entry/air-purifier-choice/)。
- <strong>皮肤反复出现皮疹、瘙痒、红斑，且与某类织物或洗涤剂相关</strong> —— 需皮肤科评估，参考[身体乳怎么用](/entry/body-lotion/)。
- <strong>皮疹出现渗液、脓点、红肿热痛</strong> —— 提示感染，<strong>尽快就诊</strong>。
- <strong>婴幼儿出现反复皮疹、持续鼻塞或夜间咳嗽</strong> —— 建议儿科就诊并检查居家环境。
- <strong>家中多处持续发霉或潮湿</strong>（毛巾长期不干、墙面发霉）—— 属于建筑潮湿问题，应联系物业或专业除湿/防水服务，参考[租房怎么防霉](/entry/mold-prevention/)。
- <strong>怀疑洗衣机造成衣物异味或皮肤问题</strong> —— 应清洁内筒和密封圈；如问题持续，可请专业人员检修。
- <strong>有脚气或皮肤真菌感染</strong> —— 需要治疗（避免家庭内传播），毛巾床品应单独处理。
- <strong>不确定自己的过敏原是什么</strong> —— 建议过敏科评估，比自行猜测和反复换洗护产品有效。
- <strong>免疫低下、术后或长期卧床者</strong>的床品清洁要求 —— 应遵医嘱（可能需要更严格的清洁与更换频率）。
