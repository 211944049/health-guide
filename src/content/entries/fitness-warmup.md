## 适用人群

- 刚开始运动、不知道怎么准备的人。
- 健身或跑步的人（想减少受伤）。
- "周末运动员"（平时不动、周末集中运动）——<strong>这一类受伤风险最高</strong>。
- 运动后经常肌肉酸痛、关节不适的人。

<strong>需要先就医</strong>：<strong>运动中出现的胸痛、明显气短、头晕、心悸</strong>；<strong>关节肿胀、卡住感、打软腿</strong>；<strong>持续超过 2 周的疼痛</strong>。

## 具体做法

### 1. 热身：5–10 分钟，分两步

<strong>第一步：升温（3–5 分钟低强度有氧）</strong>

- 快走、慢跑、骑车、跳绳（慢速）、划船机——目的是<strong>提高体温和心率</strong>。
- 强度标准：<strong>微微出汗、能说话但不能唱歌</strong>。

<strong>第二步：动态热身（3–5 分钟，与今天要做的运动相关）</strong>

| 今天练什么 | 动态热身动作 |
| --- | --- |
| 跑步 | 高抬腿走、后踢腿走、弓步走、髋部绕环、踝关节绕环 |
| 力量训练 | 目标肌群的<strong>轻重量热身组</strong>（用 40%–50% 重量做 1–2 组）、肩绕环、猫牛式 |
| 球类（篮球、羽毛球） | 侧滑步、交叉步、变向跑、跳跃落地练习 |
| 上肢为主 | 肩绕环、手臂画圈、弹力带外旋 |
| 下肢为主 | 臀桥、深蹲（徒手）、弓步、髋外展 |

<strong>要点</strong>：
- <strong>动作幅度逐步加大</strong>，从慢到快、从小到大。
- <strong>每组 8–12 次，做 1–2 组</strong>。
- <strong>不要做到力竭</strong>——热身不是训练。
- <strong>和今天的运动模式接近</strong>比"通用热身"更有效。

### 2. 静态拉伸：放到运动后，不要放前面

- <strong>运动前长时间静态拉伸</strong>（每次保持 30 秒以上、总时长较长）会<strong>暂时降低力量输出和爆发力</strong>，而且<strong>不减少运动损伤</strong>。
- <strong>运动后做静态拉伸</strong>更合适（肌肉温热、放松效果更好），有助于<strong>改善柔韧性、缓解紧张感</strong>。
- 具体做法见 [拉伸怎么做](/entry/stretching/)。
- <strong>例外</strong>：如果某个关节活动度明显受限、影响动作质量，可以在热身中做<strong>短时间</strong>的针对性拉伸（每次 10–15 秒）。

### 3. 避免受伤：真正的关键是"训练量"

<strong>热身只能减少一部分风险，训练安排才是决定性的。</strong>

- <strong>循序渐进</strong>：<strong>每周训练量（时间、距离、重量）增加不超过约 10%</strong>。这是最被广泛引用的经验法则（数值本身有争议，但"渐进"这个方向证据充分）。
- <strong>不要"周末集中补"</strong>：平时不动、周末猛练是<strong>受伤率最高</strong>的模式。宁可<strong>每周 3 次各 30 分钟</strong>。
- <strong>保证睡眠</strong>：睡眠不足会降低<strong>肌肉力量、反应速度和协调性</strong>，也影响恢复。
- <strong>安排恢复日</strong>：同一肌群<strong>至少间隔 48 小时</strong>再练下一次力量训练。
- <strong>不要带着疼痛硬练</strong>：区分"肌肉酸"和"关节/肌腱痛"（见下）。
- <strong>注意动作质量</strong>：宁可减轻重量，也不要动作变形。<strong>疲劳时的动作变形是受伤的常见时机。</strong>
- <strong>环境与装备</strong>：地面、鞋子、光线；跑鞋见 [跑鞋怎么选](/entry/running-shoes/)。

### 4. 分清"正常的酸痛"和"受伤的信号"

| 感觉 | 通常是 | 怎么处理 |
| --- | --- | --- |
| <strong>运动后 24–48 小时肌肉酸痛、按压酸、活动后减轻</strong> | 延迟性肌肉酸痛（DOMS），<strong>正常</strong> | 轻度活动、热敷、正常恢复 |
| <strong>运动中某个点突然"扎"一下的锐痛</strong> | <strong>可能是拉伤/撕裂</strong> | <strong>立即停止</strong>，休息、冷敷，必要时就医 |
| <strong>关节内部的痛、卡住、打软腿、肿胀</strong> | <strong>不是正常反应</strong> | <strong>停练并就医</strong> |
| <strong>肌腱部位（如跟腱、髌腱）持续隐痛、晨起明显、活动后稍减轻</strong> | 可能是肌腱病 | 减量；<strong>持续 2 周不缓解就就医</strong> |
| <strong>疼痛在训练中逐渐加重、需要停下来</strong> | 警示信号 | 减量或停练，评估原因 |
| <strong>麻、刺痛、放射到肢体</strong> | 可能神经受压 | 就医 |

<strong>一个简单判断</strong>：<strong>疼痛在热身和活动后减轻、且不加重 → 多为正常；疼痛在活动中加重或出现锐痛、肿胀 → 停练。</strong>

### 5. 常见运动的具体注意点

- <strong>跑步</strong>：逐步加距离、别突然换跑量或路面；见 [跑步怎么不伤膝](/entry/running-knee-health/)。
- <strong>力量训练</strong>：先学动作再加重；<strong>深蹲、硬拉等动作一开始最好有人指导</strong>；见 [力量训练怎么入门](/entry/strength-training/)。
- <strong>球类</strong>：<strong>变向和落地是受伤高发动作</strong>，热身要有侧向移动和落地练习。
- <strong>爬山/徒步</strong>：下坡对膝和股四头肌负荷大，要有准备和装备（见 [怎么开始爬山或徒步](/entry/hiking-basics/)）。
- <strong>久不运动的人重新开始</strong>：<strong>从实际能力的一半开始</strong>，第一周宁少勿多。

## 健康原理

- <strong>为什么热身能减少损伤</strong>：升温会<strong>提高肌肉的黏弹性</strong>（更不易撕裂）、<strong>加快神经传导和肌肉募集</strong>（反应更快）、<strong>增加关节滑液分泌</strong>、<strong>提高心率与血流</strong>（为运动做准备）。这些是生理性的保护作用。
- <strong>为什么"动态"优于"静态"（运动前）</strong>：静态拉伸会让肌肉在<strong>被拉长的状态下持续一段时间</strong>，产生<strong>暂时的力量下降</strong>（可测，通常持续数十分钟到 1 小时），而且多项研究显示<strong>运动前静态拉伸并不减少整体损伤率</strong>。动态热身则在<strong>活动范围内反复收缩</strong>，既升温又激活，更接近运动本身的需求。
- <strong>为什么"周末运动员"风险高</strong>：组织（肌肉、肌腱）对负荷有<strong>适应过程</strong>。平时不加负荷、周末突然大量，<strong>组织的承受能力没有跟上负荷速度</strong>，因此更容易损伤。这是"训练量突然增加"是主要风险因素的机制。
- <strong>为什么 10% 法则被反复引用</strong>：它把"渐进"量化成一个可执行的规则。<strong>具体数值有争议</strong>（不同组织适应速度不同），但<strong>"负荷增加速度决定损伤风险"这个方向是一致的</strong>。
- <strong>为什么疲劳时容易受伤</strong>：肌肉疲劳后<strong>力量输出下降、本体感觉和协调变差</strong>，动作控制变差，此时负荷仍施加在组织上，就更容易超出安全范围。<strong>这也是为什么大重量训练要在状态好时做。</strong>
- <strong>为什么睡眠不足会增加受伤风险</strong>：睡眠不足会降低<strong>肌肉力量和爆发力、反应时间、注意力</strong>，并影响<strong>组织修复</strong>（生长激素主要在深睡眠分泌）。多项研究显示睡眠不足与运动损伤率升高相关。
- <strong>为什么标 B</strong>："热身提高体温与神经肌肉激活""训练量骤增是主要风险因素""睡眠与损伤相关"都有<strong>较充分的研究支持</strong>（接近 A）；但<strong>具体热身动作对损伤率的量化影响、10% 法则的确切数值</strong>缺少统一结论。综合 B。

## 常见误区

- <strong>"运动前要好好静态拉伸"</strong>：<strong>运动前长时间静态拉伸会暂时降低力量和爆发力，且不减少损伤</strong>。改成动态热身，静态拉伸放运动后。
- <strong>"热身就是随便动两下"</strong>：需要达到<strong>微微出汗、心率上升</strong>，并针对今天的运动。
- <strong>"不热身直接上大重量也行"</strong>：风险明显增加，尤其<strong>冷天和早晨</strong>（组织温度低）。
- <strong>"酸痛说明练到位，要继续"</strong>：<strong>锐痛、关节痛、肿胀不是酸</strong>，继续练会加重损伤。
- <strong>"拉伸能预防所有损伤"</strong>：不能。<strong>训练量和恢复才是主要因素。</strong>
- <strong>"周末补上平时没做的运动"</strong>：这是<strong>受伤率最高</strong>的模式。
- <strong>"疼了吃止痛药继续练"</strong>：掩盖信号会让损伤加重（尤其<strong>骨折、肌腱撕裂</strong>）。
- <strong>"出汗多说明效果好"</strong>：出汗是散热，与效果不完全相关。
- <strong>"必须练到力竭才有效"</strong>：力竭不是必需，<strong>且显著增加受伤和过度训练风险</strong>。
- <strong>"肌肉越大越不容易受伤"</strong>：肌肉量有保护作用，但<strong>力量、动作质量和负荷管理更重要</strong>。
- <strong>"年轻不会受伤"</strong>：任何年龄都可能受伤，年轻人<strong>恢复快但风险仍在</strong>。

## 风险与禁忌

- <strong>出现以下情况立即停止运动并就医</strong>：胸痛、明显气短、头晕、晕厥、心悸、突发剧烈头痛。
- <strong>关节肿胀、卡住、打软腿、明显不稳定</strong> → 停练并就医（可能有韧带或半月板损伤）。
- <strong>听到"啪"的响声伴锐痛</strong> → 立即停止、制动、冷敷并就医。
- <strong>有心血管疾病、高血压未控制、糖尿病</strong>的人：开始新运动计划前咨询医生，必要时先做运动风险评估。
- <strong>感冒发热期间不要运动</strong>（尤其伴发热、肌肉酸痛），有诱发心肌炎的风险。
- <strong>孕期</strong>：避免仰卧起坐、跳跃、有跌倒风险的运动；需医生确认可做的强度。
- <strong>骨质疏松、关节置换术后、近期骨折</strong>：训练方案必须由医生或治疗师制定。
- <strong>不要用止痛药掩盖疼痛继续训练</strong>。
- <strong>不要在极端高温或潮湿环境下做高强度运动</strong>（中暑风险）。
- <strong>不要为了减重而在空腹状态下做高强度训练</strong>并长时间不补水。
- <strong>不要在酒精或镇静药物影响下运动</strong>。

## 何时求助专业人士

- <strong>疼痛持续超过 2 周不缓解</strong>，或反复出现同一部位疼痛 → 骨科或运动医学科。
- <strong>关节明显肿胀、活动受限、打软腿</strong> → 尽快就医。
- <strong>想开始系统训练但不知道怎么安排</strong> → 找有资质的教练或运动康复师做一次评估。
- <strong>有旧伤或慢性病</strong>想恢复运动 → 康复科或运动医学科制定方案。
- <strong>运动中出现胸闷、心悸、异常气短</strong> → <strong>立即停止并就诊</strong>（心内科）。
- <strong>减肥与运动结合的具体安排</strong> → 营养科或运动医学（见 [减重怎么减才不反弹](/entry/weight-loss-basics/)）。
