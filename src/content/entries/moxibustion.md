## 适用人群

- 手脚怕冷、想用<strong>局部温热</strong>缓解不适的人
- 已经排除器质性疾病之后的<strong>慢性肌肉酸痛</strong>
- <strong>胎位不正</strong>的孕妇（<strong>必须在产科医生知情与监测下</strong>，由专业人员操作）

<strong>不适合自行艾灸的人</strong>：

- <strong>糖尿病患者</strong>（尤其有周围神经病变、足部感觉减退）
- 有<strong>感觉减退</strong>的其他原因（脊髓损伤、周围神经病、老年人皮肤感觉迟钝）
- <strong>孕妇</strong>（腹部、腰骶部，以及某些被认为应避开的穴位）
- 皮肤有破损、感染、瘢痕的部位
- <strong>呼吸道疾病患者</strong>（哮喘、慢阻肺）——艾烟会刺激
- 婴幼儿（皮肤薄、无法表达，极易烫伤）
- 服用抗凝药者（虽主要是热损伤，但破损后出血风险高）

## 具体做法

| 项目 | 建议 |
| --- | --- |
| 距离 | 艾条与皮肤保持 <strong>3–5 厘米</strong>，以<strong>温热舒适不灼痛</strong>为准 |
| 时间 | 单次同一部位 <strong>10–15 分钟</strong>；不是越久越好 |
| 姿势 | <strong>坐着或躺着</strong>做，不要站着，防止头晕时跌倒 |
| 通风 | <strong>必须开窗或开排气扇</strong>——这一条最容易被忽略 |
| 灭火 | 用<strong>专用灭火罐或密闭金属容器</strong>，不要用水冲完就丢 |
| 检查皮肤 | 做完<strong>对着镜子看</strong>皮肤：发红是正常的，<strong>起水疱、发白、焦痂就是烫伤</strong> |
| 感觉测试 | 感觉迟钝的人<strong>不要自己操作</strong>，也不要用"我觉得不烫"来判断 |

<strong>隔物灸</strong>（隔姜、隔蒜、隔盐）温度不易控制，<strong>不建议在家自行尝试</strong>。

<strong>艾灸盒/艾灸仪</strong>：温度相对可控、烟雾较少，比手持艾条安全一些；但<strong>仍然会烫伤</strong>，仍要定时检查皮肤。

## 健康原理

<strong>证据最强的一个用途是矫正胎位不正</strong>：多项临床试验（包括随机对照）报告艾灸至阴穴可以提高臀位转为头位的比例。这也是艾灸少有的、被较严格的试验支持过的适应症。即便如此，<strong>它仍需在产科监测下进行</strong>，因为胎位问题的处理涉及分娩安全。

<strong>用于疼痛和怕冷</strong>：有一些研究报告了改善，但普遍样本小、难设盲（热感无法伪装）、随访短。所以这些用途整体只能给 <strong>C 级</strong>。

<strong>温热本身的作用是真实的</strong>：局部加热可以改善肌肉的血流、降低肌张力、减轻主观疼痛感。这个效果热敷、热水袋、暖宝宝同样能给——<strong>不需要烟，也不需要"灸"的形式</strong>。

<strong>艾烟不是"无害的香气"</strong>：艾条燃烧会产生颗粒物（PM）和多种有机物，浓度在密闭小房间里可以相当高。长期在通风不良的室内艾灸，对呼吸道是一种负担，<strong>哮喘患者尤其要注意</strong>。

## 常见误区

- <strong>"艾烟能杀菌、消毒空气"</strong> —— 燃烧确实能减少部分微生物，但<strong>同时产生大量颗粒物</strong>。用熏艾来"消毒"房间，收益远小于对呼吸道的刺激。呼吸道疾病患者应避免。
- <strong>"烫出泡才有效"</strong> —— <strong>这是错的，而且危险</strong>。化脓灸是特定条件下的专业操作，<strong>不是在家艾灸的目标</strong>。起疱说明烫伤了。
- <strong>"越烫越好、越久越有效"</strong> —— 温度与时间与疗效没有确定的剂量关系，但<strong>与烫伤风险是明确的正相关</strong>。
- <strong>"艾灸可以天天做"</strong> —— 同一部位连续做，皮肤没有恢复时间，容易积累损伤。
- <strong>"糖尿病也能艾灸，注意点就行"</strong> —— 糖尿病周围神经病变的<strong>核心问题就是感觉不到烫</strong>。这类人群自行艾灸的烫伤风险最高，应避免。

## 风险与禁忌

| 风险 | 说明 |
| --- | --- |
| <strong>烫伤</strong> | 最常见也最严重。艾条燃烧端温度可达数百度，可造成<strong>深二度烧伤和永久瘢痕</strong> |
| <strong>感觉迟钝者的隐性烫伤</strong> | 糖尿病患者可能<strong>完全没有痛觉</strong>，发现时已是深度损伤 |
| <strong>呼吸道刺激</strong> | 艾烟含颗粒物与刺激性有机物，可诱发咳嗽、哮喘发作 |
| <strong>火灾</strong> | 未完全熄灭的艾条/艾灰可引燃垃圾桶、床单。<strong>必须用金属容器密闭熄灭</strong> |
| <strong>烫伤后感染</strong> | 水疱破溃后感染，糖尿病患者可能发展为严重软组织感染 |

<strong>绝对不要做的</strong>：

- 在<strong>密闭卧室</strong>里长时间艾灸
- 在<strong>床上、沙发上</strong>艾灸（睡着了或倾倒就是火灾）
- 把还在冒烟的艾条丢进<strong>塑料垃圾桶</strong>
- 让<strong>感觉减退的人独自</strong>艾灸
- 在<strong>孕妇腹部、腰骶部</strong>自行艾灸

## 何时求助专业人士

- <strong>起水疱、皮肤发白或发黑、有焦痂</strong> —— 这是烫伤，面积大或深时立即就医
- 烫伤部位<strong>红肿扩大、流脓、发热</strong> —— 感染
- <strong>咳嗽加重、喘息、胸闷</strong>（艾烟诱发）
- <strong>孕妇</strong>：胎动异常、腹痛、阴道流血流液
- 任何<strong>不明原因的疼痛或怕冷</strong> —— 先查原因。持续怕冷可能是<strong>甲状腺功能减退、贫血</strong>等需要治疗的问题，艾灸不会解决它

<strong>一句话建议</strong>：艾灸能提供<strong>局部温热</strong>，这个作用是真实的，但热敷也能给；<strong>它的额外风险（烫伤、烟、火灾）主要来自形式和操作，不在"艾"本身</strong>。要在家做，就把通风、定时、检查皮肤这三件事做到位。
