## 适用人群

- <strong>慢性非特异性腰痛</strong>（没有明确器质性病因）的人
- <strong>久坐、肌肉紧张</strong>导致的不适
- 想通过放松缓解压力、改善睡眠的人
- 已确诊、经医生同意后作为<strong>辅助</strong>手段的人

<strong>不适合推拿的情况（重要）</strong>：

- <strong>骨质疏松</strong>（尤其绝经后女性、长期用激素者）——手法可致压缩性骨折
- <strong>脊柱肿瘤、结核、感染</strong>——按摩可能造成病理性骨折或扩散
- <strong>腰椎间盘突出急性期伴神经症状</strong>
- 正在服用<strong>抗凝药</strong>的人（软组织血肿风险）
- <strong>颈椎</strong>：有椎动脉供血不足、颈椎不稳、类风湿累及颈椎者
- 皮肤有感染、破损、血栓性静脉炎的部位

## 具体做法

| 项目 | 建议 |
| --- | --- |
| 先诊断 | <strong>先看医生排除器质性问题</strong>，带着诊断去做推拿 |
| 说明病情 | 主动告知：骨质疏松、肿瘤病史、抗凝药、既往骨折 |
| 力度 | <strong>以舒适为度</strong>。"越疼越有效"是错的，疼痛是身体在报警 |
| <strong>拒绝颈部扳法</strong> | 明确说<strong>不要做颈椎旋转扳法</strong>（那条"咔"的声音不值得冒险） |
| 频率 | 每周 1–2 次，<strong>2–4 周评估是否有效</strong>，无效就别继续 |
| 之后 | 配合<strong>运动与力量训练</strong>——长期靠按摩是维持不住的 |
| 场所 | 正规医疗机构或有资质的推拿师；避免在无资质场所做"正骨" |

<strong>评估是否有效</strong>：看<strong>功能</strong>（能不能弯腰系鞋带、久坐能坚持多久）而不是只看"当时舒服"。

## 健康原理

<strong>短期有效、长期证据不足</strong>——这是按摩类疗法在腰痛上的总体图景：

1. <strong>短期（数天到数周）</strong>：多份系统评价报告按摩能减轻疼痛、改善功能，效果与热敷、物理治疗、运动等常见手段<strong>大致相当</strong>，没有哪种明显更好。
2. <strong>长期（数月以上）</strong>：效果通常<strong>消失</strong>，与对照组无差别。所以不能靠按摩维持。
3. <strong>机制</strong>：主要是<strong>机械刺激与温热</strong>带来的肌肉放松、局部血流改善，加上<strong>一对一关注与躺卧休息</strong>的效应。这与针灸的情况类似——过程本身就有作用。
4. <strong>为什么它"感觉有效"</strong>：腰痛本身波动很大，多数发作会自行缓解。在症状高峰期做任何事，都会感觉"做了之后好多了"。

<strong>为什么仍然值得做</strong>：如果它能帮你度过急性期、让你有精力去运动，那就有价值。<strong>关键是别停在按摩上</strong>——腰痛长期管理的核心是<strong>运动与力量训练</strong>。

## 常见误区

- <strong>"按得越重、越疼越有效"</strong> —— 疼痛是组织受损的信号。重手法会加重软组织损伤，在骨质疏松者身上可造成骨折。
- <strong>"脖子响一下就好了"</strong> —— <strong>颈椎高速旋转扳法与椎动脉夹层、后循环脑卒中相关</strong>。这类事件罕见，但一旦发生后果严重（可致永久神经损伤）。<strong>没有证据表明那声响本身有治疗价值。</strong>
- <strong>"推拿能把突出的椎间盘按回去"</strong> —— 没有这回事。突出的椎间盘不会因为外力按压而复位。
- <strong>"长期按摩能治好腰痛"</strong> —— 长期效果没有证据支持。有效的是<strong>运动与力量训练</strong>。
- <strong>"按摩没有风险"</strong> —— 见上一节。风险虽不常见，但<strong>在骨质疏松、抗凝药、肿瘤病史人群中显著升高</strong>。

## 风险与禁忌

| 风险 | 说明 |
| --- | --- |
| <strong>椎动脉夹层 / 脑卒中</strong> | 与<strong>颈椎旋转扳法</strong>相关。可表现为颈部疼痛、头晕、复视、说话不清、肢体无力 |
| <strong>骨折</strong> | <strong>骨质疏松</strong>者受压可致肋骨或椎体骨折 |
| <strong>软组织损伤与血肿</strong> | 力度过大，或服用抗凝药者 |
| <strong>神经损伤</strong> | 压迫周围神经可致麻木、无力 |
| <strong>延误诊断</strong> | 反复按摩掩盖病情——最隐蔽的风险 |
| <strong>病理性骨折</strong> | 脊柱有肿瘤转移或感染时 |

<strong>必须避免</strong>：

- 对<strong>颈椎</strong>做高速旋转扳法
- 在<strong>骨质疏松、肿瘤病史、抗凝治疗</strong>者身上做重手法
- 在<strong>急性外伤、怀疑骨折、发热</strong>的情况下推拿
- 让非专业人员做"正骨""复位"

## 何时求助专业人士

<strong>推拿后立即就医的情况</strong>：

- <strong>颈部疼痛伴头晕、复视、说话不清、面部或肢体麻木无力</strong> —— <strong>立刻急诊</strong>（警惕椎动脉夹层与脑卒中）
- <strong>剧烈疼痛加重</strong>，或出现<strong>下肢麻木无力、大小便功能障碍</strong> —— <strong>急诊</strong>（警惕马尾综合征）
- <strong>呼吸困难、胸痛</strong>（肋骨骨折可能）

<strong>先看医生而不是先按摩的情况</strong>：

- 腰痛伴<strong>发热、体重下降、夜间痛醒</strong>
- 有<strong>肿瘤病史</strong>
- <strong>外伤后</strong>的腰痛
- 年龄 <strong>50 岁以上首次发作</strong>的腰痛
- <strong>长期用激素或有骨质疏松</strong>

<strong>长期管理请记住</strong>：腰痛最有效的长期手段是<strong>运动与力量训练</strong>（见「腰痛怎么办」）。<strong>按摩可以是入口，但不能是终点。</strong>
