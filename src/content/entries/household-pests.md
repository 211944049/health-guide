## 适用人群

- 谁适合照做：家里出现蟑螂、蚂蚁、蚊虫、衣蛾、书虫等害虫的人；租房族；有婴幼儿、孕妇的家庭；过敏或哮喘患者（蟑螂是重要过敏原来源）；住在一楼或老房子的人。
- 谁不适用：这条是<strong>家庭害虫处理常识</strong>。<strong>被叮咬或接触后出现明显过敏反应（呼吸困难、面部肿胀）</strong>时应立即就医。<strong>鼠患、白蚁、臭虫（床虱）严重</strong>建议直接找专业机构。

## 具体做法

### 1. 顺序不能颠倒：先断水断粮，再封堵，最后用药

<strong>这是整篇最重要的一句话。</strong> 大多数人上来就买杀虫剂，但：

- <strong>杀虫剂杀的是"现在这些"</strong>，只要食物和水还在，新的还会来。
- <strong>断绝食物和水"减少的是环境承载力"</strong>，是真正的根本措施。

<strong>建议顺序</strong>：

1. <strong>断水断粮</strong>（最关键）
2. <strong>封堵通道</strong>
3. <strong>点施药剂</strong>（胶饵为主）
4. <strong>持续观察与补施</strong>

### 2. 第一步：断水断粮（蟑螂尤其有效）

蟑螂能<strong>一个月不吃东西仍存活，但没有水只能活一周左右</strong>——所以<strong>水比食物更重要</strong>。

- <strong>睡前擦干水槽、台面、浴缸</strong>，不留积水；
- <strong>修好漏水的水龙头和管道</strong>（漏水处是蟑螂的稳定水源）；
- <strong>垃圾每天清、垃圾桶带盖</strong>，厨余不过夜；
- <strong>食物密封存放</strong>（包括宠物粮）；
- <strong>台面、灶台、地面</strong>每天擦，尤其油渍；
- <strong>不要留脏碗过夜</strong>；
- <strong>纸箱、报纸、旧衣物不要堆存</strong>（蟑螂喜欢在纸板和缝隙里栖息）。

### 3. 第二步：封堵通道

- <strong>管道穿墙的缝隙</strong>（水槽下、洗手盆下、燃气管道）用玻璃胶或水泥封堵；
- <strong>门缝加装密封条</strong>（尤其入户门、厨房门）；
- <strong>墙洞、瓷砖裂缝、踢脚线缝隙</strong>修补；
- <strong>地漏换成防虫型</strong>，保持水封（长期不用时定期注水，否则水封干涸就成了通道）；
- <strong>纱窗破损处修补</strong>；
- <strong>快递纸箱不要带进家</strong>（蟑螂和虫卵常随纸箱进入）。

### 4. 第三步：用药——优先「胶饵」，慎用「喷雾」

| 类型 | 效果 | 风险与说明 |
| --- | --- | --- |
| <strong>胶饵（点施）</strong> | <strong>首选</strong>。蟑螂取食后回窝死亡，同类分食形成连锁杀灭 | 点在缝隙、角落，少量多点；避免儿童宠物接触 |
| <strong>粘捕屋/蟑螂屋</strong> | 用于监测和减少数量 | 无毒，适合有幼儿家庭；也用来判断"还有没有" |
| <strong>粉剂/颗粒剂</strong> | 有效，但需注意防潮和误食 | 放在儿童宠物够不到的位置 |
| <strong>喷雾杀虫剂</strong> | <strong>效果最差</strong> | 只能杀看到的个体，<strong>会惊扰蟑螂使其扩散到其他房间</strong>；吸入风险大 |
| <strong>蚊香/电蚊香</strong> | 驱蚊有效 | 需通风；有哮喘、婴幼儿、孕妇时慎用 |
| <strong>"全屋熏蒸"</strong> | 需专业人员操作 | <strong>自行熏蒸非常危险</strong>，绝不建议 |

<strong>为什么胶饵优于喷雾</strong>：蟑螂是<strong>群居且有分食习性</strong>（包括取食同伴尸体和排泄物）。胶饵利用这一点实现"连锁杀灭"；而喷雾会驱散种群、让问题扩散，且对躲在缝隙里的个体无效。

<strong>有婴幼儿、孕妇、哮喘患者的家庭</strong>：优先用<strong>粘捕屋 + 封堵 + 断水断粮</strong>；如必须用药，选胶饵并点在绝对接触不到的位置。

### 5. 不同害虫的重点不一样

| 害虫 | 关键措施 |
| --- | --- |
| <strong>蟑螂</strong> | 断水最重要；胶饵；封堵管道缝隙 |
| <strong>蚂蚁</strong> | 追踪路线找到入口并封堵；用<strong>胶饵型蚁药</strong>（不要用喷雾，会分散巢群） |
| <strong>蚊虫</strong> | <strong>清除积水</strong>（花盆托盘、空调水盘、地漏）——没有积水就没有幼虫；纱窗；蚊帐 |
| <strong>衣蛾/皮蠹</strong> | 洗净干燥 + 密封收纳，参考[换季衣服怎么收纳防霉防虫](/entry/clothing-storage/) |
| <strong>果蝇</strong> | 及时清理果皮和厨余；垃圾带盖；醋+洗洁精诱捕 |
| <strong>书虫/衣鱼</strong> | 降低湿度（它们喜潮湿）；清理纸张堆存；通风 |
| <strong>潮虫（鼠妇）</strong> | 降低湿度和清理室外落叶堆积；封堵门缝 |
| <strong>鼠患</strong> | <strong>建议直接找专业机构</strong>；自行处理难以根治且有咬伤、传播疾病风险 |

### 6. 处理后的观察

- <strong>用粘捕屋做监测</strong>：连续几天没捕到，说明数量已明显下降。
- <strong>持续 2–4 周复施胶饵</strong>（蟑螂有卵鞘，孵化周期约数周，一次处理通常不够）。
- <strong>如果反复出现或整栋楼都有</strong> —— 这是<strong>楼栋层面</strong>的问题，需要联系物业做整体处理；单户处理只能缓解。

## 健康原理

<strong>① 害虫的健康风险主要是三类：过敏原、病原体媒介、以及杀虫剂本身的暴露。</strong> 理解这三条，就知道为什么"用最强的药"不是最优解。<sup class="ref-mark">[1][2][3][4][5][6][7][8]</sup>

<strong>蟑螂是重要的室内过敏原来源。</strong> 这一点常被低估：蟑螂的<strong>尸体、蜕皮、粪便和唾液</strong>中含有的蛋白质是明确的过敏原，与<strong>儿童哮喘发病和加重、过敏性鼻炎</strong>相关。美国 CDC 和多家过敏机构都把蟑螂列为室内过敏原控制的重点之一。<strong>这意味着"蟑螂多"本身就是一个呼吸道健康问题</strong>，而不仅是"脏"。也意味着<strong>处理时要注意清除尸体和排泄物残留</strong>（仅杀死成虫不够）。<sup class="ref-mark">[1][2][3][4][5][6][7][8]</sup>

<strong>为什么断水比断粮更有效。</strong> 蟑螂的耐饥能力很强（可数周不进食），但<strong>耐渴能力弱得多</strong>（通常一周左右）。所以在所有措施里，<strong>消除水源的边际效果最大</strong>。这个生理特点决定了优先级——它是"断水断粮"这个顺序的科学依据，而不是凭经验。<sup class="ref-mark">[1][2][3][4][5][6][7][8]</sup>

<strong>为什么胶饵能做到"连锁杀灭"。</strong> 蟑螂有<strong>食粪性（coprophagy）</strong>和取食同伴尸体的习性，同时是群居昆虫。缓效型胶饵让取食个体回到藏身处才死亡，其尸体和排泄物中的有效成分被同类取食，从而实现种群层面的下降。<strong>关键在"缓效"</strong>——速效药会让蟑螂死在开阔处，反而减少传递。这也解释了为什么<strong>喷雾效果差</strong>：它只作用于可见个体，而且其驱避性会<strong>使种群扩散</strong>，把局部问题变成全屋问题。<sup class="ref-mark">[1][2][3][4][5][6][7][8]</sup>

<strong>为什么喷雾对健康的直接风险更高。</strong> 喷雾型杀虫剂的暴露途径是<strong>吸入和皮肤接触</strong>，且喷洒范围大、残留面广。拟除虫菊酯类对哺乳动物毒性较低，但<strong>气溶胶颗粒可刺激呼吸道</strong>，对哮喘患者、婴幼儿尤其不友好。而胶饵是<strong>点施、封闭、低挥发</strong>的剂型，暴露量小得多。<strong>所以"胶饵优先"同时改善了有效性和安全性</strong>——两者方向一致，这在健康建议里并不常见。<sup class="ref-mark">[1][2][3][4][5][6][7][8]</sup>

<strong>为什么蚊虫靠"清积水"就能解决大半。</strong> 蚊子的幼虫阶段（孑孓）<strong>必须在水中发育</strong>。所以任何持续积水都是繁殖源——花盆托盘、空调接水盘、废弃容器、堵塞的排水沟。<strong>"清除积水"直接切断生命周期</strong>，比杀成虫有效得多。这也是 WHO 病媒生物综合管理（IVM）强调"环境治理优先于化学杀虫"的原因。<sup class="ref-mark">[1][2][3][4][5][6][7][8]</sup>

<strong>为什么反复出现说明是楼栋问题。</strong> 蟑螂和鼠类通过<strong>管道井、公共管沟、楼道</strong>在户间迁移。单户清理后，邻居或公共区域仍会持续输入。<strong>这个结构性特点决定了单户措施有其上限</strong>，需要物业层面的整体处理才能真正解决。理解这一点能避免"我已经很努力了还是没用"的挫败。<sup class="ref-mark">[1][2][3][4][5][6][7][8]</sup>

<strong>为什么专业处理更划算（对鼠患、白蚁、臭虫）。</strong> 这三类的共同点是<strong>栖息在难以触及的位置</strong>（墙体内部、地板下、床架缝隙），且<strong>繁殖周期短、扩散快</strong>。自行处理通常只能触及表面，反复投入的时间和药剂成本可能超过一次专业处理。此外鼠类有咬伤和传播疾病风险，白蚁有结构安全风险。<sup class="ref-mark">[1][2][3][4][5][6][7][8]</sup>

<strong>证据等级为什么是 C。</strong> 「蟑螂过敏原与哮喘相关」「清除积水可减少蚊虫繁殖」「胶饵优于喷雾（连锁杀灭与扩散问题）」这些有机制依据、行业实践和机构指南支持（CDC、EPA 的 IPM 指南、WHO 的 IVM）。但<strong>「家庭自防措施能把害虫密度降低多少、进而改善多少健康结局」缺乏高质量的对照研究</strong>——多数证据来自害虫防制的专业实践而非临床研究；不同药剂在真实家庭环境中的效力比较数据也有限。所以定在 C 级。<sup class="ref-mark">[1][2][3][4][5][6][7][8]</sup>

## 常见误区

- <strong>误区：直接买最强的杀虫剂喷一遍。</strong> 喷雾<strong>只杀可见个体，且会驱散种群使问题扩散</strong>，同时吸入风险大。应先用胶饵 + 断水断粮 + 封堵。
- <strong>误区：蟑螂药放得越多越好。</strong> 胶饵要<strong>少量多点</strong>（放在缝隙、角落）；堆一大坨反而效果差（蟑螂不喜在显眼处取食）。
- <strong>误区：杀虫剂气味越大越有效。</strong> 气味与效力无关，只与刺激性有关。
- <strong>误区：杀光看到的就没事了。</strong> <strong>蟑螂有卵鞘</strong>，孵化周期约数周；需要<strong>持续 2–4 周复施</strong>才能覆盖。
- <strong>误区：蟑螂只和"不干净"有关。</strong> 干净的家也可能有蟑螂——它们会随<strong>纸箱、快递、管道</strong>进入，且能在缺水前存活很久。<strong>整洁降低承载力，但密封和封堵同样重要。</strong>
- <strong>误区：蟑螂只是恶心，不影响健康。</strong> 它是<strong>明确的室内过敏原</strong>，与儿童哮喘和鼻炎相关。<strong>处理时也要清除尸体、蜕皮和粪便残留。</strong>
- <strong>误区：灭蚊靠点蚊香就行。</strong> <strong>清除积水才是根本</strong>——没有水就没有幼虫。蚊香是补充手段。
- <strong>误区：用了药就不用管环境了。</strong> 食物和水还在，新的会持续进来。<strong>环境治理是根本，药剂是加速手段。</strong>
- <strong>误区：自己处理鼠患。</strong> 鼠患涉及咬伤和疾病传播风险，且有结构性问题（鼠道、缝隙），<strong>建议找专业机构</strong>。
- <strong>误区：家里有虫说明我生活习惯差。</strong> 住一楼、老房子、楼栋整体有虫、快递带入都是常见原因。<strong>这是环境问题，不是道德问题。</strong>
- <strong>误区：全屋熏蒸一次解决。</strong> 自行熏蒸<strong>非常危险</strong>（易燃、毒性、需撤离），且对卵鞘无效。需要时应由专业机构操作。

## 风险与禁忌

- <strong>有婴幼儿、孕妇、哮喘或过敏患者的家庭</strong>：优先用<strong>粘捕屋 + 封堵 + 断水断粮</strong>；如必须用药，选胶饵并点在接触不到的位置；<strong>避免喷雾和蚊香</strong>（呼吸道刺激）。
- <strong>绝对不要自行做全屋熏蒸</strong>（熏蒸剂有毒、易燃，需要专业防护和撤离安排）。
- <strong>杀虫剂不要与食品、餐具、宠物粮放在一起</strong>；使用后洗手，喷过的台面要擦净。
- <strong>不要把杀虫剂装在饮料瓶里</strong>（误服是儿童中毒的常见原因）。
- <strong>不要在密闭、无人的室内长时间使用蚊香或电蚊香</strong>；使用后通风。
- <strong>拟除虫菊酯对猫毒性较高</strong>，养猫家庭使用含此类成分的产品需格外注意。
- <strong>不要混用不同杀虫剂</strong>，也不要在同一处叠加使用多种药剂。
- <strong>清理害虫尸体、粪便和蜕皮时要戴口罩和手套</strong>（减少过敏原吸入），处理完洗手；<strong>过敏或哮喘者不要亲自清理</strong>。
- <strong>出现以下情况立即就医</strong>：被叮咬或接触后出现<strong>呼吸困难、面部或喉部肿胀、全身皮疹</strong>（严重过敏反应）；<strong>被鼠类咬伤</strong>（需评估狂犬病和破伤风）；<strong>杀虫剂误服或出现头晕、恶心、流涎、瞳孔异常</strong>（可能中毒）。
- <strong>不要在室内随意使用"强力灭虫烟雾弹"</strong>，尤其有呼吸道疾病患者时。
- <strong>鼠患、白蚁、臭虫（床虱）严重时不要拖延</strong> —— 鼠患涉及疾病，白蚁涉及结构安全，臭虫扩散极快。
- <strong>如果家中同时有大量霉斑和害虫</strong>，说明湿度问题严重，应一并处理，参考[租房怎么防霉](/entry/mold-prevention/)与[湿度多少合适](/entry/humidity/)。

## 何时求助专业人士

出现以下情况先看医生，不要只靠本文：

- <strong>被昆虫叮咬后出现呼吸困难、面部或喉部肿胀、全身皮疹、头晕</strong> —— 可能是严重过敏反应，<strong>立即就医</strong>。
- <strong>被鼠类咬伤或抓伤</strong> —— <strong>立即就医</strong>，需评估狂犬病暴露处置和破伤风，<strong>不要自行处理伤口后观察</strong>。
- <strong>误服杀虫剂，或使用后出现头晕、恶心、呕吐、流涎、瞳孔缩小/异常、肌肉抽搐</strong> —— <strong>立即就医并带上产品包装</strong>。
- <strong>使用杀虫剂后出现持续咳嗽、喘息、胸闷</strong> —— 立即离开该环境并就医（哮喘患者尤其紧急）。
- <strong>反复出现鼻塞、夜间咳嗽、喘息、皮疹，且与家中环境相关</strong> —— 建议做过敏原评估，蟑螂和尘螨是常见室内过敏原，参考[空气净化器怎么选](/entry/air-purifier-choice/)。
- <strong>儿童反复喘息或哮喘控制不佳</strong> —— 建议评估居家过敏原（蟑螂、尘螨、霉菌），参考[租房怎么防霉](/entry/mold-prevention/)。
- <strong>整栋楼普遍有蟑螂或鼠患</strong> —— 联系物业处理；协商不成可向当地卫生健康部门（病媒生物防制）或街道办事处反映。
- <strong>怀疑是白蚁或臭虫（床虱）</strong> —— 建议直接联系专业防治机构，自行处理通常无法根治且会扩散。
- <strong>租房中害虫问题房东不处理</strong> —— 可依据租赁合同协商；涉及公共区域可要求物业介入，必要时咨询当地住房管理部门。
