## 适用人群

- 谁适合照做：所有需要自己刷牙的人；牙龈容易出血、刷牙时酸痛的人；戴固定矫治器（牙套）、有种植牙或烤瓷冠的人；手部活动不便或握力差的人；给孩子买牙刷的家长。
- 谁不适用：这条是<strong>工具选择与使用常识</strong>。<strong>牙龈持续出血、牙齿松动、遇冷热剧痛</strong>时应就医，换牙刷解决不了这些问题，参考[口腔怎么护理](/entry/oral-care/)。

## 具体做法

### 1. 选牙刷：三个硬指标

<strong>① 软毛</strong>

- <strong>这是最重要的一条。</strong> 硬毛配合「用力横刷」是<strong>楔状缺损</strong>（牙颈部凹槽）和<strong>牙龈萎缩</strong>的主要成因，而这两者<strong>不可逆</strong>。
- 很多人选硬毛是想要「刷得干净」的感觉，但清洁力来自<strong>刷毛能否到达牙龈沟</strong>，而不是硬度。
- <strong>牙龈出血时也不要改用硬毛「刷干净」</strong>——出血通常说明牙龈有炎症，应先看牙医，改用软毛并<strong>减力</strong>。

<strong>② 刷头要小</strong>

- 标准是<strong>能轻松刷到最后那颗磨牙的内侧面</strong>。刷头太大就刷不到，这是最常被忽略的漏刷位置。
- 儿童要用<strong>儿童专用小头</strong>，成人牙刷在孩子嘴里等于「刷不到后牙」。

<strong>③ 刷毛顶端要圆钝</strong>

- 磨圆率不合格的刷毛会划伤牙龈。<strong>选正规品牌</strong>（国标对磨圆率有要求），不要买来源不明的廉价牙刷。

### 2. 电动还是手动

| | 手动 | 电动 |
| --- | --- | --- |
| <strong>清洁效果</strong> | 方法正确时很好 | <strong>不比正确的手动刷牙更有效</strong> |
| <strong>适合谁</strong> | 能掌握巴氏刷牙法的人 | <strong>刷牙技巧差、手部不便、握力差、戴牙套、行动不便的人</strong> |
| <strong>要注意</strong> | 容易用力过度、时间不足 | 同样要覆盖每个面，<strong>不要用力压</strong> |

<strong>结论</strong>：电动牙刷的价值主要在<strong>帮做不到正确手动刷牙的人达到及格线</strong>（定时、有压力提示），而不是「升级」。<strong>手动的关键是方法，不是工具。</strong> 参考[口腔怎么护理](/entry/oral-care/)里的巴氏刷牙法。

### 3. 什么时候换

- <strong>每 3 个月</strong>，或<strong>刷毛变形就换</strong>——两个条件哪个先到就换。
- <strong>为什么是 3 个月</strong>：刷毛会疲劳、散开、顶端变毛糙，清洁效率和温和性都下降。
- <strong>生病后换一次</strong>（感冒、口腔感染后），减少再次接触病原体。
- <strong>不要用消毒方式「延长寿命」</strong>：微波炉、洗碗机、开水煮会损坏刷毛和刷柄。<strong>常规清水冲洗、竖立晾干即可。</strong>
- <strong>刷毛变色≠该换的唯一标准</strong>，重点是形态。

### 4. 平时怎么维护

- <strong>用后清水冲净刷毛根部</strong>（牙膏和食物残渣会积在毛根）。
- <strong>竖立放在通风处</strong>，不要放进密闭盒子里捂着（潮湿利于细菌繁殖）。
- <strong>不要和家人共用</strong>，也不要让刷头互相接触。
- <strong>不要用牙刷去刷别的</strong>（洗鞋、清理缝隙），那会污染刷毛。
- <strong>旅行盒只在路上用</strong>，到家就拿出来晾。

### 5. 特殊情况的调整

| 情况 | 建议 |
| --- | --- |
| <strong>牙龈敏感、刷牙酸痛</strong> | 软毛 + <strong>减力</strong>（用力只需「让刷毛轻触牙龈」的力度），必要时就医查牙龈退缩或楔状缺损 |
| <strong>戴固定矫治器（牙套）</strong> | 正畸专用小头刷 + 牙缝刷；电动牙刷可选（有帮助，但不能替代牙缝清洁） |
| <strong>种植牙、烤瓷冠</strong> | 软毛 + 牙缝刷/冲牙器清洁冠与牙龈交界处；<strong>不要用硬毛</strong> |
| <strong>手部活动不便、握力差</strong> | 加粗手柄、加长手柄或电动牙刷；也可考虑儿童款（柄粗） |
| <strong>口干（药物或疾病引起）</strong> | 软毛 + 更勤的清洁；口干会显著增加龋齿风险，应就医评估 |
| <strong>儿童</strong> | 儿童专用小头软毛；<strong>3 岁以下用米粒大小含氟牙膏，3–6 岁用豌豆大小</strong>，家长要监督和补刷 |

## 健康原理

<strong>牙刷的作用机制只有一个：把刷毛送到牙菌斑所在的位置，靠机械摩擦把它破坏掉。</strong> 所有选购与使用建议都可以从这一条推出来。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>① 为什么是机械摩擦而不是「刷掉脏东西」。</strong> 牙菌斑是细菌在牙面形成的<strong>生物膜</strong>，黏附力很强，<strong>漱口、冲水、含漱口水都冲不掉</strong>，必须靠物理摩擦破坏其结构。这就是为什么「软毛不沾水也刷得干净」和「硬毛用力反而有害」同时成立——决定效果的是<strong>刷毛有没有到达并摩擦到牙菌斑</strong>，而不是力度或水量。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>② 牙龈沟才是关键位置。</strong> 牙菌斑最密集的地方是<strong>牙龈与牙齿的交界处（牙龈沟）</strong>，而这里恰好是硬毛最容易造成伤害的地方。这就是巴氏刷牙法要求刷毛与牙面成 45°、小幅颤动的原因——让软毛的<strong>尖端</strong>进入沟内，而不是用硬毛去「刮」。硬毛 + 用力会把这个交界处磨出楔状缺损，并让牙龈向根方退缩，<strong>暴露的牙颈部没有釉质保护，会更敏感、更容易龋</strong>。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>③ 为什么刷头大小是硬指标。</strong> 后牙的内侧面和最后一颗磨牙的远中面是解剖上最难到达的位置。刷头过大时，<strong>刷毛在口腔内无法转向</strong>，这些位置必然漏刷。而龋齿和牙周病的高发部位恰恰在后牙。所以「刷头小」不是舒适性偏好，而是<strong>覆盖能力的物理约束</strong>。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>④ 电动牙刷的价值在「替代技巧」而不在「更强动力」。</strong> Cochrane 系统评价的结论是：电动牙刷（尤其旋转振动型）在短期内比手动牙刷多去除少量牙菌斑、减少少量牙龈炎，但<strong>长期临床结局（如龋齿、牙齿保留）的差异并不明确</strong>。所以它的实际价值是<strong>帮助做不到正确手动刷牙的人达到及格线</strong>（有定时、有压力提示），而不是让技巧已经正确的人「再上一层楼」。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>⑤ 为什么 3 个月要换。</strong> 刷毛是聚合物纤维，反复受力后会<strong>疲劳、张开、顶端磨损</strong>。散开的刷毛<strong>接触牙龈沟的能力下降</strong>（够不到沟内），同时变毛糙的顶端<strong>摩擦刺激增加</strong>。所以换牙刷的理由是<strong>清洁效率与温和性同时下降</strong>，而不是「细菌多」——顺便说明：刷毛上的细菌主要来自你自己的口腔，<strong>不会因此生病</strong>，所以「3 个月」不是卫生阈值。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>⑥ 为什么不要用微波炉/开水消毒。</strong> 刷柄多为塑料，刷毛为尼龙，两者都不耐高温，加热会使其变形。变形后的刷毛既刷不干净也更容易刺激牙龈。<strong>保持干燥和通风是更有效的做法</strong>（多数细菌繁殖需要潮湿环境）。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>证据等级为什么是 B。</strong> 分两部分：<strong>「软毛优于硬毛」「刷头大小影响覆盖」「用力横刷造成楔状缺损」「3 个月更换」</strong> 有口腔医学共识、材料学依据和国标（磨圆率等）支持，方向明确。<strong>电动与手动的比较有 Cochrane 系统评价</strong>，结论也清楚（差别有限）。但<strong>「具体更换周期」没有人做过临床结局研究</strong>——它是从刷毛疲劳特性推出的合理推荐值；「沾不沾水」这一类更是<strong>没有证据支持的民间说法</strong>。所以整体定在 B 级，并把无证据的部分明确标出来。<sup class="ref-mark">[1][2][3][4][5]</sup>

## 常见误区

- <strong>误区：硬毛刷得更干净。</strong> 清洁力来自刷毛能否进入牙龈沟，不是硬度。硬毛 + 用力是<strong>不可逆损伤</strong>的主因。
- <strong>误区：牙刷千万不能沾水。</strong> <strong>没有研究支持。</strong> 沾水的真实影响是泡沫更多，而泡沫多的代价是容易提前停手。<strong>按舒适度决定，但别缩短时间。</strong>
- <strong>误区：牙龈出血要换硬毛刷「刷干净」。</strong> 出血通常提示牙龈炎症，应<strong>就医 + 改软毛 + 减力</strong>，硬毛会加重。
- <strong>误区：电动牙刷一定比手动好。</strong> 对<strong>技巧正确</strong>的人，差异很小；它的价值是帮做不到的人达标。
- <strong>误区：刷毛没散开就不用换。</strong> 顶端磨损和刷毛疲劳可能先于「散开」出现。
- <strong>误区：牙刷用开水烫或微波炉消毒更卫生。</strong> 会损坏刷毛和刷柄，反而影响清洁并伤牙龈。
- <strong>误区：刷完放进密闭牙刷盒最卫生。</strong> 潮湿密闭环境利于微生物繁殖。<strong>应竖立通风晾干。</strong>
- <strong>误区：孩子用成人牙刷就行，反正要家长帮忙。</strong> 刷头过大必然刷不到后牙。应用<strong>儿童专用小头</strong>。
- <strong>误区：刷头越贵/越大越好。</strong> 大小要匹配口腔，材质要软毛且磨圆率合格，与价格无关。
- <strong>误区：牙刷可以和家人混用或放在同一个杯子里碰着。</strong> 会交叉传播口腔微生物，尤其有牙周病或口腔感染时。

## 风险与禁忌

- <strong>不要用硬毛牙刷</strong>，尤其已有<strong>牙龈退缩、楔状缺损、牙颈部敏感</strong>的人。
- <strong>不要把牙刷泡在开水里、微波炉加热、或放进洗碗机</strong>——会造成刷毛和刷柄变形。
- <strong>不要与他人共用牙刷</strong>，也不要在同一个杯子里让刷头互相接触。
- <strong>牙龈持续出血、牙齿松动、遇冷热剧痛、口腔有持续溃疡或白斑</strong> —— 这些<strong>不是换牙刷能解决的</strong>，应尽快就诊。
- <strong>刚吃了酸性食物（柑橘、碳酸饮料、醋）后不要立刻刷牙</strong>——此时牙釉质较软，刷牙会加速磨损。先用清水漱口，约 30 分钟后再刷。
- <strong>戴固定矫治器、种植牙、烤瓷冠的人</strong>不要用硬毛或强力冲牙模式，可能损伤矫治器或冠边缘，应咨询医生选具体工具。
- <strong>刷牙用力到刷毛明显外翻</strong>说明力度过大，长期会造成不可逆损伤，应立刻减力。
- <strong>不要把牙刷用于清洁其他物品</strong>，也不要让孩子把牙刷当玩具啃咬。
- <strong>婴幼儿的牙刷由家长保管和操作</strong>，避免孩子单独使用造成误吞或损伤；参考[口腔怎么护理](/entry/oral-care/)中儿童部分。
- <strong>出现以下情况尽快就诊</strong>：牙龈自发出血、口腔内出现<strong>超过 2 周不愈的溃疡</strong>、口腔内新出现的白斑或红斑、牙齿明显松动。

## 何时求助专业人士

出现以下情况先看医生，不要只靠本文：

- <strong>刷牙时牙龈持续出血超过 1–2 周</strong> —— 需评估牙龈炎或牙周炎，参考[口腔怎么护理](/entry/oral-care/)。
- <strong>牙齿遇冷、热、甜、酸时明显酸痛，或咬东西时疼痛</strong> —— 可能是龋齿、牙颈部暴露或牙髓问题，尽快就诊。
- <strong>牙齿松动、牙龈退缩、牙缝变大、口臭持续</strong> —— 提示牙周病，需要专业治疗（不可逆，越早越好）。
- <strong>口腔内出现超过 2 周不愈合的溃疡、白斑、红斑或肿块</strong> —— <strong>尽快就诊排除恶性病变</strong>。
- <strong>刷牙时刷毛大量出血、牙龈自发出血</strong> —— 尽快就诊。
- <strong>戴固定矫治器、有种植牙或烤瓷冠，不确定该用什么工具</strong> —— 咨询你的正畸或修复医生。
- <strong>手部活动不便、握力差，或照顾行动不便的家人</strong> —— 可咨询康复治疗师或牙科护士，有专用的加粗手柄和电动刷具。
- <strong>儿童刷牙困难、拒绝刷牙、牙齿有白斑或黑点</strong> —— 建议儿童牙科就诊，并咨询适合的工具与含氟牙膏用量。
- <strong>口干明显（药物副作用、干燥综合征等）</strong> —— 口干会显著提高龋齿风险，应就医评估并制定更密的清洁方案。
