## 适用人群

- 家里的洗衣机、饮水机、冰箱、抽油烟机从没彻底清过的人。
- 有过敏性鼻炎、哮喘、反复皮肤问题的人。
- 有婴幼儿、老人、免疫低下者的家庭。
- 合租、共用家电的人。

<strong>先给结论</strong>：<strong>家电清洁的重点不是"擦得亮"，而是"保持干燥、去掉生物膜"。</strong> 最容易被忽略、也最影响健康的是这四台：<strong>洗衣机、饮水机、冰箱、抽油烟机</strong>。

## 具体做法

### 1. 洗衣机（最容易被忽略、影响最大）

- <strong>洗衣槽（内筒和外筒之间）</strong>是皮屑、洗涤剂残留、水垢和生物膜的聚集处，<strong>你平时看不到</strong>。这就是"洗完衣服有异味""衣服洗完还发痒"的常见原因。
- <strong>每 1–3 个月做一次槽清洁</strong>：用洗衣机槽清洁剂或<strong>含氧漂白剂</strong>（不是含氯的，避免腐蚀），选<strong>最高水位 + 最高水温</strong>运行一个完整周期。
- <strong>洗完衣服不要马上关盖</strong>，开盖通风让内筒干燥。
- <strong>洗完立刻取出衣物</strong>，不要闷在机里过夜。
- <strong>过滤网（如有）每次用完清一次</strong>。
- <strong>密封圈（滚筒门胶圈）</strong>翻开擦拭，这里是霉斑重灾区；已发黑发霉且擦不掉的建议更换。
- <strong>洗衣机不要放在潮湿不通风的角落</strong>；排水管要保证通畅、不倒吸。

### 2. 饮水机

- <strong>内胆和管路</strong>长期存水，是生物膜的位置。<strong>每 1–2 个月按说明清洁消毒一次</strong>，消毒后<strong>必须用清水彻底冲洗干净</strong>再使用。
- <strong>桶装水开封后建议 7 天内喝完</strong>（放得越久菌量越高）。
- <strong>加热内胆定期除垢</strong>；出水口、接水盘每次清洁。
- <strong>不用时拔电、倒空余水</strong>。
- 更完整的做法见 [饮水机怎么清洁](/entry/water-dispenser-cleaning/)。

### 3. 冰箱

- <strong>冷藏室每周擦拭一次</strong>（尤其搁架、抽屉、密封条）。<strong>密封条的褶皱</strong>要翻开擦。
- <strong>生熟分开</strong>：生肉、生海鲜放<strong>下层</strong>并用密闭容器，避免汁液滴落污染。
- <strong>不要让食物贴住后壁</strong>（会结冰并影响冷气循环）。
- <strong>定期除霜</strong>（如有霜）：霜层过厚影响效率。
- <strong>冷藏 4 ℃ 以下、冷冻 −18 ℃ 以下</strong>；剩菜<strong>2 小时内</strong>放入冰箱，<strong>3–4 天内吃完</strong>。
- <strong>不要塞太满</strong>，影响冷气流通。
- <strong>冰箱不是保险箱</strong>：李斯特菌等能在低温下生长，<strong>孕妇、老人、免疫低下者尤其要注意即食食品的存放时间</strong>。

### 4. 抽油烟机

- <strong>油网每 1–2 个月清洗一次</strong>（油垢是火灾隐患，也影响排烟效率）。
- <strong>风轮和内部</strong>建议每年专业清洗一次。
- <strong>做饭前先开、做完再延时运行几分钟</strong>。
- <strong>必须保持厨房通风</strong>（有窗就开窗）。
- 更完整的做法见 [厨房油烟怎么处理](/entry/kitchen-fumes/)。

### 5. 其他常见家电

| 家电 | 清洁频率 | 重点位置 |
| --- | --- | --- |
| 微波炉 | 每周 | 内壁、门封、转盘；<strong>加热时盖盖</strong>减少飞溅 |
| 电饭锅 | 每次用后 | 内胆、<strong>上盖内侧密封圈</strong>（很容易发霉） |
| 电热水壶 | 每 1–2 周除垢 | 底部水垢（柠檬酸或白醋） |
| 豆浆机/破壁机 | 每次用后 | <strong>刀座密封圈</strong>（拆开洗） |
| 冰箱门封 | 每周 | 褶皱 |
| 空气净化器 | 每 2–4 周 | 前置滤网；<strong>HEPA 和活性炭按说明更换</strong>（不能洗） |
| 洗碗机 | 每 1–2 个月 | 滤网、喷淋臂、门封 |
| 扫地机器人 | 每次用后 | 滚刷、边刷、尘盒、拖布 |
| 咖啡机 | 每月 | 管路除垢 |

### 6. 通用原则（记这四条就够）

1. <strong>能拆开洗的都要拆开洗</strong>——密封圈、滤网、集水盘、接水盒，这些是藏污处。
2. <strong>洗后必须彻底干燥</strong>——潮湿是下一次污染的开始。
3. <strong>清洁剂不要混用</strong>（含氯 + 酸性 = 氯气，见 [清洁剂怎么用安全](/entry/cleaning-products/)）。
4. <strong>耗材按时换</strong>，不要"看起来还能用"就继续用（滤芯、密封圈、拖布）。

## 健康原理

- <strong>共同机制：水 + 温度 + 有机物 = 生物膜</strong>。家电里凡是<strong>长期存水、又温暖、又有皮屑或食物残留</strong>的地方（洗衣槽、饮水机内胆、冰箱密封条、油烟机油网、咖啡机管路），都会形成<strong>生物膜</strong>——微生物分泌胞外聚合物把自己黏附在表面。<strong>生物膜一旦形成，简单冲洗是去不掉的</strong>，必须靠机械刷洗或化学清洁剂分解。
- <strong>为什么"看起来干净"不等于卫生</strong>：生物膜和霉菌常出现在<strong>看不见的缝隙和背面</strong>（内筒夹层、密封圈褶皱、管路内壁）。所以清洁的重点是<strong>拆开可拆部件</strong>，而不是擦表面。
- <strong>为什么干燥如此重要</strong>：微生物需要水分。<strong>保持干燥是最有效、最便宜、最容易被忽略的一步</strong>。洗衣机开盖、饮水机倒空、餐具沥干，都是在破坏这个条件。
- <strong>冰箱为什么不是"保险箱"</strong>：低温<strong>抑制</strong>多数细菌，但<strong>李斯特菌、耶尔森菌等嗜冷菌仍能生长</strong>。而且冷藏只是减缓，不是停止。所以"放进冰箱就安全"是错的，<strong>存放时间</strong>才是关键变量。
- <strong>洗衣机与皮肤问题</strong>：洗衣槽生物膜和洗涤剂残留会附着在衣物纤维上。<strong>对皮肤敏感、湿疹、婴幼儿</strong>来说，这可能成为持续的刺激或过敏来源。<strong>"衣服洗完还痒"要先查洗衣机。</strong>
- <strong>油烟机油垢为什么是安全问题</strong>：油垢可燃，积累在油烟机和管道内是<strong>厨房火灾的常见起因</strong>。所以清洗油网既是卫生问题，也是消防问题。
- <strong>为什么标 C</strong>：清洁频率与卫生状况之间的关系<strong>机制清楚</strong>，也符合公共卫生共识；但"家电清洁频率"的具体数值缺少对照研究，且各家电差异大，多来自厂商建议与实践经验。方向可靠、数值是经验值，因此 C。

## 常见误区

- <strong>"洗衣机洗衣服，自己就干净了"</strong>：恰恰相反。<strong>洗衣槽是家里最容易藏污的地方之一</strong>，且你平时看不到。
- <strong>"用含氯消毒液洗洗衣机最好"</strong>：不要。含氯消毒剂会<strong>腐蚀金属部件</strong>，且与洗涤剂混用有风险。用<strong>含氧漂白剂或专用槽清洁剂</strong>。
- <strong>"饮水机有加热功能，所以是安全的"</strong>：加热不能替代清洁。<strong>内胆和管路的生物膜一直在</strong>。
- <strong>"冰箱温度低，放多久都行"</strong>：<strong>李斯特菌等嗜冷菌能在低温下生长</strong>，存放时间才是关键。
- <strong>"微波炉擦一下里面就够了"</strong>：<strong>门封条和边缘缝隙</strong>也要擦，残渣会持续滋生。
- <strong>"空气净化器滤芯可以洗洗再用"</strong>：<strong>HEPA 不能洗</strong>，洗过会破坏纤维结构、效率骤降。按说明更换。
- <strong>"抽油烟机油网不用常洗"</strong>：既影响排烟，也是<strong>火灾隐患</strong>。
- <strong>"家电清洁剂越强越好"</strong>：越强往往刺激性和腐蚀性越大。<strong>先按说明书</strong>，并注意通风和手套。
- <strong>"所有家电都能用同一种清洁剂"</strong>：不同材质和部件要求不同。<strong>先在不起眼处试</strong>，避免腐蚀涂层、密封圈和屏幕。

## 风险与禁忌

- <strong>绝对不要把含氯消毒剂与酸性清洁剂混用</strong>（如洁厕灵、醋、除垢剂）——会释放氯气。
- <strong>不要用含氯消毒剂清洁洗衣机金属内筒和饮水机内胆</strong>（腐蚀 + 残留）。
- <strong>清洁后必须彻底冲洗</strong>，尤其饮水机、电热水壶、咖啡机、豆浆机（残留会随饮食摄入）。
- <strong>清洁电器前先断电</strong>；不要用湿手插拔；不要向通电部件直接喷水。
- <strong>拆装按说明书</strong>，不要强行拆解密封结构（装不回会导致漏水、漏电）。
- <strong>有婴幼儿、孕妇、免疫低下者的家庭</strong>：冰箱即食食品存放时间要更严格；饮水机清洁更频繁。
- <strong>清洁剂注意通风、戴手套</strong>；避免混用；原包装存放、远离儿童。
- <strong>不要把清洁剂装进饮料瓶</strong>（误服是真实且严重的风险）。
- <strong>出现霉味、漏水、异常响声、异味</strong>：停用并检修，不要"用完这次再说"。

## 何时求助专业人士

- 家人出现<strong>不明原因的反复腹泻、呕吐、发热</strong>，且与某台家电（饮水机、冰箱、洗衣机）使用相关——先停用可疑家电并就医，必要时取样送检。
- <strong>洗衣机洗完的衣服导致反复皮肤瘙痒、皮疹</strong>，更换洗涤剂无效——考虑洗衣槽深度清洁或更换密封圈；皮肤症状持续请看皮肤科。
- <strong>饮水机/净水器出水有异味、出水变慢</strong>——需要专业检修或更换滤芯（见 [净水器怎么选](/entry/water-purifier-choice/)）。
- <strong>家电出现漏电感觉、跳闸、异味、冒烟</strong>——立即断电并请专业维修，不要自行拆修。
- <strong>空调、抽油烟机风管长期未清洗</strong>——需要专业机构（见 [空调怎么用才健康](/entry/air-conditioner-use/)）。
- 婴幼儿或老人出现<strong>持续腹泻、发热</strong>——及时就医，并回顾近期饮食与饮水来源。
