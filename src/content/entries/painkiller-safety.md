## 适用人群

- 谁适合照做：家里常备止痛药的人；经常头痛、牙痛、关节痛、痛经的人；需要给老人或孩子用药的人；正在服用其他药物的人。
- 谁不适用：这条是<strong>用药安全常识</strong>，不能替代诊疗。<strong>持续或反复疼痛</strong>应先明确原因，而不是长期靠止痛药压住。<strong>有胃溃疡、严重肾病、心血管病、孕晚期、肝病</strong>的人必须遵医嘱。

## 具体做法

### 1. 先分清两类药：它们的风险完全不同

| | 对乙酰氨基酚（扑热息痛） | 布洛芬 / 双氯芬酸 / 阿司匹林等（NSAIDs） |
| --- | --- | --- |
| 主要作用 | 退热、镇痛 | 退热、镇痛、<strong>抗炎</strong> |
| 主要风险 | <strong>肝损伤（超量时）</strong> | <strong>胃损伤、肾损伤、心血管风险</strong> |
| 是否伤胃 | 基本不伤胃 | <strong>会伤胃</strong>，需饭后吃 |
| 适合 | 头痛、发热、一般疼痛 | 炎症性疼痛（扭伤、关节炎、痛经） |
| 不适合 | 严重肝病、长期大量饮酒 | <strong>胃溃疡、严重肾病、心血管病、孕晚期</strong> |

<strong>选药的第一个问题是"这是炎症性疼痛吗"</strong>：扭伤、关节炎、痛经通常更适合 NSAIDs；单纯头痛、发热用对乙酰氨基酚即可，副作用更小。

### 2. 三条最重要的安全规则

<strong>① 不要超过说明书剂量，也不要缩短间隔</strong>

- <strong>对乙酰氨基酚</strong>：成人单次不超过说明书规定量，<strong>24 小时内总量有上限</strong>（通常 3–4 克，很多指南建议不要长期用到上限）。<strong>超量会造成严重肝损伤，且早期可能没有症状。</strong>
- <strong>布洛芬</strong>：按说明书剂量和间隔使用，<strong>不要因为"没效果"就提前加量或缩短间隔</strong>。
- <strong>不要同时吃两种含相同成分的药。</strong>

<strong>② 警惕「隐形叠加」——这是最常见的伤害原因</strong>

<strong>很多复方感冒药、退烧药、止咳药里已经含有对乙酰氨基酚。</strong> 如果你吃了感冒药又吃止痛药，很容易在不知不觉中超过每日上限。

<strong>做法</strong>：吃药前<strong>看清通用名</strong>（不是商品名）。凡是成分表里出现「对乙酰氨基酚」「扑热息痛」「acetaminophen」「paracetamol」的，都算同一种药，<strong>不能叠加</strong>。

<strong>③ 不要长期自行服用</strong>

- <strong>NSAIDs 连续使用一般不建议超过几天</strong>（具体按说明书和医生指示）。
- 长期使用会增加胃出血、肾损伤和心血管事件风险。
- <strong>疼痛持续超过 1–2 周，应该去看医生找原因</strong>，而不是继续加量吃止痛药。

### 3. 这些情况要特别小心

| 情况 | 注意 |
| --- | --- |
| <strong>胃溃疡、胃出血史</strong> | 避免 NSAIDs；如必须用，需医生评估并可能加胃保护药 |
| <strong>慢性肾病、肾功能不全</strong> | 避免或慎用 NSAIDs，需医生评估 |
| <strong>心血管病、高血压</strong> | NSAIDs 可能升高血压并增加心血管风险，需医生评估 |
| <strong>肝病、长期大量饮酒</strong> | 慎用对乙酰氨基酚，<strong>每日上限要更低</strong> |
| <strong>孕晚期</strong> | <strong>避免 NSAIDs</strong>；孕期用药一律先问产科医生 |
| <strong>哮喘</strong> | 部分人服用 NSAIDs 会诱发哮喘发作，需注意 |
| <strong>正在服用抗凝药</strong> | NSAIDs 会增加出血风险，必须告知医生 |
| <strong>老年人</strong> | 肾功能和胃黏膜保护下降，用药应更保守 |
| <strong>儿童</strong> | 按<strong>体重</strong>计算剂量，不要用成人药减半；<strong>不要给儿童用阿司匹林</strong>（与瑞氏综合征相关） |

### 4. 怎么吃能减少副作用

- <strong>NSAIDs 饭后吃</strong>，可以减少胃部刺激（但不能完全避免胃损伤）。
- <strong>用最小有效剂量、最短必要时间</strong>。
- <strong>服药期间不要饮酒</strong>（尤其对乙酰氨基酚，会显著增加肝损伤风险）。
- <strong>多喝水</strong>，尤其使用 NSAIDs 时（有助于肾脏灌注）。
- <strong>不要空腹吃布洛芬</strong>，也不要和咖啡一起空腹吃。

### 5. 头痛要特别提醒：小心「药物过量性头痛」

<strong>频繁吃止痛药本身会引起头痛</strong>。如果一个月里服用止痛药<strong>超过 10 天</strong>（某些药物更低），可能形成药物过量性头痛：药效一过就痛，越吃越频繁。

<strong>处理方式</strong>：需要在医生指导下逐步停用，而不是继续加量。<strong>这是"越吃越痛"的典型机制，很多人不知道。</strong>

## 健康原理

<strong>两类止痛药的机制不同，所以风险也完全不同。</strong> 这是本篇所有建议的基础：<sup class="ref-mark">[1][2][3][4][5]</sup>

- <strong>对乙酰氨基酚</strong>主要作用于中枢，抑制前列腺素合成，<strong>抗炎作用弱</strong>，但<strong>不损伤胃黏膜、不影响肾功能和血小板</strong>。它的风险集中在<strong>肝脏</strong>：正常剂量下安全，但<strong>超量时会产生毒性代谢产物（NAPQI）</strong>，当谷胱甘肽被耗竭后就会造成肝细胞坏死。<strong>关键在于"超量"往往是无意的</strong>——因为复方感冒药里含有它，叠加就超了。
- <strong>NSAIDs（布洛芬等）</strong> 通过抑制环氧化酶（COX）减少前列腺素合成，<strong>抗炎效果强</strong>。但前列腺素同时负责<strong>保护胃黏膜、维持肾血流、调节血小板功能</strong>，所以抑制它就会带来三类风险：<strong>胃损伤、肾损伤、出血倾向</strong>。此外 NSAIDs 还可能通过影响血管和钠水潴留<strong>升高血压、增加心血管事件风险</strong>。这解释了为什么"胃病、肾病、心血管病"人群要慎用。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>为什么"看通用名"是最有效的防错方法。</strong> 复方感冒药的<strong>商品名五花八门</strong>（各种"感冒灵""退热贴"），但成分表会写出通用名。只要认准「对乙酰氨基酚」，就能识别出重复用药。<strong>这是零成本、且能防止最危险一类错误的方法</strong>——因为对乙酰氨基酚过量早期没有明显症状，等出现症状时肝损伤可能已经明显。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>为什么"最小有效剂量、最短时间"是通用原则。</strong> 止痛药的作用是<strong>缓解症状</strong>，不治疗病因。长期使用意味着：① 药物累积风险上升；② 真正的病因被掩盖而延误诊断。所以"能不用就不用、能用小的不用大的、能短期不长期"是有依据的。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>为什么会形成药物过量性头痛。</strong> 频繁使用止痛药会导致中枢痛觉调节系统的适应性改变（与受体下调、神经递质变化有关），停药后出现反跳性头痛，形成"吃药—缓解—更痛—再吃药"的循环。它有一个<strong>明确的诊断线索：每月用药天数过多</strong>。所以本篇给出天数阈值，因为这是识别它的关键。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>为什么儿童不能用阿司匹林。</strong> 儿童在病毒感染（如流感、水痘）期间使用阿司匹林，与<strong>瑞氏综合征</strong>相关——一种可致命的急性脑病和肝脂肪变性。这是一个罕见但后果严重的关联，所以形成了明确的禁忌。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>证据等级为什么是 B。</strong> 两类药物的作用机制、对乙酰氨基酚的肝毒性阈值、NSAIDs 的胃肠道和肾脏风险、以及瑞氏综合征的关联，都有大量药理学研究和监管机构文件支持，且各国药监部门的警示高度一致——这部分证据很强。但<strong>具体到"某个人该用哪种、用多少天"仍高度个体化</strong>，部分风险（如 NSAIDs 的心血管风险幅度）在不同研究和人群中结论不完全一致，所以整体定在 B 级。<sup class="ref-mark">[1][2][3][4][5]</sup>

## 常见误区

- <strong>误区：止痛药都一样，随便买一种。</strong> 两类药机制和风险完全不同，选择取决于疼痛类型和个人疾病史。
- <strong>误区：疼得厉害就多吃一片。</strong> <strong>提前加量或缩短间隔是造成肝损伤和胃损伤的常见原因</strong>，绝不可取。
- <strong>误区：中药止痛药没有副作用。</strong> 部分中成药含对乙酰氨基酚或其他成分，同样存在超量和相互作用风险；某些含马兜铃酸的中药还有肾毒性。
- <strong>误区：感冒药和止痛药可以一起吃。</strong> 这正是<strong>对乙酰氨基酚叠加超量</strong>的典型场景，必须核对成分。
- <strong>误区：布洛芬伤胃，那就空腹吃减少负担。</strong> 恰恰相反，<strong>NSAIDs 应饭后吃</strong>。
- <strong>误区：止痛药会上瘾，所以尽量别用。</strong> 对乙酰氨基酚和 NSAIDs <strong>不属于阿片类，没有成瘾性</strong>。合理使用是安全的，不必因恐惧而忍受疼痛。
- <strong>误区：痛经忍忍就好，吃药对身体不好。</strong> 痛经多与前列腺素相关，<strong>NSAIDs 正是对症治疗</strong>，在无禁忌的情况下合理使用是恰当的。
- <strong>误区：孩子按成人剂量减半就行。</strong> 儿童剂量应按<strong>体重</strong>计算，且部分药物（如阿司匹林）禁用。
- <strong>误区：吃止痛药期间喝点酒没关系。</strong> 对乙酰氨基酚 + 酒精会<strong>显著增加肝损伤风险</strong>，是明确的禁忌组合。

## 风险与禁忌

- <strong>对乙酰氨基酚</strong>：<strong>不要超过每日上限</strong>；肝病、长期大量饮酒者需更低剂量；<strong>不要与含同成分的复方药同服</strong>；服药期间禁酒。
- <strong>NSAIDs</strong>：胃溃疡或胃出血史、严重肾病、心血管病、孕晚期、阿司匹林哮喘人群<strong>避免或严格遵医嘱</strong>；不要与抗凝药同用（须先问医生）。
- <strong>儿童禁用阿司匹林</strong>（病毒感染期间），避免瑞氏综合征。
- <strong>孕期</strong>：一律先咨询产科医生；<strong>孕晚期避免 NSAIDs</strong>。
- <strong>哺乳期</strong>：需咨询医生后再用。
- <strong>不要自行长期服用</strong>：NSAIDs 连续使用一般不超过几天；疼痛超过 1–2 周应就诊。
- <strong>不要与抗凝药、部分降压药、部分抗抑郁药同服而不告知医生</strong>（存在相互作用）。
- <strong>不要用止痛药掩盖需要急诊处理的疼痛</strong>：<strong>突发剧烈头痛、胸痛、腹痛、外伤后剧痛</strong>——立即就医，不要先吃药观察。
- <strong>药物过量须立即就医</strong>：对乙酰氨基酚过量<strong>早期可能无症状</strong>，但有特效解毒剂（乙酰半胱氨酸），<strong>越早用越有效</strong>。<strong>不要等待症状出现。</strong>
- <strong>不要把止痛药和其他药物长期混放</strong>，注意有效期并定期清理，参考[家里的药怎么存、怎么扔](/entry/medicine-storage/)。

## 何时求助专业人士

出现以下情况先看医生，不要只靠本文：

- <strong>突发剧烈头痛（"这辈子最厉害的一次"）、伴呕吐、意识改变、颈部僵硬</strong> —— <strong>立即就医</strong>，警惕颅内问题。
- <strong>胸痛、胸闷、放射到手臂或下颌的疼痛</strong> —— <strong>立即呼叫急救</strong>，不要先吃止痛药。
- <strong>突发剧烈腹痛</strong>，尤其伴发热、腹肌紧张 —— 尽快就医，<strong>不要用止痛药掩盖症状</strong>（会影响诊断）。
- <strong>服用对乙酰氨基酚过量</strong>（即使自我感觉正常）—— <strong>立即就医</strong>，带上药瓶。
- <strong>服用止痛药后出现黑便、呕血、剧烈胃痛</strong> —— 立即就医。
- <strong>疼痛持续超过 1–2 周，或反复发作</strong> —— 需要明确病因，而不是继续吃药。
- <strong>每月服用止痛药超过 10 天</strong> —— 可能已形成药物过量性头痛，需要医生指导。
- <strong>有胃溃疡、肾病、心血管病、肝病、哮喘，需要长期止痛</strong> —— 应由医生制定方案。
- <strong>孕期、哺乳期、儿童、老年人</strong>需要止痛 —— 先咨询医生或药师，参考[看医生前该准备什么](/entry/prepare-for-visit/)。
- <strong>不确定两种药能不能一起吃</strong> —— <strong>去药房问药师</strong>，这是免费的，比网上查更可靠。
