## 适用人群

- 刚开始跑步、不知道穿什么的人。
- 夏天运动后衣服黏身、冬天运动后发冷的人。
- 想买压缩衣、不确定有没有用的人。
- 健身房、球类、骑行等不同项目的运动者。

<strong>需要就医而非换衣服的情况</strong>：运动中出现胸痛、明显气短、头晕、关节疼痛——这些不是装备问题。

## 具体做法

### 1. 第一原则：别穿纯棉

| 材质 | 出汗时的表现 | 适合 |
| --- | --- | --- |
| 纯棉 | 吸汗但难干，湿后贴身、变重、发冷 | 极短、低强度活动 |
| <strong>聚酯（涤纶）</strong> | 导湿快干、轻 | <strong>大多数运动的首选</strong> |
| 锦纶（尼龙） | 柔软、弹性好、耐磨 | 紧身裤、泳装、外套 |
| 美利奴羊毛 | 吸湿、抑味、温度调节好 | 长距离、冷天，价格高 |
| 氨纶（莱卡） | 提供弹性，一般混纺 5–20% | 与上面几种混纺 |

<strong>判定方法</strong>：看吊牌成分表，聚酯/锦纶为主的通常是速干款；也可以看有没有标注吸湿速干性能标准。

### 2. 按运动类型选

| 运动 | 要点 |
| --- | --- |
| 跑步（暖天） | 背心或短袖速干上衣 + 短裤；<strong>浅色反光</strong>便于夜间被看见 |
| 跑步（冷天） | 分层：速干贴身层 + 薄抓绒/风衣；<strong>比静止时少穿一层</strong> |
| 健身房力量训练 | 弹性好的短裤或紧身裤 + 速干上衣；避免过松（器械夹挂风险） |
| 骑行 | <strong>紧身骑行裤（带坐垫）</strong>能显著减少会阴压迫和摩擦 |
| 游泳 | 泳衣贴合、减少水阻；训练款比时尚款耐用 |
| 球类 | 透气、活动不受限；注意场地要求（如室内鞋底） |
| 瑜伽、普拉提 | 贴身、不滑、不卷边 |

### 3. 三个容易被忽略的细节

1. <strong>接缝位置</strong>：跑步和骑行时，内侧接缝会摩擦皮肤。选平缝或无缝设计，长距离运动<strong>务必先试穿</strong>。
2. <strong>反光与可见性</strong>：夜跑穿浅色 + 反光条，这是安全问题，不是外观问题。
3. <strong>袜子</strong>：<strong>重要性高于上衣</strong>。选速干材质、无缝、贴合，避免纯棉（湿后易起水疱）。长距离和马拉松选手尤其重要。

### 4. 关于「压缩衣」

- <strong>运动表现</strong>：系统评价的总体结论是<strong>对成绩提升不明显</strong>，效果远小于宣传。
- <strong>恢复</strong>：运动后穿压缩衣对肌肉酸痛（DOMS）的影响，研究结果<strong>不一致且效应很小</strong>。
- <strong>可能有实际价值的地方</strong>：减少晃动带来的不适、长距离骑行与会阴压迫、部分静脉功能不全者的压迫治疗（属于医疗用途）。
- <strong>结论</strong>：喜欢穿就穿，<strong>但不值得为「提高成绩」付高价</strong>。

### 5. 清洗与保养

- <strong>运动后尽快洗</strong>：汗渍和细菌会让织物发臭，且气味会在纤维里累积（聚酯尤其明显）。
- <strong>不要用柔顺剂</strong>：会在纤维表面形成膜，<strong>破坏导湿性能</strong>。
- <strong>不要用漂白剂和高温烘干</strong>：损伤弹性纤维。
- <strong>反面洗、阴干</strong>，能延长寿命。
- <strong>功能性服装的排汗性能会随使用下降</strong>，不是永久有效。

## 健康原理

- <strong>运动时体温调节的机制</strong>：运动产热可达静息时的 10 倍以上，身体靠<strong>出汗蒸发</strong>散热。汗液必须能蒸发才带走热量；如果衣服吸汗后贴在皮肤上，蒸发受阻，散热效率下降。
- <strong>为什么湿棉衣危险</strong>：棉吸水后导热率上升、且不易干，<strong>运动后停止产热时体温会快速下降</strong>，这在冬季户外是失温的常见诱因（见[保暖怎么穿](/entry/warmth/)）。
- <strong>摩擦与水疱</strong>：潮湿皮肤+反复摩擦是水疱的成因。速干材质能保持皮肤相对干燥，无缝设计减少摩擦点——<strong>这是运动服对预防水疱的真实贡献</strong>。
- <strong>压缩衣的可能机制</strong>：外部压力可能改善静脉回流、减少肌肉振动。理论上合理，但<strong>转化为成绩或恢复的效应量很小</strong>，这也是证据不一致的原因。
- <strong>为什么标 C</strong>：材质与热湿舒适性有实验证据，但「特定运动服能改善运动表现或降低损伤率」缺少高质量长期研究；压缩衣等热门宣称的系统评价多为阴性或不一致。方向（速干、不摩擦、合身）可靠，具体产品推荐证据薄弱。综合给出 C。<sup class="ref-mark">[1][2][3][4]</sup>

## 常见误区

- <strong>纯棉最舒服所以运动也穿</strong>：低强度短时间可以，<strong>出汗多或冷天一定要换速干材质</strong>。
- <strong>压缩衣能提升成绩、加速恢复</strong>：系统评价不支持明显的成绩提升效果，恢复方面的证据也不一致。
- <strong>出汗越多说明运动效果越好</strong>：出汗量主要反映环境和个体差异，不代表训练效果；大量出汗还意味着需要更注意补水。
- <strong>运动服要买贵的</strong>：基础速干功能在平价产品上就能实现；高价主要来自品牌、设计和特殊技术。
- <strong>穿塑料服/暴汗服减肥</strong>：减掉的是水分，不是脂肪，<strong>且有脱水和中暑风险</strong>，应避免。
- <strong>洗运动服和普通衣服一样</strong>：柔顺剂会破坏导湿性能，高温会损伤弹性纤维，应分开处理。
- <strong>冬天运动要穿厚</strong>：穿太厚会出汗，停下来更冷。<strong>分层、按活动量调整</strong>才对。
- <strong>「排酸」「燃脂」面料有效</strong>：这类宣称没有可靠证据，属于营销话术。

## 风险与禁忌

- <strong>高温高湿环境</strong>：穿不透气的衣物运动显著增加热病（热痉挛、热衰竭、热射病）风险。应选透气材质、避开高温时段、及时补水。
- <strong>寒冷环境</strong>：湿衣物 + 风是失温的高危组合，<strong>运动后要尽快换干衣</strong>。
- <strong>游泳、水上运动</strong>：普通速干衣不适合入水，需专业泳装或防寒服。
- <strong>皮肤疾病（如湿疹、股癣）</strong>：紧身、潮湿的衣物会加重，建议宽松、透气、及时更换。
- <strong>女性的运动内衣</strong>：<strong>支撑度是真实需求</strong>，不是可选装饰。不当支撑与乳房疼痛、运动不适相关，应选择与运动强度匹配的支撑等级。
- <strong>骑行长时间压迫</strong>：需选带合适坐垫的骑行裤，长时间骑行出现会阴麻木应调整车座或就医。
- <strong>不要为了「保暖」在运动中饮酒</strong>：酒精增加散热并影响判断。
- <strong>有心血管疾病、糖尿病者</strong>：运动装备无法替代运动前的医学评估和运动中的监测。

## 何时求助专业人士

- <strong>运动中出现胸痛、胸闷、明显气短、晕厥</strong>：<strong>立即停止并就医</strong>，这是危险信号。
- <strong>反复起水疱、皮肤破损</strong>：需评估鞋袜是否合适，糖尿病或循环不良者应尽快就医。
- <strong>持续关节或肌肉疼痛超过 2 周</strong>：建议运动医学科或康复科评估，不要只换装备硬扛。
- <strong>高温下运动后出现头晕、恶心、停止出汗、意识模糊</strong>：可能是热射病，<strong>属于急症，立即降温并呼叫急救</strong>。
- <strong>寒冷环境中出现寒战伴言语含糊、嗜睡</strong>：低温症，<strong>立即呼叫急救</strong>。
- <strong>女性运动时乳房明显疼痛</strong>：建议咨询专业人员选择合适的运动内衣，持续疼痛需乳腺外科评估。
