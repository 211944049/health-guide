## 适用人群

- 习惯"趁热喝"的人；每天喝很热的茶、水、汤、粥的人。
- 吃火锅、喝汤时习惯刚出锅就入口的人。
- 有食管癌家族史、长期吸烟饮酒的人（<strong>风险是叠加的</strong>）。
- 家里有老人习惯喝滚烫热茶的人。

<strong>以下情况不要用"改温度"来处理，应直接就医</strong>：已经出现吞咽困难、吞咽疼痛、胸骨后疼痛、不明原因体重下降。

## 具体做法

### 1. 判断标准只有一条：入口不烫、能连续喝

- 大约 <strong>65 ℃ 以上</strong>算"烫"。国际癌症研究机构把<strong>65 ℃ 以上的热饮</strong>列为 <strong>2A 类（很可能致癌）</strong>
- 实用判断：<strong>入口不烫、能一口接一口连续喝</strong>，这个温度就够安全了
- 不要凭"我觉得不烫"——长期吃烫食的人对温度的敏感度会下降，<strong>你的主观标准可能已经偏高了</strong>

### 2. 四个最常见的场景

| 场景 | 该怎么做 |
| --- | --- |
| <strong>热茶 / 热水</strong> | 倒出来后等 <strong>3–5 分钟</strong>；不要用保温杯长时间保持高温 |
| <strong>热汤 / 粥</strong> | 刚离火的温度远高于 65 ℃，盛出来先放一会儿 |
| <strong>火锅</strong> | 食材刚捞出时温度很高，尤其<strong>丸子和豆腐的内部</strong>——先放碗里、切开、等一会儿 |
| <strong>保温杯</strong> | 它保温的能力，也让液体长时间停在高温；喝之前先试试温度 |

### 3. 为什么"趁热吃"反而有风险

- 食管黏膜的<strong>耐受温度比口腔低</strong>，所以"嘴里不觉得烫"不代表食管没事
- 反复烫伤 → 慢性炎症 → 黏膜反复修复增生
- 长期热刺激会让<strong>温度感觉变迟钝</strong>，形成"越吃越烫"的循环

### 4. 顺带：这些也会增加食管癌风险

- <strong>吸烟</strong>、<strong>重度饮酒</strong>（与烫食叠加，不是互相替代）
- <strong>腌制、熏制食品</strong>（亚硝酸盐、多环芳烃）
- <strong>进食过快</strong>、食物过于粗糙
- 有食管癌家族史、或来自高发地区

## 健康原理

<strong>① 温度与组织损伤。</strong> 蛋白质在 60 ℃ 以上开始变性，细胞膜结构受损。黏膜上皮对温度敏感，温度越高、接触时间越长，损伤越明显。

<strong>② 为什么食管比口腔更脆弱。</strong> 口腔和舌能耐受的温度高于食管黏膜。所以"入口不烫"是很宽松的标准，而食管已经在承受更高的实际温度。

<strong>③ 慢性热损伤如何与癌症相关。</strong> 反复的黏膜损伤 → 修复性细胞增生 → 每次分裂都有突变机会。这是"慢性刺激促进癌变"的一般机制，不限于食管。

<strong>④ 流行病学证据。</strong> 习惯饮用非常热饮料的人群（南美马黛茶、中东热茶、东亚热汤等）在多项研究中显示食管癌风险升高。IARC 2016 年的评估正是基于这些证据。

<strong>⑤ 温度不是唯一因素。</strong> 食管癌在中国有明显的地域聚集性，与吸烟、饮酒、腌制食品、营养因素都有关。<strong>烫食是可控因素之一，不是全部。</strong>

<strong>证据等级为什么是 B。</strong> "65 ℃ 以上热饮为 2A 类"是 IARC 的权威分类，"热损伤 → 慢性炎症 → 增生"的机制清楚，流行病学方向一致。但<strong>精确的阈值（到底是 65 还是 60）、以及"降到多少最安全"缺少直接的干预试验</strong>，所以是 B 而不是 A。

## 常见误区

- <strong>误区：我喝了几十年烫的也没事。</strong> 个体观察无法否定人群统计——风险是概率，不是必然。就像有人抽一辈子烟也没得肺癌。
- <strong>误区：趁热喝才养胃。</strong> 没有证据支持；而烫是明确的风险因素。
- <strong>误区：热汤最有营养。</strong> 汤里主要是水、盐、脂肪和嘌呤，蛋白质主要在肉里（见[喝汤有营养吗](/entry/soup-nutrition/)）。
- <strong>误区：凉一点就不好喝了。</strong> 等 3–5 分钟，风味损失很小；烫伤的风险却完全消失。
- <strong>误区：只有茶才算热饮。</strong> 任何 65 ℃ 以上的液体都一样，包括水、汤、粥、咖啡。
- <strong>误区：吹一吹就凉了。</strong> 表面降温快，内部仍然很烫——<strong>搅拌比吹更有效</strong>。

## 风险与禁忌

- 出现<strong>吞咽困难、胸骨后疼痛、体重下降、呕血或黑便</strong> → <strong>立即就医</strong>，不要用"改温度"来观察。
- <strong>食管癌高发地区居民、有家族史者</strong> → 更应避免烫食，并按医生建议决定是否筛查。
- <strong>长期吸烟 + 重度饮酒 + 烫食</strong> → 三重叠加，风险显著高于单一因素。
- <strong>不要用"改温度"替代对已出现症状的检查。</strong>
- 儿童和老人对温度的判断更不可靠，给他们盛汤时要<strong>先试温</strong>。

## 何时求助专业人士

- <strong>吞咽困难或吞咽疼痛持续超过 2 周</strong>。
- <strong>不明原因体重下降</strong>。
- 反复胸骨后烧灼感、反酸（需与胃食管反流鉴别）。
- 有<strong>食管癌家族史</strong>、或来自高发地区 → 咨询是否需要胃镜筛查。
- 长期进食后胸骨后不适、食物"卡住感"。
