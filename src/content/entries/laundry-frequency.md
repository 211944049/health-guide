## 适用人群

- 谁适合照做：所有家庭；皮肤敏感、易长痘、有湿疹或过敏的人；有幼儿的家庭。
- 谁不适用：这条没有不适用的人。<strong>有传染性皮肤问题（如疥疮、头虱、真菌感染）时</strong>，清洁要求会更严格，需按医生指示处理。

## 具体做法

### 1. 按「接触程度」决定频率

判断依据不是"看起来脏不脏"，而是<strong>是否直接接触皮肤、是否吸附汗液</strong>：

| 衣物 | 建议频率 | 原因 |
| --- | --- | --- |
| 内衣、袜子 | <strong>每次穿过就洗</strong> | 直接接触皮肤，汗液和分泌物多 |
| T恤、背心（贴身） | <strong>每次穿过就洗</strong> | 汗液、皮脂直接接触 |
| 睡衣 | <strong>2–3 次一洗</strong> | 整夜接触皮肤，但出汗量相对少 |
| 运动服 | <strong>每次运动后洗</strong> | 大量汗液，细菌繁殖快 |
| 衬衫、外穿T恤 | 1–2 次 | 视出汗量 |
| 毛衣、卫衣 | 3–5 次 | 一般不直接贴皮肤 |
| 牛仔裤、外裤 | 3–5 次（或更久） | 不直接接触，勤洗反而加速磨损 |
| 外套、大衣 | 一季 1–2 次 | 主要防污，不吸汗 |
| <strong>床单、被套</strong> | <strong>每周 1 次</strong> | 皮屑、汗液、尘螨 |
| <strong>枕套</strong> | <strong>每周 1 次</strong>（油性皮肤可更勤） | 直接接触面部 |
| 毛巾 | <strong>2–3 次使用后</strong> | 潮湿环境易滋生细菌 |
| 浴巾 | <strong>3–4 次使用后</strong>，且每次晾干 | 潮湿易生菌 |

### 2. 几条例外：这些情况要立刻洗

- <strong>明显出汗后</strong>（运动、高温、赶路）。
- <strong>接触过病人或医院环境后</strong>。
- <strong>沾染了体液、血迹、呕吐物</strong>——先冷水冲掉血迹，再单独清洗并消毒。
- <strong>有脚气、灰指甲</strong>：袜子单独洗，或用高温程序。
- <strong>皮肤有感染、伤口渗出</strong>时，贴身衣物单独清洗。
- <strong>家里有人得了疥疮、头虱</strong>：床品、衣物需按医生要求高温清洗并处理。
- <strong>过敏季或雾霾天</strong>外出后的外衣，建议挂在通风处而不是直接放进衣柜。

### 3. 洗的时候几个关键点

- <strong>水温</strong>：普通衣物常温或 30–40 ℃ 即可；<strong>需要杀菌时（如病人衣物、毛巾）用 60 ℃ 以上</strong>，多数细菌和尘螨在高温下被杀灭。
- <strong>不要塞太满</strong>：洗衣机装得过满，机械摩擦不足，洗不干净。
- <strong>晾干比洗净同样重要</strong>：<strong>潮湿的衣物是霉和细菌的温床</strong>。洗完尽快晾干，阴雨天用烘干机或除湿机，参考[湿度多少合适](/entry/humidity/)。
- <strong>不要长期放在洗衣机里</strong>：洗完忘了拿出来，几小时后就会有异味和细菌繁殖。
- <strong>洗衣机本身要清洁</strong>：建议每月运行一次筒自洁或用专用清洁剂，尤其滚筒机的密封圈要擦干。参考[洗衣液和柔顺剂怎么选](/entry/laundry-detergent/)。
- <strong>柔顺剂少用</strong>：它会在纤维表面形成膜，降低毛巾吸水性，也可能刺激敏感皮肤。

### 4. 皮肤敏感或有湿疹的人

- <strong>选无香、无染料的洗涤剂</strong>，并<strong>多漂洗一次</strong>。
- <strong>避免柔顺剂和衣物柔顺喷雾</strong>。
- <strong>新衣服先洗再穿</strong>（残留的染料和整理剂可能刺激皮肤）。
- <strong>贴身衣物选纯棉等透气材质</strong>，参考[内衣材质怎么选](/entry/underwear-material/)。
- <strong>洗涤剂用量按说明，不要"多加更干净"</strong>——残留比污渍更容易引起刺激。

## 健康原理

<strong>衣物需要清洗的核心原因是"皮肤与织物之间的微环境"。</strong> 皮肤持续分泌汗液和皮脂，脱落的角质细胞成为微生物的营养来源。贴身织物吸收这些物质后，形成一个<strong>温暖、潮湿、富含有机物的环境</strong>，有利于细菌和真菌繁殖。这就是为什么"贴身程度"是判断频率的首要依据，而不是视觉上的干净程度。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>为什么床品要每周洗。</strong> 床是多重暴露的叠加场所：<strong>皮屑（尘螨的食物）、汗液、皮脂、以及整夜的时间</strong>。尘螨以皮屑为食，其排泄物是常见的过敏原，与过敏性鼻炎和哮喘症状相关。所以对过敏人群来说，床品清洁频率的影响比其他衣物更直接。<strong>枕套尤其重要</strong>——面部整夜接触，与痤疮、面部皮炎的发生有一定关联。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>为什么"潮湿"是关键变量。</strong> 微生物繁殖需要水分。洗净但没晾干的衣物，其微生物负荷可能比洗净前更高——这也是"阴干后发臭"的原因（细菌代谢产物）。所以<strong>晾干和除湿是清洁流程的一部分</strong>，尤其在梅雨季和南方潮湿地区。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>为什么高温清洗对特定情况必要。</strong> 常规洗涤剂和常温水流能去除大部分污垢和相当一部分微生物，但<strong>对尘螨和部分病原体，温度是更可靠的杀灭手段</strong>。所以当目标是"减少病原体"（病人衣物、疥疮、头虱、毛巾）而不只是"去除污渍"时，需要 60 ℃ 以上或烘干。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>为什么柔顺剂对敏感皮肤不友好。</strong> 柔顺剂通过在纤维表面留下阳离子表面活性剂和香精来产生柔软感，这些残留物可能刺激皮肤；同时它降低吸水性，对毛巾和运动服不利。多漂洗和减少助剂是敏感皮肤护理的常规建议。<sup class="ref-mark">[1][2][3][4][5]</sup>

<strong>证据等级为什么是 C。</strong> 「床品与尘螨过敏原相关」「高温可杀灭尘螨和病原体」「潮湿促进微生物繁殖」这些机制有较好支持。但<strong>"具体衣物应该多少天洗一次"缺乏直接的高质量研究</strong>——本站在表格里给的是基于接触程度和微生物原理的<strong>合理推断</strong>，不同机构的建议也有差异。所以定在 C 级，并把判断依据（接触程度）讲清楚，而不是给出看似精确却无出处的天数。<sup class="ref-mark">[1][2][3][4][5]</sup>

## 常见误区

- <strong>误区：看起来不脏就不用洗。</strong> 汗液、皮脂和微生物是看不见的。判断依据应是接触程度。
- <strong>误区：牛仔裤不能洗，越不洗越好。</strong> 长时间不洗会有明显细菌负荷和异味；适度清洗不影响"养牛"效果，只要避免高温烘干。
- <strong>误区：外套不用洗。</strong> 外套会吸附空气中的颗粒物和污染物，一季至少清洗一次。
- <strong>误区：洗涤剂越多洗得越干净。</strong> 过量洗涤剂难以漂净，残留会刺激皮肤并让衣物发硬。
- <strong>误区：柔顺剂让衣服更"干净"。</strong> 它只是改变手感，与清洁无关，还可能刺激皮肤。
- <strong>误区：阴干和晒干一样。</strong> 阴干慢、湿度高，微生物繁殖更多；有条件应晒干或用烘干机。
- <strong>误区：洗衣机不用清洁。</strong> 洗衣机内筒和密封圈会积累生物膜，洗出来的衣服会带异味，需要定期清洁。
- <strong>误区：新衣服可以直接穿。</strong> 生产过程中的染料、整理剂和运输中的灰尘都可能刺激皮肤，建议先洗。

## 风险与禁忌

- <strong>有疥疮、头虱、真菌感染（脚气、体癣）时</strong>，衣物和床品需按医生要求处理（通常需要高温清洗或密封放置一段时间），<strong>不要与家人混洗</strong>。
- <strong>接触过病人体液、呕吐物、血迹的衣物</strong>应单独清洗，先冷水处理血迹，并使用高温或消毒程序。
- <strong>皮肤有渗出、感染或大面积湿疹</strong>时，贴身衣物应单独清洗并充分漂洗。
- <strong>婴幼儿衣物</strong>应与成人衣物分开洗，使用温和无香洗涤剂，避免柔顺剂。
- <strong>不要用开水烫洗所有衣物</strong>，会损伤纤维并可能造成烫伤风险；按洗涤标签操作。
- <strong>不要在密闭潮湿环境中晾衣服</strong>（如小卫生间），容易导致霉味和霉菌孢子扩散，参考[租房怎么防霉](/entry/mold-prevention/)。
- <strong>不要把湿衣物长时间留在洗衣机里</strong>，这是异味和微生物繁殖的常见原因。
- <strong>对洗涤剂或柔顺剂过敏的人</strong>应停止使用并更换产品；出现明显皮疹需就医。
- <strong>不要把"勤洗"变成强迫行为</strong>：过度清洗会损伤衣物、增加环境负担，也可能加重皮肤干燥。按接触程度处理即可。

## 何时求助专业人士

出现以下情况先看医生，不要只靠本文：

- <strong>反复出现皮肤瘙痒、红疹、脱屑，且更换洗涤剂后无改善</strong>——需要皮肤科评估（可能是湿疹、真菌感染或接触性皮炎）。
- <strong>家人之间出现同样的皮疹并反复传播</strong>——需警惕疥疮等传染性皮肤问题，需要同时治疗所有接触者。
- <strong>怀疑尘螨过敏</strong>（晨起鼻塞、打喷嚏、夜间咳嗽）——建议做过敏原评估，参考[租房怎么防霉](/entry/mold-prevention/)与[湿度多少合适](/entry/humidity/)。
- <strong>衣物洗后仍有异味、或洗衣机内筒发霉</strong>且清洁后不改善——可能需要专业清洗或更换设备。
- <strong>婴幼儿出现不明原因的皮疹、持续瘙痒</strong>——需儿科评估，并检查洗涤用品。
- <strong>皮肤问题伴随发热、大面积红肿、渗液</strong>——尽快就医。
