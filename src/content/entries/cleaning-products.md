## 适用人群

- 家里常备洁厕灵、84 消毒液、除垢剂的人。
- 有婴幼儿、老人或宠物的家庭。
- 做深度清洁、刷卫生间和厨房的人。
- 皮肤敏感、清洁后手部起疹的人。

<strong>需要立即就医的情况</strong>：混合清洁剂后吸入气体出现咳嗽、胸闷、呼吸困难、眼睛刺痛——这是<strong>急性化学中毒，属于急症</strong>，应立即离开现场并呼叫急救。

## 具体做法

### 1. 三条绝对不能违反的规则

<strong>（1）含氯消毒剂不能与酸性产品混用</strong>

| 不要混的组合 | 后果 |
| --- | --- |
| 84 消毒液 + 洁厕灵 | <strong>产生氯气</strong>，可致严重呼吸道损伤甚至死亡 |
| 84 消毒液 + 醋 / 柠檬酸除垢剂 | 同上 |
| 84 消毒液 + 含氨清洁剂（玻璃水等） | 产生氯胺类有毒气体 |
| 含氯消毒剂 + 过氧化氢 | 剧烈反应 |

<strong>氯气的识别</strong>：黄绿色气体、刺鼻呛人的气味、眼睛和喉咙立即刺痛。<strong>出现这种感觉说明已经暴露，立即离开、开窗通风，不要再去「看看怎么回事」。</strong>

<strong>最安全的做法：一次只用一种清洁剂。</strong> 需要先用 A 再用 B 时，<strong>必须充分冲洗干净、通风</strong>再用下一种。

<strong>（2）清洁剂必须原包装、远离儿童和宠物</strong>

- <strong>绝对不要把清洁剂分装到饮料瓶、矿泉水瓶里</strong>——这是家庭误服中毒最经典的原因。
- 存放在<strong>儿童打不开的柜子或高处</strong>，最好加安全锁。
- <strong>不要放在食物、餐具、药品附近。</strong>
- <strong>洗衣凝珠尤其危险</strong>：外观像糖果，误食可致严重化学烧伤，必须锁存。

<strong>（3）通风是前提</strong>

- 清洁卫生间、厨房时<strong>开窗 + 开排气扇</strong>。
- <strong>不要关着门窗闷头刷</strong>。
- 使用喷雾型产品时避免直接吸入气雾。
- 清洁后继续通风一段时间。

### 2. 减少不必要的化学暴露

- <strong>日常清洁不需要消毒剂</strong>：洗涤剂 + 清水 + 物理擦拭就能去除大部分污垢和微生物。
- <strong>「杀菌率 99.9%」的宣称意义有限</strong>：家庭环境不需要无菌，过度消毒反而可能促进耐药菌并刺激呼吸道。
- <strong>需要消毒的情况</strong>：家中有传染病患者、被体液污染的表面、免疫低下者的居住环境。
- <strong>少用气雾喷雾（喷雾型空气清新剂、消毒喷雾）</strong>：会产生可吸入颗粒，对呼吸道不友好。
- <strong>慎用「强力除垢」「强效去油」</strong>：通常意味着更强的酸或碱，风险也更高。

### 3. 保护自己

- <strong>戴手套</strong>：丁腈手套比乳胶更耐化学腐蚀，且不易过敏。乳胶过敏者选丁腈。
- <strong>戴护目镜</strong>：使用强酸、强碱或喷雾时，避免溅入眼睛。
- <strong>穿长袖</strong>，避免皮肤直接接触。
- <strong>口罩</strong>：在通风差的空间、使用粉末或喷雾产品时佩戴。
- <strong>洗手</strong>：清洁后彻底洗手，再接触食物、孩子。
- <strong>不要用手揉眼睛、摸脸</strong>。

### 4. 万一发生意外怎么办

| 情况 | 处理 |
| --- | --- |
| <strong>吸入刺激性气体</strong> | 立即离开现场，到通风处深呼吸；<strong>出现持续咳嗽、胸闷、呼吸困难立即就医或拨打急救电话</strong> |
| <strong>溅入眼睛</strong> | <strong>立即用大量清水冲洗 15 分钟以上</strong>（翻开眼睑），然后就医 |
| <strong>皮肤接触</strong> | 脱掉污染衣物，用大量清水冲洗 15 分钟；出现灼伤、水疱就医 |
| <strong>误服</strong> | <strong>不要催吐</strong>（强酸强碱会二次损伤食管），<strong>立即就医或拨打急救电话</strong>，带上产品包装 |
| <strong>婴幼儿误服</strong> | <strong>立即就医或拨打急救电话</strong>，不要自行催吐或喂水喂奶 |

<strong>把这些号码存进手机</strong>：当地急救电话（120）、中毒咨询热线（中国疾控中毒咨询电话可查询当地号码）。

### 5. 更安全的替代方案

- <strong>白醋</strong>：可去除水垢（但不能与含氯消毒剂同用）。
- <strong>柠檬酸</strong>：除水垢效果好，食品级更安全。
- <strong>小苏打</strong>：温和的研磨和除味剂。
- <strong>肥皂水 + 热水</strong>：日常去污的主力，安全有效。
- <strong>蒸汽清洁机</strong>：用高温物理方式清洁，减少化学品使用。

<strong>注意</strong>：天然 ≠ 无风险。<strong>醋和柠檬酸是酸，仍然不能与含氯消毒剂混用</strong>，浓度高时也会刺激皮肤和眼睛。

## 健康原理

- <strong>氯气为什么会致命</strong>：氯气与呼吸道黏膜的水分反应生成盐酸和次氯酸，直接损伤气道和肺泡。低浓度引起咳嗽、眼痛、咽痛；高浓度可致化学性肺炎、肺水肿，甚至死亡。<strong>在通风差的卫生间混合使用，浓度可以迅速达到危险水平。</strong>
- <strong>为什么「先冲干净再用另一种」有效</strong>：只要没有残留的次氯酸盐，就不会与酸反应。<strong>冲洗和通风是打破反应条件的唯一方法。</strong>
- <strong>误服为什么要避免催吐</strong>：强酸强碱会造成二次灼伤（食管反复受腐蚀），且呕吐物可能进入气道。<strong>正确做法是立即就医，带上产品包装以便判断成分。</strong>
- <strong>皮肤刺激的机制</strong>：清洁剂中的表面活性剂会溶解皮肤脂质屏障，导致干燥、脱屑、接触性皮炎。<strong>长期不戴手套做家务是手部湿疹的常见原因。</strong>
- <strong>为什么不需要过度消毒</strong>：家庭环境中的微生物多数无害，人体免疫系统也需要适度暴露。过度消毒增加化学暴露风险，且对呼吸道有刺激（尤其儿童和哮喘患者）。
- <strong>为什么标 B</strong>：混用产生氯气、误服中毒的机制和后果都有明确的毒理学与临床证据，中毒预防措施也是各机构一致建议；但「家庭清洁剂残留对健康的长期影响」研究有限，不同产品的具体风险差异大。综合给出 B。<sup class="ref-mark">[1][2][3][4]</sup>

## 常见误区

- <strong>两种清洁剂一起用效果更强</strong>：<strong>这是最危险的误区</strong>。含氯 + 酸性 = 氯气；很多家庭中毒事件就源于「先用洁厕灵、再倒 84」。
- <strong>闻不到味道就没事</strong>：氯气的嗅觉适应很快，<strong>气味变淡不代表浓度降低</strong>，反而可能是嗅觉疲劳。
- <strong>清洁剂稀释后就没危险了</strong>：稀释降低但不消除风险，混用仍会反应；而稀释过度会让使用者加入更多量，反而增加暴露。
- <strong>清洁剂可以装到饮料瓶里方便使用</strong>：<strong>绝对不要</strong>。这是儿童误服的首要原因。
- <strong>天然成分的清洁剂可以随便混</strong>：醋、柠檬酸是酸，与含氯消毒剂混用一样产生氯气。
- <strong>杀菌率 99.9% 才干净</strong>：家庭不需要无菌环境，过度消毒没有额外健康收益。
- <strong>手不疼就说明清洁剂不伤皮肤</strong>：刺激和过敏反应可能延迟出现；长期接触会累积损伤。
- <strong>用热水稀释消毒剂效果更好</strong>：部分含氯产品遇热水会加速分解并释放更多气体，<strong>按说明书用常温水</strong>。
- <strong>空气清新剂能改善室内空气</strong>：它只是掩盖气味，喷雾型产品还可能带来可吸入颗粒和挥发性有机物（见[甲醛怎么测](/entry/formaldehyde-testing/)里关于通风的部分）。

## 风险与禁忌

- <strong>哮喘、慢性呼吸道疾病患者</strong>：对含氯气雾、喷雾型产品更敏感，<strong>应避免使用喷雾型清洁剂和含氯消毒剂</strong>，改由他人清洁并保持通风。
- <strong>婴幼儿与儿童</strong>：化学品必须锁存；<strong>不要在孩子在场时使用喷雾型清洁剂</strong>；表面清洁后用清水擦净再让孩子接触。
- <strong>孕妇</strong>：尽量避免接触强效清洁剂和有机溶剂，保持通风，或请他人代做。
- <strong>宠物</strong>：部分成分（如酚类、季铵盐、部分精油）对猫狗毒性高，<strong>养宠家庭应选宠物安全产品</strong>并避免宠物接触未干的表面。
- <strong>皮肤病患者（湿疹、接触性皮炎）</strong>：戴手套、选温和产品，症状持续看皮肤科。
- <strong>不要混合任何清洁产品「图省事」</strong>；需要多种时，<strong>冲洗 + 通风 + 分别使用</strong>。
- <strong>不要用清洁剂清洗食物或餐具</strong>，除非是食品用洗涤剂并彻底冲净。
- <strong>不要把消毒剂用于人体</strong>（除非是医用皮肤消毒产品），尤其不要用来漱口、清洗伤口。
- <strong>强酸强碱类产品</strong>（通渠剂、除垢剂）应单独存放，使用时戴护目镜，<strong>不要与任何其他产品混用</strong>。

## 何时求助专业人士

- <strong>吸入清洁剂气体后出现持续咳嗽、胸闷、气短、呼吸困难</strong>：<strong>立即离开现场并拨打急救电话</strong>，不要等待症状自行缓解。
- <strong>清洁剂溅入眼睛</strong>：立即清水冲洗 15 分钟以上并<strong>急诊就医</strong>，化学性眼损伤需要及时处理。
- <strong>误服清洁剂（尤其儿童）</strong>：<strong>立即就医或拨打急救电话，不要催吐</strong>，带上产品包装。
- <strong>皮肤出现灼伤、水疱、大面积红肿</strong>：就医处理，不要自行涂抹药膏。
- <strong>清洁后反复出现皮疹、手部干裂脱屑</strong>：看皮肤科，可能需要斑贴试验明确致敏原。
- <strong>家中宠物在清洁后出现流涎、呕吐、精神萎靡</strong>：立即联系兽医，并带上产品成分信息。
- <strong>长期暴露后出现不明原因的呼吸道症状</strong>：建议呼吸科评估，并排查家庭化学品使用情况。
