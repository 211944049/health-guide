关于本站

高性价比健康指南不做在线诊所，做生活决策助手：把健康问题拆成能在日常生活里执行的动作， 每条都标出证据等级、成本、耗时和适用人群，并写清什么时候该去看医生。

灵感来自开源项目《高性价比人生指南》的结构化思路：结构化、可检索、持续更新、证据标注。 区别是本站聚焦「衣食住行 + 护理 + 身心 + 健康管理」这些每天都会遇到的决策。

一个词条长什么样

词条统一按下面的顺序组织。带 ※ 的部分由 frontmatter 自动生成，正文里不再重复写，避免两处数字对不上：

  1. 一句话结论（frontmatter 的 summary，没有就取正文第一段）※
  2. 适用人群（frontmatter 的 audience）※
  3. 具体做法 —— 步骤 / 清单 / 对比表
  4. 健康原理 —— 为什么这么做
  5. 证据等级（frontmatter 的 evidence）※
  6. 成本与时间（frontmatter 的 cost / time）※
  7. 常见误区
  8. 风险与禁忌
  9. 何时求助专业人士
  10. 参考来源（frontmatter 的 sources）※
  11. 最后更新（frontmatter 的 updated）※

正文必须出现的六个小标题：适用人群、具体做法、健康原理、常见误区、风险与禁忌、何时求助专业人士。 pnpm build 会先跑内容体检，缺标题、枚举值写错、来源里留着 TODO 都会直接构建失败。

证据等级

A · 证据强

多项高质量研究或权威指南一致支持，结论稳定

B · 证据中

有较好研究或权威指南支持，但存在细节分歧

C · 证据弱

证据有限、以专家经验或间接推论为主，仅供参考

D · 有争议

研究结论不一致，或学界仍在争论，不当作定论

证据等级是对「这条建议的证据强度」的标注，不是对「内容好不好」的评价。标 C 的建议也照做通常无害， 但它更依赖专家经验和间接推论，指南更新后可能被推翻，所以别把它当铁律。

成本与时间的口径

  • 成本：免费 / 低 / 中 / 高。免费＝不花钱；低＝每月 50 元以内；中＝每月 50–300 元；高＝一次性 500 元以上或每月 300 元以上。
  • 时间：1分钟 / 5分钟 / 15分钟 / 30分钟 / 1小时 / 长期。指读完并照着做一次大概花多久；需要长期坚持的记「长期」。

合规底线

  • 每页底部有「本站内容仅供参考，不构成医疗建议，不能替代面诊、诊断与处方。」
  • 不诊断、不治疗、不推荐处方药，不给个体化用药剂量
  • 涉及症状、疾病、用药的词条，必须有「何时求助专业人士」
  • 有商业链接会明确标注（目前没有任何商业合作）
  • 来源透明可查，不抄受版权保护的大段原文

谁在维护这个站

本站由个人独立维护，不是医疗机构，也不提供诊疗服务。所有词条都由维护者查阅公开指南与标准后撰写，并在文末列出依据。

所以本站的说法是有限度的：每个词条都会标出证据等级和依据， 证据弱的地方就说证据弱（比如「冥想」「枕头怎么选」是 C 级）， 有争议的地方就说有争议（D 级）。你不该在这里找到「三天治好」这类话。

全部词条的源文件是公开的。 你可以在这里逐条核对我们的写法、证据等级判断和引用方式（含 纠错流程 ）： 源码仓库 。发现问题可以直接提，不用先写一封邮件。

怎么纠错、怎么提选题

发现事实错误、来源过时、或者表述不清，欢迎指出来。 健康内容一定有错的时候，而纠错渠道是这件事唯一可靠的补救方式。

写什么最有帮助

  • 指错时带上依据：指南名 / 标准编号 / 论文（能给链接最好）。 只说「我觉得不对」我很难判断，而有出处我能直接去核对。
  • 指出具体位置：哪一条词条、哪一段或哪句话。可以直接复制那句话。
  • 提选题就直接写题目（比如「冰箱里放多久还能吃」）。 排期会按被问到的频次调整顺序——被问得多的先写。

我会怎么处理

  • 核对后会直接改词条，并把 updated 日期更新。 改动是连续的，不会单独发「勘误声明」——因为每条词条的改动历史都在它的更新日期上。
  • 如果是证据等级判断错了（比如 C 级其实该是 B 级），我会调整等级并说明为什么。
  • 如果无法核实（比如只有个案报告），我会在词条里注明这一点，而不是当作事实写进去。
