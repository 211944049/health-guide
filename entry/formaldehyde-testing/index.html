甲醛怎么测

要拿到能当依据的结果，就找有 CMA 资质的机构按标准采样；几十块的自测盒只能当筛子，几百块的手持电子检测仪普遍不准，别用它做「能不能住」的决定；测之前先问清检测机构用的是哪个标准、关窗多久，不同标准的结果不能直接比。

B · 证据中 成本 中 耗时 1小时 适合 新装修家庭适合 租房族适合 有婴幼儿的家庭

适用人群

  • 刚装修完、准备入住，想知道「能不能住」的人。
  • 买了大量新家具、闻到明显气味的人。
  • 租到刚翻新过的房子、担心甲醛的租客。
  • 家里有孕妇、婴幼儿、老人或呼吸道疾病患者，需要更谨慎判断的人。

本文只解决「怎么测、怎么读结果」。要不要买净化器、怎么选，见空气净化器怎么选。

具体做法

1. 先明确测什么

装修后的室内空气问题不只是甲醛，主要还有苯系物（苯、甲苯、二甲苯）和 TVOC（总挥发性有机物）。只测甲醛会漏掉一部分风险，所以正规检测一般是一次采样、多项出结果。

2. 选检测方式（按可靠性排序）

方式大致花费可信度适合用来做什么
CMA 资质机构上门采样、实验室分析每个点位几百元高，报告可用于维权判断能否入住、租房纠纷、维权
自测盒（比色法）几十元低，半定量粗略筛查、看不同房间的相对高低
手持电子检测仪几十到几百元普遍不可靠不建议作为决策依据

手持仪器的问题不是「便宜」，而是传感器对多种气体交叉敏感、且几乎没有校准：喷点酒精、醋、香水，数值都会跳。它能告诉你「浓度变高了」，但说不清高的是不是甲醛，也说不准高了多少。

3. 采样条件必须问清楚

同一间房，采样条件不同，结果能差一倍以上。约检测之前先问这四件事：

  1. 依据哪个标准（GB/T 18883 还是 GB 50325），以及对应的关窗时间是 1 小时还是 12 小时——这两种条件测出的数值不能互相比较。
  2. 采样点位：应在呼吸带高度（约 0.5–1.5 m），不是放地上也不是放柜子里。
  3. 每个房间单独采一个点，别用一个点的结果代表全屋。
  4. 当时的温度和湿度：温度越高释放越快，夏天或开着暖气测，更接近最坏情况。

4. 什么时候测

  • 家具全部进场之后。家具（板材、胶、软包）往往是甲醛的主要来源，家具没到齐就测等于白测。
  • 不要在刚刷完漆、满地清洁剂气味的时候测，会干扰结果。
  • 想在冬天入住，建议夏天最热的时候补测一次。

5. 结果怎么读

现行标准里甲醛限值不是全国唯一一个数：不同标准（GB/T 18883 与 GB 50325）、不同建筑类别（住宅与办公楼）限值不同，大体在 0.07–0.10 mg/m³ 这个量级，具体数值以最新版标准原文为准。

两个容易搞错的地方：

  • 合格 ≠ 长期安全。甲醛释放以年计，温度一升浓度就会反弹，一次检测只代表当时的条件。
  • 超标 ≠ 立刻不能住。先看超多少、是哪个房间，通常优先做的是加强通风、减少新家具，而不是马上买设备。

6. 避坑：不要选「免费检测 + 收费治理」

这是典型的利益冲突：检测方同时是治理方，结果自然容易「超标」。要拿报告就找只做检测、不做治理的 CMA 机构。

健康原理

  • 甲醛是明确的 I 类致癌物（国际癌症研究机构分级），主要危害是刺激眼、鼻、咽喉和呼吸道，长期暴露与白血病风险升高相关，儿童和孕妇更敏感。
  • 释放周期长：板材里的脲醛树脂会持续缓慢分解释放，周期以年计，所以「通风三个月」不是一个有依据的截止点。
  • 温度是最大的变量：温度升高会显著加快释放，这就是为什么同一间房子夏天和冬天测出来不一样。
  • 通风为什么仍是第一位的手段：它直接把室内浓度稀释到室外水平，效果立竿见影且没有副作用；吸附类产品（活性炭）会饱和，饱和后可能重新释放。
  • 为什么标 B：甲醛的健康危害和释放规律证据充分，检测标准也是明确的；但「家用检测设备的准确性」和「各种治理手段的实际效果」研究有限，所以整体标 B。[1][2][3][4]

常见误区

  • 靠鼻子判断：低浓度甲醛不一定闻得到，而你闻到的刺鼻气味可能主要来自 TVOC 或木材本身的气味。
  • 绿植、柚子皮、茶叶、醋能除甲醛：吸附能力微乎其微，醋和柚子皮只是用更强的气味盖住了异味。
  • 活性炭包放着就行：会饱和，需要定期更换，且不及时换可能成为二次释放源。
  • 电子检测仪显示 0.01 就放心：没有校准的家用仪器，数字的绝对值和精度都不可信。
  • 专业治理后就一劳永逸：封闭类药剂有效期有限，之后可能反弹，治理后仍要复检和通风。
  • 装修完通风三个月就安全：释放以年计，三个月只是把初期高浓度阶段度过去。

风险与禁忌

  • 孕妇、婴幼儿、老人、哮喘或慢性呼吸道疾病患者对甲醛更敏感，条件允许时应尽量推迟入住，并以通风为主。
  • 入住后出现持续的眼鼻刺激、咽痛、干咳、皮疹、头痛，先离开并加强通风，症状不缓解及时就医。
  • 不要在有人活动的房间使用臭氧机或强电离设备除味：臭氧本身刺激呼吸道，是有害污染物而不是清新剂。
  • 检测前 24 小时不要使用香水、空气清新剂、强效清洁剂，也不要刚做完油漆修补，否则结果没有参考意义。
  • 甲醛不是唯一污染物：如果家里有持续的霉味、潮湿问题，或房龄很老怀疑石棉，需要单独检测，不要用一个甲醛结果概括全部。

何时求助专业人士

  • 家庭成员（尤其儿童）出现反复或持续的呼吸道症状，且与居住环境时间上相关。
  • 需要用检测报告维权、退租或索赔时，必须找有 CMA 资质的机构出具正式报告。
  • 怀疑除了甲醛之外还有霉菌、石棉、一氧化碳等问题，找专业检测机构，不要自行判断。
  • 本身有哮喘、慢性阻塞性肺病、免疫缺陷，或家中有正在化疗的患者，入住前的空气评估建议听医生意见。

  • 租房怎么防霉

    防霉的关键是控湿 + 通风 + 除湿，不是靠除霉喷雾反复擦。室内相对湿度控制在 50% 以下就能明显抑制霉菌生长；优先用除湿机（南方梅雨季最有效），其次加强通风、把家具离墙留缝、避免在室内晾衣。已经长霉的表面必须真正清除（含氯消毒剂或酒精擦拭），只盖一层漆或香氛是无效的；大面积发霉、墙体渗水属于房东责任，应当要求维修。

  • 厨房油烟怎么处理

    油烟的危害主要来自高温煎炸产生的细颗粒物和多环芳烃，靠「开抽油烟机 + 开窗 + 控制油温」三件事就能大幅降低——关键细节是炒菜前先开机、炒完再让它多跑 5–10 分钟；抽油烟机要按风量和安装高度选，开放式厨房尤其要注意。

  • 燃气热水器和一氧化碳怎么防

    一氧化碳无色无味，中毒时人往往在不知不觉中失去意识，所以防护只能靠三件事——「热水器不要装在浴室里」「装一氧化碳报警器」「用炭火或煤炉时保持通风」；一旦怀疑中毒（头痛、恶心、多人同时不适），先开窗、把人移到室外、再打 120，不要在室内打电话或开关电器。

    🏠 住 B 中 成本 低 耗时 30分钟

  • 老房子的水管和水质要注意什么

    老房子最需要留意的不是"水脏不脏"，而是管材和停水后的那一段水——镀锌铁管老化会带来铁锈和浑浊，含铅管件（多见于很老的建筑）会缓慢析出铅，而停水、长期空置后重新通水时，管道里积存的水污染物浓度最高；最实际的做法是「长期没用或刚停水后，先放水 1–2 分钟再用来喝和做饭」「早上第一杯水不直接喝」「烧开能杀菌但不能去除铅和部分重金属」。

    🏠 住 C 弱 成本 低 耗时 15分钟

  • 二手家具和旧书会不会有污染

    二手家具和旧书的主要风险不是甲醛——它们已经挥发过很久，释放量通常远低于新家具；真正的风险是「霉菌和尘螨（受潮存放的旧家具、旧书）」「胶合板老化后重新释放（受潮、受热时）」「以及旧家具的阻燃剂和翻新油漆」；所以拿到二手家具先「闻、看、擦、通风」，受潮发霉的宁可不要。

    🏠 住 C 弱 成本 免费 耗时 15分钟

  • 净水器怎么选

    先别急着买——我国自来水出厂要符合《生活饮用水卫生标准》（GB 5749-2022），多数城市烧开喝就够；真正需要装的情况是管道老化、二次供水水箱不洁、或对余氯口感敏感。要装就按「想除掉什么」选技术：反渗透（RO）能去重金属、水垢和水中的大部分溶解物，超滤和活性炭去不了溶解性重金属和水垢。TDS 笔只测导电性，测不出细菌和具体污染物，别拿它当水质安全结论。
