看医生前该准备什么

就诊前花十分钟写一张纸：这次最主要的一个问题、什么时候开始的、怎么变化的、已经做过什么、正在吃什么药（含剂量）、有什么过敏；带上既往报告和用药清单，把想问的问题按重要程度排序——这一步能明显减少「出了诊室才想起要问什么」。

适用人群

  • 谁适合照做：所有需要就诊的人，尤其是有多个健康问题、长期服药或需要看多个科室的人；陪老人或孩子看病的家属。
  • 谁不适用：这条人人都适用。急性重症（胸痛、呼吸困难、意识改变、大出血）不需要”准备”——直接就医或呼叫急救，把准备留给家属在路上做。

具体做法

1. 写一张纸，只写「一个」主要问题

门诊时间通常只有几分钟。开场的三十秒决定了这次就诊的效率，所以要先用一句话说清最要紧的事：

「我最主要的问题是______，从______时候开始的，最近______（变好/变坏/没变）。」

不要把五个问题平均分配——先解决最要紧的那个，其余的可以另外挂号或写下来交给医生判断优先级。

2. 把「时间线」写清楚

医生最需要的是时间线，而患者最容易漏的也是时间线：

  • 症状什么时候开始的（具体到哪一周/哪一月）
  • 是持续还是阵发，多久一次，每次持续多久
  • 什么情况下加重，什么情况下缓解
  • 期间有没有做过检查、吃过药，结果和反应如何
  • 有没有伴随的其他变化（体重、食欲、睡眠、排便、情绪）

3. 带一份「用药清单」

这一项最容易被忽视，也最影响决策：

  • 所有正在吃的药，包括处方药、非处方药、中成药、保健品、外用药
  • 每种药的名称和剂量（不确定就拍下药盒照片，或直接带药盒）
  • 特别标注：抗凝药（如华法林、阿司匹林、氯吡格雷）、降糖药、降压药、激素类、免疫抑制剂

为什么强调抗凝药：它直接影响出血风险和操作决策（比如能不能做活检、拔牙、小手术）。医生不知道你在吃抗凝药，可能做出不安全的处置。

4. 带齐材料

  • 既往的检查报告、化验单、影像片（注意：影像要带片子或电子影像，不只是文字报告）
  • 之前住过院的出院小结（上面有诊断和用药，信息密度很高）
  • 过敏史清单（药物、食物，以及过敏反应是什么样）
  • 医保卡、就诊卡、身份证

材料按时间顺序整理好，用一个文件袋装。在诊室里翻包找报告是浪费时间。

5. 把问题写下来，按重要程度排序

在纸上写下你最想问的问题，排好序。诊室里容易紧张，想到什么问什么，结果最重要的问题反而忘了。

常见该问的：

  • 这可能是什么问题？还需要做哪些检查来确认？
  • 这个治疗/药物的目的是什么？要吃多久？
  • 有没有更简单的替代方案？如果不治疗会怎样？
  • 有什么副作用需要留意？出现什么情况要立刻回来？
  • 什么时候复查？

6. 带上一个人（可选但很有用）

如果可能，带一个家属或朋友。理由有两个：一是当事人容易紧张、听不全；二是两个人记的内容可以互相补充。让同行的人负责记录医生的关键结论和下一步安排。

7. 出诊室前做三件事

  1. 复述一遍：用自己的话把医生的结论和下一步说出来，问「我理解得对吗」。这是减少误解最有效的办法。
  2. 确认下一步：要做什么检查、去哪做、什么时候拿结果、什么时候复诊、复诊挂谁的号。
  3. 记下没听清的词：回家再查，不要在诊室里用手机搜索。

健康原理

门诊的核心约束是时间，所以信息传递效率决定就诊质量。 在几分钟里，医生需要完成三件事：获取病史、形成判断、给出方案。患者提供的结构化信息能显著提高前两步的效率——把时间从”问基本信息”留给”讨论方案”。[1][2][3][4][5]

为什么时间线比”我现在很难受”更有用。 症状的时间特征是鉴别诊断的关键线索之一：急性起病和缓慢进展指向完全不同的病因范围；间歇性和持续性也各有不同的常见原因。患者往往强调当下的感受强度，而医生最想要的是这个模式。[1][2][3][4][5]

为什么用药清单是安全底线。 药物相互作用和用药冲突是可预防的医疗风险的主要来源之一。医生在开新药时必须知道你在吃什么——尤其是抗凝药、降糖药、影响肝酶代谢的药。患者不主动说，医生就可能不知道（不同医院的信息系统往往不互通）。这也是世界卫生组织把「用药核对」列为患者安全重点的原因。[1][2][3][4][5]

为什么要复述。 患者对医嘱的理解和医生的意图之间存在系统性偏差，这在研究里被反复观察到（” teach-back “方法正是为此设计）。复述是成本最低的纠错手段：说错了当场就能被发现，而回家后才发现往往已经晚了。[1][2][3][4][5]

为什么要带家属。 紧张情境下的记忆编码和提取都会变差，这是普遍的认知现象，不是”记性不好”。第二个人在场能提供独立的记忆副本。[1][2][3][4][5]

证据等级为什么是 C。 「结构化沟通与复述能改善理解与依从性」这一类结论方向一致，但研究质量参差：多数证据来自质量改进项目和观察性研究，很难做严格对照；不同医疗体系的门诊流程差异也很大，具体做法不能照搬。所以本篇给的是原则和清单，而不是有强证据支持的精确操作规范，定在 C 级。[1][2][3][4][5]

常见误区

  • 误区：准备材料是浪费时间，医生问什么答什么就行。 门诊时间有限，被动回答往往覆盖不到关键信息（尤其是用药和过敏史）。
  • 误区：一次把所有老毛病都讲一遍。 这会让最要紧的问题被淹没。一次就诊聚焦一个主要问题，其余的另约。
  • 误区：记不住药名就说”降压药那种小白片”。 用手机拍下药盒照片，或直接带药盒，比任何描述都可靠。
  • 误区：只带报告不带片子。 影像诊断需要看原始图像，文字报告的信息量远小于片子。
  • 误区：医生说没事就不用再问了。 至少问清「什么情况要回来」——这决定了你回家后的判断依据。
  • 误区：出了诊室马上上网搜医生说的术语。 搜索出来的多是极端案例，容易造成不必要的焦虑。存下来，下次复诊时问。

风险与禁忌

  • 急性重症不要准备：胸痛、严重呼吸困难、意识改变、大出血、剧烈腹痛、肢体无力或言语不清——立即就医或呼叫急救。
  • 不要隐瞒：饮酒、吸烟、保健品、中成药、既往流产史、精神类药物使用——这些都会影响判断和用药安全。隐瞒的代价由自己承担。
  • 不要自己停用长期药物（如降压药、降糖药、抗凝药、激素）后再去看病，除非医生明确指示。突然停用可能造成危险。
  • 不要带着”考医生”的心态，也不要因为医生解释得简短就认为他不认真——用准备好的问题清单来引导，比对抗更有效。
  • 不要替家人做决定：陪诊者应帮忙记录和转述，但治疗方案的选择权在患者本人（除非患者无行为能力）。
  • 不要相信”熟人介绍的偏方”胜过医生，也不要把网上查到的诊断当成结论去要求医生。

何时求助专业人士

出现以下情况先看医生，不要只靠本文：

  • 急性重症症状（见上）——立即就医，跳过准备环节。
  • 症状在短期内明显加重，或出现新的、无法解释的症状（不明原因体重下降、持续发热、异常出血）——尽快就诊，不要等原定的复诊时间。
  • 服药后出现新症状（皮疹、黄疸、明显乏力、黑便、意识改变）——尽快联系开药医生或就诊，并带上正在服的所有药。
  • 同时看多个科室、在吃 5 种以上药物——建议主动要求一次用药梳理，避免重复用药和相互作用。
  • 听不懂医嘱、或对方案有疑虑——当场问，或者约一次复诊专门问清楚。不要带着疑问回家自己琢磨。
  • 反复就诊但问题一直没明确——可以主动要求转诊或寻求第二诊疗意见，这是合理且被鼓励的做法，不是不信任医生。

  • 怎么看懂化验单

    读懂化验单靠的是看懂「格式信息」，不是猜数值：①先分清这份单子是筛查还是诊断（两者阈值逻辑不同）②看「项目名 + 结果 + 单位 + 参考区间」四列——参考区间是从一组健康人身上测出来再按统计划定的，绑定着检测系统，所以换一家医院「正常范围」会变，两次结果不能跨机构直接比 ③单位是最容易出错的地方（mg/dL 与 mmol/L 差十几倍，换算错会得出相反结论）④一组指标一起看，因为疾病影响的是通路 ⑤拿同机构的历史结果比趋势。至于「看到箭头要不要紧、要不要马上就医」，是另一篇体检报告上的箭头要紧吗。

  • 止痛药怎么吃才安全

  • 体检报告上的箭头要紧吗

    箭头只说明「超出了这份报告设定的参考区间」，不等于「有病」——参考区间通常按健康人群中间 95% 划定，所以每 20 个健康人里就会有 1 个人某项超标；先看超出幅度、再看有没有相关症状和其他指标一起异常，单次轻度异常多半只需复查，别自己吓自己，也别把箭头当没事。

  • 常见避孕方式怎么选

    选避孕方式看两件事——要多可靠和能不能坚持用，因为「用错的方法」远不如「能一直用对的方法」；按效果排：皮下埋植、宫内节育器（IUD，含铜或含孕激素）> 绝育 > 口服避孕药/贴片/环 > 避孕套 > 体外射精/安全期（这两种失败率很高，不建议作为主要方式）；避孕套是唯一同时防性传播感染的方式，所以推荐「高效方法 + 避孕套」双保险；紧急避孕药是补救、不是常规方法，越早吃越有效。

  • 中药和西药能不能一起吃

    能一起吃，但必须让医生知道你同时在用什么。风险不在于"中药有毒"，而在于有些中药会改变西药在体内的浓度或作用：丹参、当归、银杏会增强抗凝药效果（出血风险），贯叶连翘（圣约翰草）会让多种药物失效，甘草会升高血压并降血钾，麻黄会升高血压心率。而且"中西药隔开半小时"这个流行说法没有可靠证据支持——相互作用多数发生在吸收之后的代谢环节，隔开服用挡不住。中药和中成药也可能伤肝，部分产品还检出过重金属与农残。
